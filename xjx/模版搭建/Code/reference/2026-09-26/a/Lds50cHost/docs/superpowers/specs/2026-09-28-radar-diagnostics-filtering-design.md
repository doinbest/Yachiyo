# 雷达初始化、状态诊断与原始数据导出设计

## 目标

解决自研上位机与原厂上位机点云表现不一致且缺少诊断依据的问题。每次扫描前把 LDS-50C-2/-3 设置为毫米、带能量、开启去拖点和雷达滤波；随后显示雷达实际状态，允许在同一圈数据上切换“接收原始点云”和“上位机筛选点云”，并导出原始整圈 CSV 供进一步分析。

成功标准：

- 单次扫描和持续扫描使用相同的雷达预配置顺序。
- 用户能看到雷达实际报告的距离单位、能量、去拖点和滤波状态。
- 用户能在不重新扫描的情况下切换两种点云显示。
- 点云显示模式不改变障碍格分类和路径规划结果。
- 用户能导出当前完整原始圈的角度、毫米距离和能量。
- 现有串口会话互斥、停止命令和错误处理行为保持有效。

## 用户可见定义

### 接收原始点云

“接收原始”指雷达在当前硬件配置下回传的一整圈测量数据，只进行极坐标到场地坐标的转换，不应用上位机的角度、距离和能量筛选。由于扫描前会开启雷达自身的去拖点和滤波，该模式不是雷达内部算法之前的光学原始采样。

### 上位机筛选点云

“上位机筛选”指同一整圈数据经过当前角度、距离和能量范围筛选后的点云。障碍格识别和路径规划始终使用此数据，显示模式只影响画布，不影响规划。

### CSV 原始数据

导出的是点击按钮时 `ApplicationState` 中最后一个完整 `RadarScan` 的不可变快照。CSV 固定包含：

```text
index,angle_deg,distance_mm,energy
```

角度使用不依赖系统区域设置的小数点格式；距离统一为毫米；文件使用 UTF-8 BOM，便于 Excel 直接打开。持续扫描时导出按钮获取最近已经完成的一圈，不导出正在拼接的半圈。

## 雷达预配置

单次扫描和持续扫描在创建解析器和整圈拼接器后、发送开始命令前，依次写入：

```text
LMDMMH
LOCONH
LFFF1H
LSSS1H
LSTARH
```

含义分别为毫米单位、开启能量、开启去拖点、开启雷达滤波、开始旋转。

所有写操作属于同一个已经取得排他权的雷达会话。任一预配置写入失败时，扫描立即失败，不发送后续开始命令；清理阶段仍按现有规则尝试发送 `LSTOPH`。程序不依赖命令的文本回复来判定成功，而以每圈 `StatusFrame` 的实际状态作为最终诊断依据。

## 状态与单位处理

`ApplicationState` 保存最近一个 `StatusFrame` 的四项解释结果和接收时间：

- `UsesMillimetres`
- `EnergyEnabled`
- `TrailingPointRemovalEnabled`
- `FilterEnabled`

状态在单次扫描和持续扫描的数据循环中更新。尚未收到状态包时界面显示“等待雷达状态”；收到的状态与预期不一致时，对对应项目显示警告。

预配置要求毫米输出。若状态包仍报告厘米输出，程序不得把厘米值直接当作毫米；后续测量帧在进入整圈拼接器之前将距离乘以 10 并以毫米保存。若尚未收到状态包，则依据刚发送的 `LMDMMH` 按毫米解析。归一化后的距离超过 `ushort` 表示范围时将该点记为无效距离 0，避免溢出产生近距离假点。

## 状态管理与地图数据流

`ApplicationState` 同时维护：

- `RawScan`：最后一个完整、距离已归一化为毫米的扫描圈。
- `RawFieldPoints`：`RawScan` 中所有点转换到场地坐标后的结果。
- `FilteredPoints` / `FieldPoints`：应用现有上位机筛选后的结果。
- `PointCloudViewMode`：`ReceivedRaw` 或 `HostFiltered`，默认 `HostFiltered`。
- 最近雷达状态：可空，表示尚未收到状态包。

接收新圈、修改地图雷达坐标或修改筛选条件时，重新计算相应坐标数组。障碍分类器只接收 `FieldPoints`；`FieldMap` 根据 `PointCloudViewMode` 在 `RawFieldPoints` 和 `FieldPoints` 之间选择画布点集。

切换显示模式只触发界面刷新，不修改本机保存配置，不修改 STM32 下载配置，也不重新扫描。

## 界面

### 点云筛选面板

增加两段式按钮：

- 接收原始
- 上位机筛选

按钮旁文字说明“只切换显示，不改变障碍格和路径”。现有角度、距离、能量筛选输入保持不变。

### 数据诊断面板

在帧解析计数附近增加“雷达实际状态”：

- 单位：毫米 / 厘米 / 等待状态
- 能量：开启 / 关闭 / 等待状态
- 去拖点：开启 / 关闭 / 等待状态
- 雷达滤波：开启 / 关闭 / 等待状态

与预期不一致的已知状态使用警告样式。点预览表根据当前显示模式展示前 12 条，并明确标注当前模式。

增加“导出当前原始圈 CSV”按钮。没有完整扫描圈时按钮禁用；下载失败时记录到现有运行日志并显示可读错误。

## CSV 下载接口

应用增加只读下载端点 `GET /api/radar/latest-scan.csv`。端点从 `ApplicationState` 获取最近完整圈的快照并调用独立的 CSV 序列化器：

- 有扫描时返回 `text/csv; charset=utf-8` 和带时间戳的文件名。
- 没有扫描时返回 `404`，不生成空文件。
- 序列化器是无状态纯逻辑，便于独立测试。

端点只读取本应用内存中的扫描数据，不访问串口，不停止持续扫描，不写服务器文件。

## 错误处理

- 预配置命令写失败：扫描失败并显示具体命令阶段，保留上一圈地图。
- 状态与预期不一致：扫描继续，但诊断面板显示警告；厘米数据执行单位归一化。
- 状态包缺失：扫描继续并标注“等待雷达状态”，不臆造已开启状态。
- CSV 无可用圈：按钮禁用；直接访问端点返回 404。
- CSV 序列化失败：返回服务器错误并写运行日志，不影响扫描会话。

## 测试策略

### 核心测试

- 厘米测量帧正确转换为毫米。
- 毫米帧保持不变。
- 厘米换算溢出时产生无效距离 0，而不是回绕为近距离。
- CSV 表头、行号、角度格式、毫米距离、能量和 UTF-8 BOM 正确。
- CSV 在中文区域设置下仍使用小数点。

### 应用测试

- 单次扫描按 `LMDMMH`、`LOCONH`、`LFFF1H`、`LSSS1H`、`LSTARH` 顺序写入，结束时发送 `LSTOPH`。
- 持续扫描使用相同预配置顺序。
- 预配置写失败时不发送 `LSTARH`，但清理逻辑仍可执行。
- 收到状态包后 `ApplicationState` 保存四项状态。
- 状态报告厘米时，后续完整圈中的距离以毫米保存。
- 切换点云显示模式改变画布数据源，但不改变障碍格和路径。
- 修改雷达场地坐标会同时更新原始和筛选后的场地点。
- 下载端点在有圈时返回 CSV，在无圈时返回 404。

## 非目标

- 本阶段不实现厂商 SDK 的阴影滤波、中值滤波或邻域离群点滤波。
- 不集成厂商 C++ DLL。
- 不导出正在拼接的半圈数据。
- 不改变 STM32 通信协议和路径规划算法。
- 不在本阶段提供关闭雷达硬件滤波或去拖点的界面开关。
