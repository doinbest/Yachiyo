# 硬件验证清单

自动化测试不能代替真实雷达、USB-UART 和 STM32 的联调。第一次上车前逐项记录结果，不要为了通过测试而放宽帧头、长度、校验或 CRC 检查。

## 1. 上电前

- [ ] 用万用表确认雷达电源约 5.1 V，极性正确，电源限流能力至少覆盖 1.5 A 启动峰值。
- [ ] 确认 UART 为 3.3 V，不把 5 V TTL 直接接入雷达 RX。
- [ ] 雷达、USB-UART、STM32 共地，TX/RX 交叉。
- [ ] 雷达旋转中心实测位置录入 X/Y；默认 `(230, 230) mm` 只是当前场地初值。
- [ ] 确认雷达 0° 朝场地 +Y，顺时针角度朝 +X 增大。

## 2. 雷达直连

- [ ] 本项目当前硬件验收使用 `921600`、8N1；若无数据，先核对雷达当前保存的波特率和串口占用，而不是盲试任意值。
- [ ] 点击连接后发送“启动旋转”，确认机械旋转稳定。
- [ ] 点击“单次扫描”，确认 8 秒内完成一圈并自动停止。
- [ ] 开始单次或持续扫描后，确认程序依次发送 `LMDMMH`、`LOCONH`、`LFFF1H`、`LSSS1H`、`LSTARH`；停止后确认发送 `LSTOPH`。
- [ ] 诊断面板显示：距离单位“毫米”、能量数据“开启”、去拖点“开启”、雷达滤波“开启”，并有本次扫描的状态更新时间。
- [ ] 有效帧持续增加；校验错误、长度错误和丢弃字节在稳定链路下应为 0 或不再增长。
- [ ] 保存一次原始整圈串口字节为 `fixtures/真实设备_日期_波特率.bin`，同时记录型号、转速、分辨率和环境。

## 3. 距离与坐标

- [ ] 在 0° 正前方放置平整目标，实测 500、1000、2000 mm；界面距离应在设备精度允许范围内。
- [ ] 在 90° 方向放置目标，确认点主要增加在场地 +X，而不是 -X 或 +Y。
- [ ] 用已知直墙检查点云是否形成直线；若整体平移先校准雷达 X/Y，若整体旋转则纠正安装朝向。
- [ ] 黑色目标分别在近、中、远距离测试。降低最小能量只影响过滤，不会让雷达产生原本未收到的回波。

## 4. 筛选、分区与规划

- [ ] 冻结一次扫描后改变角度、距离、能量，原始点数不变，筛选点数和地图可变。
- [ ] “接收原始”显示雷达固件处理后实际发回的点；“上位机筛选”显示本软件角度、距离和能量条件通过后的点。切换显示时，障碍格、格内点数和规划路径不得变化。
- [ ] 下载最新完整一圈 CSV，确认首行为 `index,angle_deg,distance_mm,energy`，行顺序与接收点顺序一致，且不包含正在接收的半圈。
- [ ] 把障碍放入已知方格，确认红色扫描障碍格与物理位置一致。
- [ ] 分别拖动 8 条内部边界，确认只有所拖边界变化，任何格宽/高不得小于 50 mm。
- [ ] 黄色四格始终是固定禁区且不能单击清除；普通格可在无色与橙色之间切换。
- [ ] 路径不穿过黄、橙、红障碍，只进行上下左右移动。

## 5. 可疑回波与原厂上位机对照

以下步骤必须让雷达、目标和场地全程保持不动，并让两个上位机使用相同的雷达安装位置与朝向。一次只能由一个程序占用串口。

- [ ] 在本上位机以 `921600` 启动持续扫描，等待点云稳定后记录四项雷达状态。
- [ ] 切到“接收原始”，确认可疑的中间竖线是否存在；再切到“上位机筛选”，记录它是否被保留。两次切换期间不要移动雷达或物体。
- [ ] 导出最新完整一圈 CSV，找到竖线对应的角度范围和 `distance_mm`；确认这些记录确实来自雷达返回，而不是画布连线或历史圈叠加。
- [ ] 选择一面位置明确的实体直墙，记录本上位机 CSV 中该墙的距离，并用画布鼠标坐标核对绘制位置。
- [ ] 停止扫描并确认 `LSTOPH` 后退出本上位机，再用原厂上位机连接同一雷达；在相同静止环境和相同角度处记录该实体墙的距离以及可疑竖线是否存在。
- [ ] 比较三项结果：本上位机 CSV 距离、本上位机绘图距离、原厂上位机距离。CSV 与本软件绘图不同表示坐标变换/显示问题；两者一致但与原厂不同表示设备配置或协议解释问题；三个结果都出现同一点则它是雷达实际返回的回波，应继续排查反射、多径或场地内低矮物体。
- [ ] 点击“停止持续扫描”，确认雷达正常停止且最后一圈仍可查看、导出。

## 6. STM32 下载与读回

- [ ] STM32 串口实现 [stm32-protocol.md](stm32-protocol.md) 的 3.3 V 8N1 接收、缓存、CRC 和超时。
- [ ] 选择“STM32 配置”并连接正确 COM 口。
- [ ] 点击“下载、应用并校验”，确认四步顺序均得到相同序号的响应。
- [ ] STM32 读回 47 字节配置与上位机一致。
- [ ] 故意破坏一个 CRC，STM32 应 NACK 或丢弃，不得应用部分配置。
- [ ] 点击“保存到 STM32 Flash”，确认收到 ACK；断电重启后读回配置仍一致。下载流程本身只保证本次运行时应用，不会自动擦写 Flash。

## 7. 底盘标定

- [ ] 测量车轮有效直径、减速比、编码器每转脉冲数，得到理论 `脉冲/mm`。
- [ ] 分别命令直行 500、1000、2000 mm，实测并拟合比例，不只用一个距离。
- [ ] 标定左右轮差、起步死区、制动提前量和 90° 转向量。
- [ ] 路径坐标正确不代表车辆必然走准；最终误差必须用编码器/IMU 闭环和实车重复测量验证。
