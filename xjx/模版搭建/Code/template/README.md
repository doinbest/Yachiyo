电机总线短时接收噪声优先恢复RX并输出警告，未收到真实应答仍按原期限处理，不重复HOME/运动。非比赛通信锁定自动停止并尝试恢复；恢复内通信抖动间隔2秒重试，人工停止可取消。四轮零速写入均确认后，单独同步被拒绝只记警告，仍须验证真实停稳。恢复通信不表示中断的回零已完成；参考未验证时需重新回零。比赛沿原暂停/恢复进度处理。

比赛视觉航向开启时，每次进入加工区或暂存区仅启动一次航向观测；同次访问的换环、逐件放置和加工取回不重复。第二批再次进站重新观测。每件色环/物料位置对准保留；暂停、继续与总线恢复续接当前阶段，未完成观测可继续取证，独立航向测试不变。

航向采样使用独立5秒窗口，从机构停稳、开始请求时计时；漏检、USB重试及采样组重置不延长截止时间。允许间断有效帧累计，至少3个不同序号且接收时刻递增的新鲜样本；最后一帧必须新鲜。已标定使用head_spread比较换算后的角度，未标定/独立观测使用图像角最大差0.3°并取三帧平均值；不凭未标定图像角自动更新地图。无效/缺失帧不清空已有有效样本，不一致则重建采样组；机构运动后旧样本作废。5秒内证据不足报告heading_no_observation并沿用原航向继续。尚未成功提交的校准也受该截止时间约束；已采用校准或开始转向后仍完成运动和停稳验证，不以采样超时跳过。人工暂停后重新给予观测窗口，普通物料视觉等待参数不变。

X/Z固定目标动作使用当前轴配置的驱动加速度档位，默认X20、Z255；场景速度和有限绝对终点保持，MCU不再周期重发余弦调速。视觉连续纠偏、渐进下降、回零、Base和ID8沿用各自控制。到位、停稳、机械限位和驱动故障检查保留；Z先抬到0再收X，取仓避让X30 mm并行规则不变。详见[机械臂协议](../../docs/协议/机械臂与取放.md)。

## 按需求定位

正式比赛加工进站为(1200,380)到点转至180°后视觉接管，删除固定125 mm贴近；同次工位作业保存首次成功对准的实际底盘XY及环号，后续按环距150 mm保留位置偏移换环，每件仍重新视觉确认，加工取回顺序不变。中心到暂存区在中心停车，按较小转角选0°倒车或180°前进至(425,1200)，停车转90°作业朝向，保留最后75 mm低速接近。暂停/恢复保留工位锚点，再次进站重建；无需网页写入新参数，预览共用固件C核心。

底盘直线平移提供linear与cosine两种模式：linear为默认，软件向量加减速度300 mm/s²；cosine为K=200、名义400 ms半余弦速度过渡，短段降低峰值。两者都计入反馈年龄和驱动响应的制动余量，共用1000 mm/s路线默认速度、工位局部限速、位置/航向及新鲜停稳判定。除线性模式恢复分段开局外，其他连续转弯和原地转向保持现行独立控制。驱动档位仍为0，位置与停稳确认独立。余弦模式正式右下开局采用共享 `chassis_path.h` 的右通道曲线：保持180°到(2125,350)，600 mm内转至(2100,950,90°)后直行；开局上限200 mm/s，保留原前瞻、向量变化率和航向限速。第一批从右侧保持90°横移到物料台中间(1200,2100)，到点停稳后原地顺时针转90°至0°；第二批中央进站曲线保留。余弦模式开局接近段尚未改为余弦控制。线性模式的正式右下标准开局恢复分段路线：(2250,150,180°)保持朝向斜移到(2100,300)，新鲜反馈确认停稳后顺时针原地转到90°，再直行至本轮二维码纵坐标；各平移段使用本轮路线速度上限及300 mm/s²线性规划，不套连续弯道200 mm/s上限。转向停稳后才准备Base扫码姿态，并可与后续直行并行。余弦模式保留右通道连续开局；右上起点、右上角至物料台、第二批进站、非标准绕障和独立二维码测试保持各自现行路线。详见[比赛与取放约定](../../docs/比赛与取放约定.md)。

普通雷达扫描统一为15个有效完整圈；`radar scan lower 15` 采集并规划，`radar live map start lower` 持续更新最近15圈，`radar stop` 停止采集。下方默认情况二 `(2280,314)` 和精确Q16标定；车体起点为 `(2250,150,-180°)`，工位、首段接驳和取放流程保留。上方独立雷达安装为 `(2050,2250,270°)`，与右上车辆名义起点 `(2250,2250)` 分开，不套用下方矩阵。稳定点XY是独立结果，原始点云仅来自最后一圈诊断。

机构实物条件见[硬件与运行基线](../../docs/硬件与运行基线.md)：Base作业为原参考+130°、扫码为原参考+35°，车仓方向为原参考；ID8仓1/2/3默认0°/+90°/+180°，与Base及车体yaw独立。源码默认、烧录版本及设备RAM分别核对。

坏帧、缺段和DMA覆盖只回滚当前圈。更改标定或筛选需新15圈；阈值和路线参数可用匹配的完整稳定证据重算。CPU工作区及稳定点传输副本使用CCM，接收DMA仍在普通SRAM。操作与协议见[地图与雷达](../upper-computer-web/local-car/docs/地图与雷达.md)、[雷达协议](../../docs/协议/雷达.md)。

离线程序 `Code/tools/radar_plan_cli.c` 支持原有 `RADAR1` 历史单圈语义，以及 `RADAR2 mask circle_count`：随后为原10项参数、情况编号、4项矩阵Q16、2项平移Q16、零角0.1°，再依次为每圈点数及 `[angle_tenths distance_mm energy]`。输入至少15个有效完整圈，超过15圈按最近15圈计算；自动双起点输入为15圈。离线程序调用同一投影、稳定证据和规划C核心，不操纵串口。
