三角速度：均匀加力，直接换成刹车

速度线向上倾斜：每秒变快同样多；到了中点，改为每秒变慢同样多。因此速度连续，但加速度会从正值突然跳到负值。

如果先碰到速度上限，中间会多出一段匀速，形状从三角变成梯形。

半余弦：轻轻推起，再逐渐收力

每次加速过渡的两头变化慢、中间变化快。减速也逐渐加重、再逐渐收尾，减少突然“推一下”的感觉。

相同用时下，中间最大加速度是线性方式的π/2倍，约1.57倍。若限制相同最大加速度，就要给它更多时间。

为什么平顺有时能减少打滑？

轮胎靠地面摩擦拉动车身。加速度越大，需要的牵引力越大；突然改变加速度也容易带来冲击、晃动和跟踪误差。平滑过渡有助于减轻这些瞬态影响，但牵引需求仍不能超过地面能提供的能力。

红色仅表示 |加速度| 超过你设定的假设牵引上限。地图按无滑移理想运动计算，超限时也不人为生成漂移。真实打滑还取决于地面、载荷、麦轮方向和电机响应；本演示不能预测打滑距离，也不能证明实车可达到所设速度。
