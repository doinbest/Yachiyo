当前待部署新版为 [`combined_color_digit_ring.py`](combined_color_digit_ring.py)，以用户2026-10-15提供的 `combined_color_digit_ring(1).py` 为基准更新。支持颜色01～06、编号环0A～0C、色环姿态0D（优先三环，允许相邻两环）及码垛前方黑线姿态0E。旧入口 `vision.py` 保留，不自动切换服务或远端部署。STM32已接入两种姿态来源；尚未实测标定，普通核验仅观测。实现、软件验证、下载、远端部署及实车状态见[本次记录](../../docs/开发记录/2026-10-15-码垛前方黑线航向.md)。

启动：`python3 combined_color_digit_ring.py --usb-port <实际设备路径>`。附件新版颜色默认准心为 `(357,324)`，编号环及色环姿态准心为 `(367,316)`，按本次最新版保留；颜色可用 `--center-x/--center-y` 覆盖，不接受旧ring-center选项。不要把历史准心或39/−1补偿再次加入STM32；实机启动配置及补偿仍需分别核对。

| 请求 | 独立回复目标与数据槽 |
|---|---|
| `FF B2 0D FF` | `0D / Valid / EX / EY / EA_X100 / STOP` |
| `FF B2 0E FF` | `0E / Valid / 0 / 0 / EA_X100 / STOP` |

回复仍为14字节B2帧，四槽有符号大端int16，SUM包含STOP。两种角度共用 `THREE_RING_REFERENCE_YAW_DEG`（当前图像水平向右0°），右端向下为正；STOP只是±5°诊断，不驱动车体。黑线只检测画面底部70%～97%区域、横跨至少70%宽度的近水平黑带，用浮点拟合方向输出角度。黑带两侧须有较亮背景；宽度支持受实际观察高度和画面影响。

黑线每次有效输出都重新检查三帧稳定窗口。漏检时保留至多两帧历史线用于画面提示，但发送`Valid=0`及零数据，不把旧角度当新校准证据；重获后三帧重新确认。单纯使用相同图像零点不证明透视与车体映射已经标定；STM32用独立`head_line_zero/head_line_gain`，不复用色环映射。黑线专项测试：`python Code/tests/pile_line_pose_test.py`，不打开摄像头或串口。

启动：`python3 vision.py --usb-port <实际设备路径>`。依赖 Python 3、OpenCV、NumPy、pyserial；数字圆检测使用 `cv2.HOUGH_GRADIENT_ALT`。默认请求 V4L2/MJPG、640×480、120 FPS，实际能力以相机为准。采集线程仅保留最新帧，发送上限50 Hz，实际频率受检测耗时影响。

| USB CDC请求 | 目标 |
|---|---|
| `FF B2 01 FF`～`FF B2 06 FF` | 红、黄、蓝、绿、黑、浅蓝 |
| `FF B2 0A FF` | 中央数字1的同心圆 |
| `FF B2 0B FF` | 中央数字2的同心圆 |
| `FF B2 0C FF` | 中央数字3的同心圆 |

返回仍为14字节 `FF B2 Command Valid CX_H CX_L CY_H CY_L DX_H DX_L DY_H DY_L SUM FE`，目标字节回显请求。2026-10-12物料颜色默认准心改为(372,345)，用 `--center-x/--center-y` 修改；编号环默认(378,333)，用 `--ring-center-x/--ring-center-y` 修改。两类参数互不覆盖，DX=CX−对应准心X、DY=对应准心Y−CY。当前STM32所有视觉控制均直接使用B2有符号DX/DY，包括真实零值，旧ref_u/ref_v已删除；CX/CY仅用于诊断和视野边缘判断，见[当前协议](../../docs/协议/视觉B2与动态追踪.md)。没有检测到目标时发送Valid=0及零坐标，协议不包含采集时间、置信度或远端帧序号。本地源码、远端部署、启动参数覆盖及实机状态须分别核对。

**当前STM32源码已接入0A～0C**：仅识别使用 `camera ring <1|2|3>`，静态对准统一使用 `grab align ring <1|2|3> [z_mm] [stay]`，旧 `grab ring align` 保留兼容。视觉任务页分别提供环号选择；对准后的人工装料/Z放置流程保留。新版固件与视觉程序均部署后方可实测。

数字模式每帧检测多重同心圆，再以合成字体模板/HOG识别中央数字，要求至少3个不同半径的圆，圆心组距离阈值12像素；数字置信阈值0.50，类别差阈值0.015。默认半径18～65像素，最大组半径25～65像素，需要用实际观察高度验证。物料遮挡数字后可能漏检，不能把持续编号识别当作已完成定位的唯一依据。
