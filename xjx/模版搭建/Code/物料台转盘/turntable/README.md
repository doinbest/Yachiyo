# STM32F103C8T6 物料台转盘

## 当前入口：双按键自动分度，不等待回包（2026-09-25）

main.c 调用 Turntable_DirectInit/Process，上电静止等待按键；不启动串口接收，不发送查询，不等待应答。上电等待 1 秒后再按键。

- PA15：空闲时发送使能，间隔 100 ms 后以 8 RPM 执行分度；首次约 60°，之后每段约 120°，估计运动完成后等待 2 秒，自动循环。再次按下直接发送停止并取消自动循环；单步过程中 PA15 也发送停止。
- PB3：仅本机空闲状态接受，发送使能，间隔 100 ms 后发送模式 0、相对上一目标位置递增的单步命令；首次约 60°（533 脉冲），后续约 120°（1067/1067/1066 脉冲交替，避免固定取整累计偏差）。运动中不排队，长按不连发。
- 每段忙碌时间按指令速度/脉冲估算并额外等待 500 ms；自动模式再等待 2000 ms 才发送下一段，实际静止时长可能大于 2 秒，不是反馈确认后的精确计时。PB3 单步完成后不循环。无机械回零。
- PA15 停止只说明本机发送了停止请求，无回包不能确认物理停车。中途停止后没有读取实际位置，不能保证补完原目标或下一次相对实际位置恰好转 120°；当前修正验证的是每段正常完成后的连续分度。停止中断运动后不会自动对齐初始工位；需要重新对齐时断电人工摆放、重新上电。
- Keil Watch 可查看 Turntable_DirectStatus：pa15_events/pb3_events 是消抖按下次数，tx_attempts 是发送尝试次数，tx_result=0 表示 HAL_OK，state 仅为本机指令状态。计数增长而电机不动时继续检查发送和驱动执行；不应把发送成功当作应答。

上电直发版已保存于 Git 提交 2e23ffe。原上电直发与有反馈分度模块均保留但当前不调用。旧反馈模块的说明与验收步骤保存在[整理前说明](../../../docs/开发记录/2026-10-09-文档整理前快照/原F103转盘说明.md)，不作为当前操作。

2026-09-25修正记录：模式字节由 2 改为 0。用户实测模式 2 表现为到绝对 60°、绝对 120°后不再移动；不再依赖该扩展模式。正常完成各段时，累计目标应为约 60°、180°、300°、420°。

## 当前工程入口与回归

Keil 打开 `MDK-ARM/turntable.uvprojx`，Target `turntable`；CubeMX 工程为 `turntable.ioc`，当前没有 EIDE 清单。`Core/Src/main.c` 调用 `App/turntable_direct.c` 的 `Turntable_DirectInit/Process`，按键消抖在 `Hardware/turntable_key.c`。

在仓库根目录执行 `python Code/物料台转盘/turntable/tests/run_tests.py`，需要 GCC、Python；测试不操作硬件，日志保存到 `.embeddedskills/turntable/`。模块与压缩包分类见 [上级目录说明](../README.md)。



## 接线与硬件

主控F103C8T6，HSE 8 MHz、HCLK 72 MHz，保留PA13/PA14 SWD并关闭JTAG。USART1 PA9 TX接驱动RX、PA10为RX引脚，115200/8N1并共地；当前direct入口不启动串口接收。PA15/PB3按下接GND，PB4未焊接、不读取。Emm电机默认ID1、1∶1直连、三盘120°均布；运动速度8 RPM是当前训练设置，比赛实际方向/停留按现场条件。软件发送成功不代表实际停车。
