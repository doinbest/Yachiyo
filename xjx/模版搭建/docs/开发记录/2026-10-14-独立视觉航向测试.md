# 独立视觉航向测试

用户要求上电后把小车有意摆偏，先准备视觉姿态，再点击独立航向矫正。已增加“视觉任务 → 航向矫正”，不依赖比赛扫码、任务码、库存或路线。

## 操作

1. 将空爪小车摆在加工区或暂存区的三环前，允许待测试的小角度偏差；等待上电回零和IMU验证完成。
2. 选择对应工位，点击“1 · 准备视觉姿态”。复用物料取放的`grab pose work`，先抬Z、收X，再Base到原参考+128°，完成后开爪2500 µs。
3. 姿态完成后点击“2 · 开始视觉航向矫正”。页面展示图像角、测试前地图角及当前地图角。点“读取测试状态”可刷新设备状态；进入、编辑、重连均不自动动作。
4. “停止测试”结束独立任务并核验实际停车；再次开始需已具备准备姿态，停止后可重新准备。停止尚未确认时拒绝新测试。

当前用户确认尚未实测角度映射，因此参数继续未设置：只采集图像角，不修改地图航向或自动转车。补齐对应工位零点/比例、稳定与完成门限以及实测可转范围后，同一入口复用比赛的校正模块。测试转速默认5°/s，可选1～10°/s，仅标定后实际转向时使用；不是已验证实车精度或许可范围。

## 接入

命令`grab heading proc [1..10]` / `grab heading temp [1..10]`分别采用加工180°、暂存90°名义航向。受理后自动开启四轮反馈，等待新鲜静止反馈及有效IMU。已有有效定位原点不改；上电无定位时，在当前位置建立(0,0,名义航向)的本地测试基准，不冒充真实场地XY、不复位IMU。正因初始摆偏仍被赋名义角，后续有效视觉校正才能用来验证这类映射偏差。

测试复用比赛调度所有权，状态为`mode=heading`；不启动比赛路线、不扫二维码、不清库存、不自动取放、不修改比赛默认开关。机构准备仍由原Pose流程负责，独立测试等待完整Base/X/Z新鲜静止证据后才使用角度。B2/0D及STOP忽略规则不变。独立测试停止后不提供自动续跑；通信故障停止，处理后可重新准备并测试，比赛自身恢复流程保留。

状态另有`heading_before`、`map_yaw`与`local_origin`；前两项单位度，local_origin=1表示本轮自动建立本地基准。已有定位时local_origin=0表示复用，不能仅凭0推断该原点一定是真实场地标定。
