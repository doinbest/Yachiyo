# 底盘补偿航向独立测试

> 更新：2026-09-12独立测试已改用本次启动验证通过的HWT101模块角度，不再调用外部补偿或从Flash恢复验证资格。PID参数及测试范围保留；当前流程见《2026-09-12HWT101原生零偏标定》。

## 范围与数据流

用户选择先增加独立测试命令，验证后再用于视觉搬运。本轮将补偿角度接入独立速度航向控制，不改变 MaterialVision 的原有运动算法，不启用旧 Chassis_Key_Process。

主循环先调用 HWT101_Process 和 HWT101_Drift_Process，再运行 Mecanum_Velocity_Process。后者在独立测试期间读取 HWT101_Drift_ControlAngleGet 的缓存数据：必须 DONE/PASS，补偿有效、传感器就绪、无新增 I2C 错误且数据新鲜。异常不回退到原始 yaw，发送四轮停车命令并结束测试。

控制角度采用固定 bias_dps，对最新原始读取补偿；其时间和计数对应这次原始读取，不等待下一个 100 ms 拟合样本。日志和原始角度接口维持现有语义。

每次测试锁定启动时的补偿航向，使用现有麦轮运动学和 UART5 电机接口。初始 P=0.02 rad/s/deg、I=D=0，角速度限幅 ±0.15 rad/s，名义更新周期 100 ms，发送四轮命令本身有阻塞耗时。到时停车依赖主循环执行，不是硬实时硬件定时停车。发送成功也不等于实际电机已反馈确认停止。

## 命令

| 命令 | 行为 |
|---|---|
| `chassis hold 30 5` | 锁定当前补偿航向，前进30 mm/s，运行约5秒后发送停车 |
| `chassis hold -30 5` | 保持当前航向后退 |
| `chassis hold 0 3` | 原地保持当前航向，不设平移速度 |
| `chassis status` | 查询active、reason、target_deg、current_deg、output_rad_s |
| `chassis stop` | 提前结束测试并发送停车 |

速度范围-100..100 mm/s，时长1..10秒。目标角度为启动时的朝向，不是绝对0度。测试结束通过 `chassis status` 查询，不增加连续输出。

未通过IMU验证返回 `imu_not_verified`；已运行持续速度模式时返回 `velocity_busy`，需先停车。独立测试期间阻止新的运动命令和按键视觉对准，允许查询、停止和IMU日志控制；`imu cal start` 返回忙，`imu cal clear` 先发送停车再清除补偿。

状态原因：`running`运行中、`complete`到时结束、`stopped`主动停止、`imu_invalid`补偿失效、`motor_tx_error`运行命令发送失败、`stop_tx_error`停车发送失败。`current_deg` 为最近一次用于控制的角度，结束后保留；停止后输出值清零。

## 实物测试步骤

1. 烧录新HEX，首次预热并发送 `imu cal start`，保持静止直到PASS。最新版本自动保存Flash：等待FLASH state=saved后可断电，重启恢复时imu status显示result=SAVED、source=flash。恢复历史值也可用于hold测试，详见《2026-09-11IMU标定Flash持久化》。
2. 电机不使能时发送 `imu stream on`，从上方观察，轻轻将整车逆时针转动少许，检查corrected增大。无需精确转90度，这只是确认反馈方向。当前 `CHASSIS_HEADING_TEST_YAW_SIGN=1.0f`；若逆时针角度减小，应改为-1.0f并重新编译，然后再测试电机。小幅转动时避开±180度边界以便观察。
3. 关闭stream。先架空验证已知的四轮极性与修正转向，再在有空间的地面低速测试。若偏转修正方向相反，立即 `chassis stop`，核对IMU符号和四轮极性。
4. 发送 `chassis hold 30 5`，程序以30 mm/s前进约5秒；理想平移约150 mm，实际以轮径、打滑和电机响应为准。运行中可少量查询 `chassis status`，避免连续轮询占用控制时间。
5. 到时查询 `chassis status`，应为active=0、reason=complete。也可运行中发送 `chassis stop` 验证提前停止。
6. 对比开始/结束朝向以及target/current偏差，记录是否持续偏转、是否振荡、是否出现imu_invalid。通过实物方向和低速测试后再讨论视觉搬运接入及增益整定。

OLED缺失时旧重试路径仍可能造成sample_gap，继而使独立测试停车；本轮未修改OLED驱动。不能将这种退出解释为航向PID失稳。
