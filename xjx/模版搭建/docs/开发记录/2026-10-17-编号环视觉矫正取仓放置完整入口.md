# 编号环视觉矫正取仓放置完整入口

用户要求在编号环区域增加单条指令完成视觉航向矫正、选择环号、对准、指定车仓取料和放置，并可调下降高度。沿用当前只修改代码、不测试、不编译、不烧录安排。

## 接口与动作

新增grab ring run <ring 1..3> <slot 1..3> <drop_mm>，例如grab ring run 2 1 110。drop为从Z=0向下的正数，(0,150] mm并核验当前真实Z边界；本次release_z=-drop仅保存于独立任务及对准快照，不写z_proc_place、不影响后续正式比赛。接受后短行报告ring/slot/drop_mm/release_z。网页编号环放置新增“一键完整流程”，选择环、仓和下降距离，初值由源码默认z_proc_place换算；原分步入口保留。

父任务采用RingOnly独立模式和新的RingFlow标识，自动启动作业姿态，按独立航向准备逻辑核验新鲜四轮/IMU及真实停稳。已有有效原点保留，缺少时仅建立当前位置本地测试参考，不声明比赛起点。色环使用现行比赛同源反号1∶1及最高10°/s规则；只有heading_verified才进入指定编号环高位对准，观测不足或参考不合格报告原原因并停止。该严格要求只作用本次独立完整测试，不改变正式比赛的5秒观测不足继续策略。

对准后复用保存实际X/Z、预分度、指定仓取料、2120µs防碰开口、X30避让、首仓90°避让、恢复保存X、下降释放提起的现有流程，不扫码、不跑比赛路线、不清全部库存。颜色未登记沿用未知，不假设红色；只在实际完成取起时按原逻辑更新所选仓。新高度经GrabTask_AlignPlaceStartAtZForSlot写入本件RingReleaseZ，Capture保存release_z，后续AlignedPlace直接使用该快照。

暂停/继续沿用父子任务进度，本件环、仓、释放绝对高度及已夹阶段保留。独立航向没有路线停车所有者，新增该阶段暂停时的显式ChassisMotion停车及本次反馈确认；续接重新准备并核验航向，不能遗留转向在后台。终止沿用取消链。启动下一普通比赛明确撤销RingFlow，独立新任务清空旧RingAlignmentSaved，避免复用旧对准或本次高度。
