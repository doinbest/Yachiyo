# 前进变顺时针旋转：静止反馈检查

用户报告 `chassis run 100 0 0 1000` 导致小车原地顺时针旋转。用户确认 COM37、115200 / 8N1，并确认已停稳，授权解除上位机停车锁，仅开启四轮反馈检查。

通过现有本地共享服务操作，没有发送使能、运动、复位或参数持久化命令，没有修改固件。

初次缓存四轮均 valid=0,0,0、rx_ms=0，不能将缓存的零转速视为实际静止。执行 `chassis feedback 0`、`chassis feedback on` 后，两次查询均四轮 valid=1,1,1、raw_rpm=0、flags=0x03；接收时间约从 MCU 657.7 秒更新至 672.1 秒。位置如下，两次完全相同：

| ID / 轮位 | 原始位置单位 |
|---|---:|
| 1 / 左前 | 107347 |
| 2 / 左后 | 264511 |
| 3 / 右后 | -205625 |
| 4 / 右前 | -362317 |

任务查询 state=3、reason=cancelled、error=0、ack=2、locked=0、units=0。units=0 是当前 MCU RAM 尚未应用位置反馈换算配置，不改变已确认的 Emm 65536 协议单位/电机轴圈定义。

结论：本次静止观察中四个驱动器均应答，反馈持续更新且位置稳定。绝对位置包括之前多次运动，不能用其正负或大小推断本次运动轮向。源码前进极性为 ID 1/2 dir=0、ID 3/4 dir=1；实际轮向、轮位与 ID 的对应以及航向纠偏符号仍需独立验证。尚未定位或修复原地旋转原因。

结束发送 `chassis feedback off` 并收到受理；COM37 保持连接，上位机停车锁已解除。没有为恢复停车锁额外发送停车命令。
