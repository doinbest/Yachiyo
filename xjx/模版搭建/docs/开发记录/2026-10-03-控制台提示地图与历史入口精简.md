# 控制台提示、地图与历史入口精简

用户要求取消参数行重复的未读取提示，地图使用合适的固定比例，并整理旧版控制台功能。修改前基线为 `d60658c`（参数页密度与标题提示优化）。本轮仅调整本地网页、相关测试和现行说明，不修改 STM32 固件或通信协议。

## 参数提示

- 正常参数行只显示名称、输入框、单位；取消常驻“设备值：未读取”“未读取”“已读取”“读回一致”等重复标签。
- 顶部统一显示未读取、全批次读取进度和实际成功/失败数量，两行结果栏显示应用与核对结果。
- 草稿改动用输入边框颜色标记待应用。未设置、读取失败、未支持、设备拒绝及读回不一致按字段显示原因；成功项不额外占一行。
- 内部已读设备值继续用于写后比较、Z 距离换算及草稿判断；鼠标悬停输入框可查看设备值或历史值。单项应用后，其余尚未重新读取的历史值仍在顶部标明。
- “读取当前全部参数”继续覆盖五个标签的全部设备字段，雷达使用完整分页批次读取，浏览器路线速度不参加设备读取。
- 保留读写超时与取消、失败保留输入、普通停止保留读回与草稿、断线/重启标记历史值，以及导航不发命令的既有行为。

## 完整场地视野

地图按固定范围等比适配容器，包含比赛场、场外原料台及标注。取消滚轮缩放、右键放大、左键拖动和“恢复视图”，滚轮及触摸恢复为正常页面滚动，鼠标使用坐标查看光标。桌面地图高度随可用容器空间适配，整幅图默认可见；图例、快照年龄及长说明仍可滚动查看。远处点云不改变地图比例。

场地坐标、左下原点、车体尺寸、地图/车辆/路径/点云变换保持原有约定，鼠标坐标读数和图层开关保留。实车16段路线、离线16段运动学模拟、雷达设备规划与同一 `radar_map.c` 的离线对照继续保留。

## 常规与历史入口

- 视觉页常规标签收敛为“单件抓取”“相机调试”。旧 `material auto`、独立 Base/X 对准及旧标定收拢到默认关闭的“历史视觉诊断”，保留各自状态与停止入口。
- 明确旧 ArmVision/MaterialVision 标定使用独立模型，不会写当前 GrabTask 的响应矩阵。当前取放参数集中在参数页，旧诊断不作为单件取放的准备步骤。
- 机械臂页移除重复运动配置表单，新增通往“运动与标定”的链接；使能、状态、运动、夹爪、回零和零点操作保留。
- 底栏只保留“立即停止底盘”和“全部轴 / 关联任务停止”；任务自身停止留在对应任务区域。按钮减少不改变固件停车或停止流程。
- 兼容命令、旧视觉固件模块及 PE2 实体按键调用保持不变。保护 Emm、W25Q128、IOC 和 EIDE 配置；不连接真实串口，不烧录或操作实车。

README 以现行七页、统一参数入口和单件入仓/取出流程为准；已有历史验证与版本说明置于明确的历史范围，历史开发记录不改写。
