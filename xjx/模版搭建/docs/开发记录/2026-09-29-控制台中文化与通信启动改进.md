# 控制台中文化、通信负载与启动／断开流程改进

## 范围与保留项

按用户确认计划实施；保留已有工作区修改，修改前源码快照在 `.embeddedskills/backups/console-plan-20260929.zip`。不修改芯片、时钟、引脚、下载配置，不发送实车指令或烧录。

## 结果与原因

1. 网页显示层翻译常用设备/总线/机械臂/视觉/抓取/底盘/IMU/二维码回复，未知项保留；原文解析和导出不变。统一终端、公共回复面板和抓取回复文本；`OK` 前缀不掩盖故障。视觉无效改为“当前无有效视觉数据”。终端采用单次动画帧更新，隐藏页面不积压渲染任务。
2. 连接事件和 HTTP 返回通过同一状态入口，修复重复提示；旧连接的发送 HTTP 返回不得注册成新连接的待确认命令。断开立刻进入共享 `disconnecting` 状态，禁止普通指令和重复操作。准备流程查询也要求租约所有者，取消/断开/停车释放准备，普通命令不重发。
3. scoped stop 仍发送自己的命令，以独立优先队列处理，取消未发送的普通命令。新的准备不能吞掉已排队的停止。全局停车沿用 Ctrl+C 与带 token 请求；不把抓取停止改成独立 Base/X 任务停止。
4. 停车临时采集全部四轮，直接使用 Mecanum 原始反馈和 Emm 65536 单位/圈，脱离地图单位/原点/IMU。完成/失败释放临时采集，不改写基础采集开关和选轮策略。确认结果保留在该 token 下，新运动使其失效：这是一次停止的结果，不是永久静止监视。
5. 固件按停车状态变化主动上报（含 token）。桥接匹配确认后立即关闭串口，兼容旧固件保留 2 秒查询，6 秒失败兜底和停止锁不变。确认仅指四轮，不表示机械臂全轴已停稳。
6. USART1 DMA 参数、512 字节环形缓冲和 TX 32/30 不变。抓取同阶段 1000 ms 报告，阶段变化走回复队列，手动完整查询；停止期间拒绝新调试/遥测样本并取消旧槽，在途整行或 JSON 继续完整发送。
7. 关闭正常启动的 W25Q128 六次 ID 调试，保留默认关闭编译开关。OLED 初始化改为延后首次 I/O；主循环统一排除回零、机械臂/视觉/抓取/路线、停车、恢复和电机事务。保留顺序回零及驱动等待；IMU 已验证时复用原有准备流程。
