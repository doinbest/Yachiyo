# 蓝黑主题修正与停止入口分析

用户反馈：蓝色之外保留黑色，不要白色背景；询问底部停止按钮是否仍有用。修改前工作区干净，基线提交为 `fa78ce0`。

## 主题修正

控制台只提供蓝色与黑色两种背景，默认蓝色。顶部按钮显示“切换黑色”或“切换蓝色”，选择保存在浏览器；旧 `dark=false` 浅色偏好映射为黑色。页面初始 HTML 与 CSS 也使用深色，避免初始化前出现白色背景。主题切换保留参数草稿和其它本地设置，不发送设备命令。

本轮只修改网页主题和现行说明，没有修改停止按钮、固件或硬件配置。

## 停止按钮核查

五个按钮都有仍可达的处理，但在抓取任务运行时存在重叠。

| 底部按钮 | 当前实际作用 |
|---|---|
| 立即停止底盘 | 共享服务先发送 Ctrl+C，再发送带 token 的 `chassis stop` 并查询停车结果。固件取消自动任务、请求 ID 8 停止并请求底盘停车；反馈确认针对底盘。仅手动机械臂运动、各任务空闲时，不广播停止机械臂。 |
| 全部轴 / 关联任务停止 | `stop all`；抓取运行时取消整个抓取/组合流程并停止 ID 8。任务空闲时停止 ID 8 并广播机械臂总线停止，适用于手动轴运动。旧视觉任务运行时先停止对应生产者。 |
| 独立 Base/X 对准停止 | `vision stop`；用于“标定与分步测试”的独立 Base/X 对准。新抓取运行时转为取消当前抓取。 |
| 抓取 / 协同对准停止 | `grab stop`；用于现行固定抓取、协同对准、视觉抓取和单件取放，也取消组合抓取路线。 |
| 物料任务停止 | `material stop`；用于仍保留的“旧版对准调试”。新抓取运行时转为取消当前抓取。 |

依据：`index.html` 的底部命令绑定、`app.mjs` 的共享停车入口和视觉子页、`serial_bridge.py` 的停车事务，以及固件 `ArmConsole_StopRequest`、抓取停止分发、`ArmVision_Stop`、`MaterialVision_Stop`。

建议底部常驻保留“立即停止底盘”和“全部轴 / 关联任务停止”，后三个使用各自功能页现有入口，减少每页重复按钮。前两个覆盖范围不同，不能简单只保留红色按钮。本轮用户只要求分析，暂不调整停止布局或取消任何功能。
