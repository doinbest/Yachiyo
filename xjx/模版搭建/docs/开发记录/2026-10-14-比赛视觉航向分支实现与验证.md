## 当前行为

比赛页新增独立的“视觉航向矫正”：默认关闭，开始成功受理后锁定；草稿、重连及暂停继续不改变本轮值。关闭不请求0D、不进入新等待。开启后在加工/暂存进站中心以及每次换环停车、完整Base+128°作业姿态完成后核验；原料、扫码、已保存加工X/Z之后及最终下降不插入核验。

未标定时收集三个不同本地接收时刻的有效三环报文，显示“未标定 · 仅观测，沿用原航向”，不更新地图、不转车。没有观测时沿用原`vision_wait_ms`等待窗口（默认12000 ms）重获，窗口结束显示未取得观测，保留原任务。没有合格定位或停车证据时继续等待，不将缺反馈当成功。

协议仍为`FF B2 0D FF`请求、14字节回复。Camera独立发布有符号EX/EY/EA/STOP；普通DX/DY消费者拿不到姿态数据。STOP参与校验与可选日志，不参与控制、稳定、完成或失败；Valid=0全零不算对正。原`vision.py`与新文件均保留，未改算法、未切换启动入口、未部署香橙派。

## 标定后的控制路径与边界

原始图像角经过对应工位实测零点/比例转换成车体相对标准方向的偏角。主循环一次同步motion、localization、observer的地图角与轮积分基线，保留原始IMU展开值、X/Y、起点、定位generation和库存；额外记录航向revision。加工目标仍180°、暂存仍90°，后续路线继承新映射。

必要精调按绝对目标转向，再停稳重取视觉；重复快照不重复累加。视觉精调单独采用实测完成容差，普通路线仍使用现有容差。仿真暴露小角度比例输出被整数RPM归零的问题，因此仅精调在正常启动斜坡结束后使用最小1 RPM等效角速度，持续IMU核验，到角仍停车并以新鲜反馈确认。

参数统一在`grab_parameters.def`维护，经原`grab get/set`及参数页读写，全部无实测默认值，复位为未标定：

| 参数 | 含义 |
|---|---|
| head_proc_zero / head_temp_zero | 对应工位真实标准朝向下的图像零角，° |
| head_proc_gain / head_temp_gain | 车体偏角/图像角的有符号比例；0不构成有效标定 |
| head_tol | 实测可达到的完成容差，°，与目标零偏角分开 |
| head_spread | 多帧车体偏角最大波动范围，° |
| head_settle_ms | 停稳后接收隔离时间，须根据实测处理/通信延迟设定 |
| head_proc_turn / head_temp_turn | 两方向及全部使用环位已验证的可转范围，±°；未设置禁止新自动转向 |

目前只实现局部零点/比例映射；若透视、环位或距离变化使同一配置不能达到要求，应保留观测模式并重新做标定模型，不能猜比例。观察姿态固定复用当前X收回、Z行驶抬升高度、Base+128°；相关原点及X/Z尺度/观察位置改变会作废对应航向增益，Base降级参考只观测。普通暂停/停止不清空有效配置。

当前工程没有实测完整车体包络和统一扫掠检查。可转范围是必须通过实际工位几何验证后填写的适用范围，不是自动计算的避障证明；不填时可观测/校正地图，但发现需真实转车就保留阶段等待，不自动猜退出路线。这一限制不影响未标定观测模式。

报文没有远端请求号、图像序号或拍摄时间。本地请求批次/接收序号仅防重复消费，不能严格证明远端帧新鲜。切目标清本地缓冲，运动/恢复后重新采集静止窗口；重复发0D不会重置视觉端稳定窗口。尚未实测延迟时不会启用自动映射。

## 命令与状态

`vlow`表示lowered加视觉航向分支，`vhigh`表示raised加分支；只改变比赛ASCII命令末尾token，视觉B2报文不变。原lowered/raised显式命令保持关闭。省略新选项也关闭航向分支，高度默认遵循当前比赛代码。

比赛状态增加`visual_heading=on|off`、`heading_result`、`heading_image`、`heading_error`。图像角可在未标定时显示，车体误差未标定为nan。设备采用值与网页草稿分开。原始像素日志将0D标为POSE，防止EA/STOP伪装成DX/DY。
