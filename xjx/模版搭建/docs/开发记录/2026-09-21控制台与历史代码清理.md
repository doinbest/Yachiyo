# 2026-09-21 控制台与历史代码清理

## 目标与实际范围

按用户确认的清理计划，将现行入口统一为 STM32 `template/`、香橙派 `orange_pi/change.py` 和 `upper-computer-web/local-car/`。用户负责需求、建议、关键取舍与实物验收，Codex 负责全部设计、编码、集成、软件验证和文档；该长期规则已写入根 AGENTS.md。

本次没有修改运动控制算法、引脚、时钟或通信参数，没有连接串口、烧录、复位或发送实车指令。未操作远端站点；原有未跟踪的串口抓包记录、截图及 `.embeddedskills/backups/` 保留。历史源码依赖 Git 追溯，没有向活动工程复制备份。

## 接口与文档调整

- 删除 `Camera_RingTypeDef`、`Camera_RingStart`、`ArmVision_CalibrationStart`、`ArmVision_RingStart` 和 B3 专用枚举项。`ARM_VISION_JOB_PICK_MATERIAL` 与 `ARM_VISION_CALIBRATION_MATERIAL` 显式保留数值 2，B2 的 `material` 文本保持不变，历史来源索引 1 留作 reserved。
- 控制台仍返回 `ERR Unsupported B3`；测试覆盖 `vision calib 1`、`vision ring 1`、`camera ring 1` 被拒绝且不触发相机或电机调用。
- `tests/run_firmware_tests.py` 不再调用退役 CRC 工具测试；其余有效用例保留，视觉测试增加现行编号及来源文本检查。
- 根 README 改为使用入口；AGENTS 更新授权、主动改进和开源借鉴规则；开发规范同步协作方式。
- 控制台 README 改为操作手册，明确网页 COM23 默认与 CMD `--serial-port`、工具配置的区别；不把软件默认端口当现场识别。
- [现行协议](../上位机协议.md)集中描述 ASCII、B2 边界、二维码、遥测和停车；旧 `#` 格式迁至[历史网页协议](历史Zigbee网页原型协议.md)。旧 IMU、CRC 和迁移记录增加状态提示，保留当时事实。
