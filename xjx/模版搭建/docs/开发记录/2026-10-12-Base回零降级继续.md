# Base 回零降级继续

用户确认 Base 实际已基本达到预期车仓方向，但驱动经常报告回零失败；比赛中整段退出的代价高于少量角度误差。本次授权加入近似参考降级继续，保留故障记录与真正的驱动保护处理。

## 行为

- `grab_parameters.def` 新增 RAM 参数 `base_home_degrade`，默认 1；0 保留严格模式。网页参数调试的“运动与标定”可显式设置、读回。停止保留，复位恢复默认。
- 仅 Base 本次 HOME 失败可进入降级验证，X/Z 不变。必须编码器/校准就绪、HOME 已结束且无过温/过流；新鲜位置稳定、电机使能、无瞬时堵转或堵转保护，连续两轮实际 0x35 转速 0 RPM 才接受当前位置为近似后向参考。短时变化等待恢复，不重发 HOME。
- 机械臂新增只读 `MechanicalArm_SpeedRead`，使用现有 ARM 总线所有者与官方 Emm `S_VEL` 封装，解析带方向实际 RPM，不复用命令 SpeedRpm。
- 降级时若失能，补发一次 ENABLE 前也读取实际零速；使能后重新验证位置、状态及转速。正常回零的既有使能恢复流程保留。
- 继续启动 IMU 验证，或完成手动 Base 近零参考验证后继续已请求的姿态准备。`home_complete_degraded` 区别于正常回零完成；普通任务及追踪状态持续报告 `base_home_degraded=1`，网页正常状态也显示。
- 原始失败标志保留在 `OK grab home_degraded ... failed_home_flags=...`。停止保留已接受的参考与策略；改变相关原点或正常回零重新建立时清除降级标志。Base 两次位置差窗口 5°不表示真实零点误差 5°以内。
- 严格模式失败或降级验证超时后，本次 Base 失败且 X/Z 已验证可显式 `grab home accept`。网页“视觉任务 → 回零与通信恢复”提供“确认 Base 近似参考并继续”。只重新读取 Base 反馈，不重发 HOME/X/Z，也不自动重启已取消的姿态；仍须满足停稳和健康状态。HOME 中断可能清除驱动失败位，显式接受依然标记近似参考。
- 保留过温/过流、编码器/校准异常、堵转保护、读回失败、人工停止及原有60秒回零/5秒退出上限。实际转速非零或HOME仍运行不会建立参考。

## 误差与边界

近似参考基于用户确认“已基本回到预期车仓方向”的实物条件，不能通过停稳读数证明距离驱动保存零点很近。Base +128°作业与默认−128°回仓会带入参考误差；不改变 ID8 仓位、底盘航向、驱动机械零点或多圈计数。未新增上电持久化参考。P001手动Base移动造成视觉参考失效仍暂缓。
