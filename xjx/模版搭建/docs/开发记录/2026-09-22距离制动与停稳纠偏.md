# 距离制动与停稳纠偏（2026-09-22）

## 原因与修改
原距离控制仅按剩余误差比例算速度，再作加减速限制，没有预留制动距离。到点后停止判定又要求始终处于10mm半径内；停车期间滑出范围会被报告为stop_unconfirmed。

新增速度包络，满足 v*T + v²/(2a) <= 剩余可用距离。T包含250ms响应预留及四轮位置/速度样本最大年龄；测量车速高于命令斜坡时额外保留距离。原始反馈轮速先按电机安装方向归一化。Kp从1.0改为1.5；软件加减速度保持100mm/s²，末端50mm期望速度上限20mm/s，仍经过原加减速约束。

物理停稳独立验证（新鲜四轮反馈、轮速≤1RPM、位置变化≤2mm、至少3组且持续500ms）。停稳且位置超差≤100mm、航向仍合格时，最多两次20mm/s低速纠偏。保留原任务ID、总超时和所有运动门槛；取消不会触发纠偏。超差过大、航向不合格或纠偏耗尽：position_not_reached，停车确认保持true。没有停稳证据才为stop_unconfirmed。路线在纠偏期间不得进入下一段；网页区分低速纠偏与已停稳但未到位。

## 1m/s验证边界
可设上限仍1000mm/s。按100mm/s²加减速，从静止到1m/s再停车至少需要10m，尚未计响应余量，因此最长1.75m固定路线不能达到实际1m/s。没有擅自把实车制动能力当作更高数值；后续需测量可可靠跟随的加速度和停车距离，再调整软件参数。

动态主机模型：100ms采样、100/200ms反馈延迟、120ms电机一阶响应，使用生产控制代码及真实轮向。14m软件直线峰值1000mm/s，最终约差-7.6mm，无过冲/反向；1750mm峰值约403mm/s；900mm峰值284mm/s；212mm峰值128mm/s。额外施加25mm位移后触发低速纠偏，最大反向约19mm/s，最终误差约6.2mm。模型不是实车证明，未覆盖轮胎打滑与未测得的电机负载极限。
