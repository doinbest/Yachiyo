# 车载取放口 X 默认 100 mm

用户指定 `x_car` 为 10 cm，即相对 X 回零原点的绝对位置 `100 mm`。本次只修改该固件默认值，不改雷达、网页、通信节奏或 Base 回零流程。

## 原因与修改

此前 `GrabTask_Init()` 将 `x_car` 留为未设置；启动回零又清除 X 相关参考，而 X 回零成功后只恢复尺度、行程和预伸位置，未恢复车载取放口位置。因此复位或回零后会报告缺少 `x_car`。

- 在 `Code/template/App/mechanical_arm_config.h` 集中定义 `MECHANICAL_ARM_CAR_X_DEFAULT_MM=100.0f`。
- 在 `GrabTask_Init()` 和 X 回零反馈验证成功的分支恢复该值；100 mm 位于现有 X 默认行程 `[0,100] mm` 内，不扩大行程。
- `grab set x_car ...` 仍只改 RAM，普通停止保留调参值，复位或验证回零后恢复固件默认；手动改变 X 原点仍使相关参考失效。
- 保留现有驱动故障处理；日志中的 Base `home_flags=0x0B` / `home_driver_fault` 为独立问题，不能通过补齐 `x_car` 消除。
