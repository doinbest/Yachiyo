# 开局余弦提速与入弯减速 Implementation Plan

> **后续取舍覆盖原几何约束：** 用户查看动画后确认先改路线。当前改为右通道(2125,350)→(2100,950)，600 mm分散转向，开局上限200 mm/s；详见[本次记录](../../开发记录/2026-10-14-开局右通道长距离转向.md)。下文保留原提速设计供后续接续，其中“保留旧内凹几何”和无固定弯道上限已不适用于当前测试版；接近段余弦与非零入弯余弦制动尚未执行，不得将下列任务全标为完成。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 保持现有开局几何与扫码朝向，解除斜移段的固定低速限制，提前减速入弯，连续出弯加速。

**Architecture:** 在共享路径中区分开局类型，在底盘运动控制器内完成速度规划。斜移和出弯直线复用K=200余弦过渡，入弯速度由后续路径的转向需求决定；比赛状态机仍只在二维码终点交接停车与扫码。

**Tech Stack:** STM32F407、C、现有HAL/Keil工程、C主机运动仿真、Node网页路线测试。

**Spec:** [比赛与取放约定](../../比赛与取放约定.md)中的路线要求及用户本轮确认的下列流程。状态：已制定计划，以下代码工作均待实施；本轮不编译、不烧录。

## 置顶：本次修改的关键点

**第一优先：斜移段不能因为后面有弯道而全程限制为60 mm/s。第二优先：必须按距离提前减速，不能到弯道入口才突然降速。**

| 顺序 | 动作 | 速度规划与衔接要求 |
|---|---|---|
| 1 | 从右下起点出发，保持180°斜移 | K=200，名义400 ms余弦过渡；以用户路线速度为上限，短距离降低峰值，不强求达到1000 mm/s |
| 2 | 接近弯道，仍保持180° | 根据剩余弧长、反馈延迟和后续转向需求，提前减到可跟随的非零入弯速度 |
| 3 | 连续移动并顺时针转至90° | 弯内按角速度、路径航向变化率和实际航向跟随误差限速，取消开局弯道统一60 mm/s限制 |
| 4 | 从弯道接入二维码直线 | 继承当前运动速度，余弦加速；不清零速度，不重新从静止起步 |
| 5 | 到达二维码位置 | 保留终点位置、航向、新鲜停稳反馈与扫码姿态检查 |

## Global Constraints

- 本次仅优化正式比赛右下标准开局（路径kind=1）；物料台进站kind=2/3、右上起点、绕障接驳与独立测试保持现有行为。
- 保持当前源码几何：(2250,150,180°) → (2050,350,180°) → 内侧弧段 → (2050,450,90°) → 二维码终点。旧规则中的(2100,300)属于原分段通行描述，实施时统一文档适用范围，不反向改掉已实现的连续路径。
- 保留目前65%转向预算和5°开始的航向跟随降速；本次不同时扩大角速度、修改车体尺寸或加宽弯道。
- 加速、制动与完成确认分开。反馈及人工停车机制保留；暂停后从实际停稳状态重新规划，不能恢复停车前的速度命令。
- Base扫码姿态仍在车体转向完成后启动，与后续直行并行；不能因为提速提前到斜移或转弯阶段启动。
- 仅维护现有Keil Target template，保留工作区已有修改。软件仿真、编译、烧录和实车结果分别记录。

## Task 2：接近段余弦提速与距离制动

**接口边界：** 保留`ChassisMotion_PathStart`及路线调用协议。新增计算集中为`chassis_motion.c`内部静态函数；输入明确使用mm、mm/s、秒和°/s，输出为沿路径速度上限，不直接发送电机指令。

速度过渡采用：

\[
v(t)=v_0+(v_1-v_0)\frac{1-\cos(\pi t/T)}2,\quad 0\le t\le T
\]

完整过渡距离为`(v0+v1)*T/2`；已进入过渡时使用剩余积分距离。名义T=0.4 s，短接近段联合考虑加速与减速距离降低峰值。目标速度相同时不制造额外过渡或等待。

弯道基础限速沿用`0.65*最大角速度/abs(dθ/ds)`；航向不变的段不做除零计算。向前检查剩余弯段，以最紧约束和到达该约束的距离共同形成制动包络。

- [ ] 增加仿真断言：请求1000 mm/s、100°/s且反馈正常时，接近段峰值明显超过旧60限制；入弯前已完成必要降速，弯内未超当前转向预算。
- [ ] 覆盖低请求速度、低转向上限、短剩余距离、0/120/220 ms反馈延迟；先运行确认旧实现不能满足提速断言。
- [ ] 在kind=1接近段接入余弦规划，复用普通直线的反馈年龄和驱动响应余量来源；短段自动降低峰值。以路径剩余弧长规划，不用到二维码终点的直线距离代替入弯距离。
- [ ] 将kind=1目前固定150 mm/s²的平方根前瞻替换为与实际余弦过渡一致的剩余积分制动计算；非零目标速度也纳入距离预算，不能只套用“减到零”的函数。
- [ ] 分离标量速度过渡与弯内方向变化处理：接近段不能再叠加旧300 mm/s²限制而抵消K=200效果；弯内保留必要向量变化率，并将其计入可行速度。kind=2/3继续使用原控制分支。
- [ ] 保留航向跟随降速，并核查横向纠偏合入后的最终平移向量、前馈角速度和反馈纠偏之和；不能让现有`speed+20`补偿绕过弯内约束，也不能只靠最后裁剪角速度掩盖平移过快。
- [ ] 重跑同模型对比：接近段耗时下降、整个开局耗时下降；不新增超出既有终点、航向和车体外框验收阈值的问题。保存曲线与数据，不把仿真加速效果写为实测结果。
