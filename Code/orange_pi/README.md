# 香橙派视觉代码

本目录保存小车香橙派视觉代码，与 `Code/template/` 的 STM32 主车固件分别维护。

| 文件 | 用途 |
|---|---|
| `vision.py` | 用户于 2026-10-02 提供的最新视觉源码；颜色粗定位、色环精定位及 USB CDC B2 通信 |

2026-10-02 已按用户要求用最新 `vision.py` 替换旧 `change.py`、`test_connect.py`。源码从用户提供文件原样复制，未修改识别算法。此次为本地源码更新，未上传或启动香橙派程序。2026-09-30 关于旧 `change.py` 并非实机入口的说明属于历史状态，不再作为当前源码入口。

程序请求 V4L2 + MJPG，默认 640×480、120 FPS；采集线程只保留最新帧。收到 `FF B2 Color FF` 后开始识别，粗定位双轴误差均在 50 像素内时切换到色环定位；圆环连续漏检 5 个处理帧后退回粗定位。发送上限默认 50 Hz，受实际采集和处理速度限制；未识别时直接发送 `Valid=0`。B2 不包含检测阶段、采集时间或远端帧序号。

入口为 `python3 vision.py --usb-port <实际设备路径>`。依赖 Python 3、OpenCV、NumPy 和 pyserial；设备、相机能力及实际启动参数以实机为准。源码开头保留了原文件的旧文件名示例，实际使用本目录的 `vision.py`。

后续部署前应确认实际运行文件、相机、串口设备和依赖，不把本目录文件自动上传或启动。通信约定见 [B2 兼容恢复记录](../../docs/开发记录/2026-09-29-B2协议兼容恢复.md)；整体入口见 [项目 README](../../README.md)。

本轮 `align` / `pick` 流程、次数限制及比赛场景容错建议见 [分析记录](../../docs/开发记录/2026-10-02-视觉源码更新与align-pick容错分析.md)。STM32 行为本轮未修改。
