# 香橙派视觉代码

本目录当前入口为 `vision.py`，2026-10-07 已用用户提供的 `Final.py` 原样替换。颜色粗定位/色环精定位保留，新增按中央数字选择1、2、3号同心圆。该次替换只更新本地项目；实机当前程序与部署状态须按现场核对，不能由本地源码推定。

启动：`python3 vision.py --usb-port <实际设备路径>`。依赖 Python 3、OpenCV、NumPy、pyserial；数字圆检测使用 `cv2.HOUGH_GRADIENT_ALT`。默认请求 V4L2/MJPG、640×480、120 FPS，实际能力以相机为准。采集线程仅保留最新帧，发送上限50 Hz，实际频率受检测耗时影响。

| USB CDC请求 | 目标 |
|---|---|
| `FF B2 01 FF`～`FF B2 06 FF` | 红、黄、蓝、绿、黑、浅蓝 |
| `FF B2 0A FF` | 中央数字1的同心圆 |
| `FF B2 0B FF` | 中央数字2的同心圆 |
| `FF B2 0C FF` | 中央数字3的同心圆 |

返回仍为14字节 `FF B2 Command Valid CX_H CX_L CY_H CY_L DX_H DX_L DY_H DY_L SUM FE`，目标字节回显请求。2026-10-08起准心分开：物料颜色默认(334,338)，用 `--center-x/--center-y` 修改；编号环默认(378,333)，用 `--ring-center-x/--ring-center-y` 修改。两类参数互不覆盖，DX=CX−对应准心X、DY=对应准心Y−CY。STM32编号环对准固定使用(378,333)，物料保留原ref_u/ref_v配置；修改视觉启动参数须同步对应类别的STM32参考。没有检测到目标时发送Valid=0及零坐标，协议不包含采集时间、置信度或远端帧序号。2026-10-08准心更新为本地源码修改，当时未远程部署；实机状态单独核对。

**当前STM32源码已接入0A～0C**：仅识别使用 `camera ring <1|2|3>`，静态对准统一使用 `grab align ring <1|2|3> [z_mm] [stay]`，旧 `grab ring align` 保留兼容。视觉任务页分别提供环号选择；对准后的人工装料/Z放置流程保留。新版固件与视觉程序均部署后方可实测。

数字模式每帧检测多重同心圆，再以合成字体模板/HOG识别中央数字，要求至少3个不同半径的圆，圆心组距离阈值12像素；数字置信阈值0.50，类别差阈值0.015。默认半径18～65像素，最大组半径25～65像素，需要用实际观察高度验证。物料遮挡数字后可能漏检，不能把持续编号识别当作已完成定位的唯一依据。
