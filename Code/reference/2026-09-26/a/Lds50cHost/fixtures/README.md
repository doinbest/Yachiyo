# LDS-50C 原始数据夹具

此目录预留真实雷达串口捕获文件。目前没有可验证来源的真实整圈数据，因此仓库不伪造“实测”文件；协议测试使用代码确定性生成的 `CE FA`、`CF FA`、状态和报警帧。

录制硬件数据时：

1. 从串口直接保存原始字节，不要保存十六进制文本、截图或已经转换的坐标。
2. 至少包含第一圈同步数据和随后一整圈，使扫描组装器能观察到两次角度回绕。
3. 文件名建议为 `lds50c-2_20260927_500000_10hz.bin`。
4. 在同名 `.md` 中记录型号、固件、波特率、转速、角分辨率、能量/滤波/去拖点状态、目标布置和是否脱敏。
5. 不要记录设备序列号等不必要标识；提交前确认捕获中没有其他串口设备数据。
6. 新增文件后增加回归测试，断言整圈成功、点数合理、错误计数为 0，并选取若干已知角度/距离点校验。
