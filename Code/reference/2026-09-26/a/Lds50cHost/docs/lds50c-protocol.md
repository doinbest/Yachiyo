# LDS-50C-2/-3 串口与数据协议

本文记录本项目实际解析的协议。字节序除单字节字段外均为小端：低字节在前。

## 串口

- UART 3.3 V，8N1，无硬件流控。
- LDS-50C-2：384000、500000、768000、921600。
- LDS-50C-3：500000、768000、921600。
- 默认建议从 500000 开始；必须与雷达当前保存值一致。

## 控制指令

控制指令为 ASCII，无 CR/LF：

| 指令 | 作用 |
|---|---|
| `LSTARH` | 开始旋转 |
| `LSTOPH` | 停止旋转 |
| `LMEASH` | 固定测距 |
| `LRESTH` | 重启 |
| `LVERSH` | 获取版本 |
| `LUUIDH` | 获取序列号 |
| `LNCONH` / `LOCONH` | 关闭 / 开启能量等级 |
| `LSSS1H` / `LSSS0H` | 开启 / 关闭前端滤波 |
| `LFFF1H` / `LFFF0H` | 开启 / 关闭去拖点 |
| `LSRPM:xxxH` | 设置转速 |
| `LSERR:xxH` | 设置距离偏置；出厂已校准，不应随意修改 |

本软件的一次扫描流程只自动使用 `LSTARH` 和 `LSTOPH`。

## 普通测量帧 `CE FA`

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 2 | 帧头 `CE FA` |
| 2 | 2 | 本包点数 `N` |
| 4 | 2 | 起始角度，单位 0.1° |
| 6 | `3 × N` | 每点：能量 `uint8`，距离 `uint16` mm |
| `6 + 3N` | 2 | 16 位校验和 |

帧长为 `8 + 3N` 字节。校验为 `N + 起始角度 + 每个点的能量 + 每个点的距离` 的低 16 位；帧头不参与。

普通帧本身不携带扇区终止角。程序用相邻数据包的起始角求本包角跨度，并以 `角跨度 / N` 插值得到各点角度。检测到起始角从大角度回绕到小角度后，才认为一圈边界成立；第一段不完整数据会被丢弃，第二次回绕时输出一整圈。

## 固定角分辨率测量帧 `CF FA`

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 2 | 帧头 `CF FA` |
| 2 | 2 | 本包点数 `N` |
| 4 | 2 | 起始角度，单位 0.1° |
| 6 | 2 | 扇区角度，单位 0.1° |
| 8 | `3 × N` | 每点：能量 `uint8`，距离 `uint16` mm |
| `8 + 3N` | 2 | 16 位校验和 |

帧长为 `10 + 3N` 字节。校验还要加上扇区角度。固定分辨率包将扇区首尾都视为采样边界；`N > 1` 时点间隔为 `扇区角度 / (N - 1)`。

## 状态帧

固定 8 字节：`53 54 flags r0 r1 r2 45 44`，即 `ST....ED`。

`flags` 低四位：

- bit 0：0 为 cm，1 为 mm；本项目预期 mm。
- bit 1：能量输出开关。
- bit 2：去拖点开关。
- bit 3：前端滤波开关。

## 报警帧

固定 6 字节：`CE CE CE CE codeLo codeHi`。`code` 为小端 16 位报警码。程序会把报警码写入运行日志，但不会把报警字节当测量点。

## 容错与诊断

解析器可接收任意切片的串口数据，包括一次一个字节；会在噪声后重新同步到下一个已知帧头。界面显示：

- 有效帧：成功解析的数据、状态、报警帧总数。
- 校验错误：测量帧校验和不匹配。
- 长度错误：点数超上限或状态帧尾无效。
- 丢弃字节：同步噪声和损坏帧字节。

点数上限为 4096，用于避免损坏长度字段导致无界等待或内存占用。
