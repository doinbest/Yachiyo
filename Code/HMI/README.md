# 串口屏配置

| 文件 | 用途 |
|---|---|
| `display.HMI` | 串口屏软件的可编辑工程入口 |
| `任务码大字.zi` | 任务码显示字库资源 |
| `统计文字.zi` | 统计信息显示字库资源 |

用对应串口屏编辑软件打开 `display.HMI`，字库与工程保留在同目录；编译和下载按实际屏幕型号与软件配置执行。本次目录整理没有重新编译或下载屏幕工程。

主车通过 USART3 PD8/PD9 与屏幕通信。固件驱动在 [tjc_screen.c](../template/Hardware/tjc_screen.c)，页面显示业务在 [contest_screen.c](../template/App/contest_screen.c)。修改页名、控件名或显示格式时，两端一起核对。

任务码适配说明见 [串口屏任务码显示记录](../../docs/开发记录/2026-09-23串口屏任务码显示适配.md)。整体入口见 [项目 README](../../README.md)。
