# F407主车固件

linear单段测试支持独立起步加速度与停车减速度，各10～5000 mm/s²；网页初值500/300，参数受理后锁定，只覆盖本次独立动作。旧指令只给一个加速度时仍同时用于加、减速；固件省略参数与普通MoveTo保留300/300；正式linear比赛按路段分配起步500/800/1000，停车减速度300。制动包络用停车减速度，速度矢量减少当前平移动量时用减速度、增加时用起步加速度；前进与后退一致。普通linear直线到点进入位置/航向窗口后，先让平移参考按减速度降至零，再请求同步零速及真实停车确认；人工停止、取消和故障仍立即请求停车，原地转向和连续路径主体沿用独立控制。cosine保持K200，航向默认P0.1/D0。

底盘控制计算目标周期为1 ms；直线平移曲线更新周期默认1 ms，独立单段测试可在上位机填写1～100 ms整数。曲线周期只决定平移速度参考（含位置收敛、制动包络及加减速限制）的更新时间，中间复用最近参考；坐标系转换、按新鲜IMU更新的航向纠偏、四轮分配和到点/停车检查仍按控制循环执行。1 ms与1 ms时同频；例如曲线5 ms时，中间控制循环复用平移参考。参数受理后锁定，仅覆盖本次独立测试，后续普通任务恢复默认1 ms；原地转向、连续路径仍用各自控制。控制周期是主循环调度目标，不保证硬实时1 ms、IMU每1 ms出新样本或串口四轮批次每1 ms生效；同值去重、最新待发目标替换、同步批次及反馈组调度保留，不补发历史积压。

直线平移航向保持默认单P：P=0.1（rad/s每度误差）、I=0、D=0，输出限幅保留±0.50 rad/s。普通直线平移及定时heading/hold航向保持采用±0.1°纠偏死区（比较含0.0001°浮点容差）：误差绝对值≤0.1°时P、D输出均为0，并重置测量角速度历史；超出后按原误差恢复控制。该死区不作用于原地转向、视觉精确转向或视觉坐标对准；视觉校正保留原有精度、观测有效性和新鲜停稳判定。新鲜IMU样本更新航向纠偏，重复样本保持上次输出；测量转速滤波代码保留，但D=0时不参与输出。原地转向仍用独立P=0.02及原速度/起停控制，连续弯道控制不变；正式linear比赛按路段分配，普通MoveTo保留300/300，cosine保持K200；独立单段测试可按次填写线性加速度或余弦K及航向P、D，受理时锁定，不覆盖其他任务。本版采用P0.1/D0，软件通过不代替各方向、载料及整场实车验收。 当前分段参数与验证见[正式比赛速度分配](../../docs/开发记录/2026-10-16-正式比赛速度分配.md)。

电机总线短时接收噪声优先恢复RX并输出警告，未收到真实应答仍按原期限处理，不重复HOME/运动。非比赛通信锁定自动停止并尝试恢复；恢复内通信抖动间隔2秒重试，人工停止可取消。四轮零速写入均确认后，单独同步被拒绝只记警告，仍须验证真实停稳。恢复通信不表示中断的回零已完成；参考未验证时需重新回零。比赛沿原暂停/恢复进度处理。

比赛视觉航向开启时，每次进入加工区或暂存区仅启动一次航向观测：加工区两批及暂存区第一批使用色环B2/0D，暂存区第二批码垛使用色环前方黑线B2/0E；同次访问的换环、逐件放置和加工取回不重复。第二批再次进站重新观测。每件色环/物料位置对准保留；暂停、继续与总线恢复续接当前阶段，未完成观测可继续取证，独立航向测试不变。

航向采样使用独立5秒窗口，从机构停稳、开始请求时计时；漏检、USB重试及采样组重置不延长截止时间。允许间断有效帧累计，至少3个不同序号且接收时刻递增的新鲜样本；最后一帧必须新鲜。已标定使用head_spread比较换算后的角度，未标定/独立观测使用图像角最大差0.3°并取三帧平均值；不凭未标定图像角自动更新地图。无效/缺失帧不清空已有有效样本，不一致则重建采样组；机构运动后旧样本作废。5秒内证据不足报告heading_no_observation并沿用原航向继续。尚未成功提交的校准也受该截止时间约束；已采用校准或开始转向后仍完成运动和停稳验证，不以采样超时跳过。人工暂停后重新给予观测窗口，普通物料视觉等待参数不变。

X/Z固定目标动作使用当前轴配置的驱动加速度档位，默认X20、Z255；场景速度和有限绝对终点保持，MCU不再周期重发余弦调速。视觉连续纠偏、渐进下降、回零、Base和ID8沿用各自控制。到位按9F/实际反馈后备处理，机械限位、驱动故障和人工停车确认保留；Z先抬到0再收X，取仓避让X30 mm并行规则不变。详见[机械臂协议](../../docs/协议/机械臂与取放.md)。

## 按需求定位

正式比赛加工进站为(1200,380)到点转至180°后视觉接管，删除固定125 mm贴近；同次工位作业保存首次成功对准的实际底盘XY及环号，后续按环距150 mm保留位置偏移换环，每件仍重新视觉确认，加工取回顺序不变。中心到暂存区在中心停车，按较小转角选0°倒车或180°前进至(425,1200)，停车转90°作业朝向，保留最后75 mm低速接近。暂停/恢复保留工位锚点，再次进站重建；无需网页写入新参数，预览共用固件C核心。

底盘直线平移提供linear与cosine两种模式：linear为默认，普通MoveTo加减速度300 mm/s²，正式比赛按路段起步500/800/1000、停车300 mm/s²；cosine为K=200、名义400 ms半余弦速度过渡，短段降低峰值；余弦保留半余弦起步与距离制动参考，位置P收敛按反馈和驱动响应时间降低有效增益；同一平移段保留已观测的最大反馈年龄作为制动预算，避免新反馈突然放宽限速。反馈引起的速度矢量变化受该段曲线峰值加速度约束，末端接近速度按到点窗口和延迟进一步限速，避免目标前提前归零后反复补走。两者都计入反馈年龄和驱动响应的制动余量，共用1000 mm/s路线默认速度、工位局部限速、位置/航向及新鲜停稳判定。除线性模式恢复分段开局外，其他连续转弯和原地转向保持现行独立控制。驱动档位仍为0，位置与停稳确认独立。余弦模式正式右下开局采用共享 `chassis_path.h` 的右通道曲线：保持180°到(2125,350)，600 mm内转至(2100,950,90°)后直行；开局上限200 mm/s，保留原前瞻、向量变化率和航向限速。第一批从右侧保持90°横移到物料台中间(1200,2100)，到点停稳后原地顺时针转90°至0°；第二批中央进站曲线保留。余弦模式开局接近段尚未改为余弦控制。线性模式的正式右下标准开局恢复分段路线：(2250,150,180°)保持朝向斜移到(2100,300)，新鲜反馈确认停稳后顺时针原地转到90°，再直行至本轮二维码纵坐标；各平移段同时受本轮路线速度上限与分段参数限制：起步短斜移500/停车300、速度300，扫码直线起步1000/停车300、速度上限1000，不套连续弯道200 mm/s上限。转向停稳后才准备Base扫码姿态，并可与后续直行并行。余弦模式保留右通道连续开局；右上起点、右上角至物料台、第二批进站、非标准绕障和独立二维码测试保持各自现行路线。详见[比赛与取放约定](../../docs/比赛与取放约定.md)。

普通雷达扫描统一为15个有效完整圈；`radar scan lower 15` 采集并规划，`radar live map start lower` 持续更新最近15圈，`radar stop` 停止采集。下方默认情况二 `(2280,314)` 和精确Q16标定；车体起点为 `(2250,150,-180°)`，工位、首段接驳和取放流程保留。上方独立雷达安装为 `(2050,2250,270°)`，与右上车辆名义起点 `(2250,2250)` 分开，不套用下方矩阵。稳定点XY是独立结果，原始点云仅来自最后一圈诊断。

## 统一比赛入口

2026-10-13增加[比赛动作连续衔接](../../docs/开发记录/2026-10-13-比赛动作连续衔接.md)：末件入仓直接结束在行驶姿态，实时X/Z避让完成后重叠Base与底盘平移，复用进站姿态；路线busy保存原目标重试，相容共线纯途经点合并。串口入口不变，主机回归与实车验证分别记录。

车仓选仓共用`Turntable_Index()`：1号仓执行ID8单圈就近回零，2/3号仓按最短方向定位。仓1按回零完成、新鲜位置稳定及零速/使能反馈确认后继续，不依赖普通位置到位标志；不清库存或重建机械臂参考。入仓、取出和比赛流程同时适用，参见[实施记录](../../docs/开发记录/2026-10-13-车仓1号采用就近回零.md)。实现与各次下载证据见开发记录，车仓实物验收另记。

`grab mission qr [speed] [turn_deg_s] [lower|upper] [fixed|radar] [lowered|raised] [linear|cosine]` 或 `grab mission fixed <code> [speed] [turn_deg_s] [lower|upper] [fixed|radar] [lowered|raised] [linear|cosine]`，省略选项默认路线1000 mm/s、linear300 mm/s²、转向100°/s、右下、固定路线、raised（Z=0高位对准）；低位对照须显式指定lowered。两种来源都真实扫码，屏幕只显示实际码，采用码独立冻结。`grab mission pause`及`grab stop`暂停，`grab mission stop`终止，`grab mission continue`停稳后续接；终止停车未确认时不能新开比赛。完整字段、取放和恢复见[现行约定](../../docs/比赛与取放约定.md)及[协议](../../docs/协议/机械臂与取放.md)，软件、烧录和实车结果分别记录。

加工区第三件取回入仓采用ID8直接270°避让、Z提起到位后回180°，回转可与Base并行；角度随仓3配置计算，暂停保留目标。见[实施记录](../../docs/开发记录/2026-10-14-加工第三件车仓避让.md)。后续编译及DAP烧录校验已通过，实车验证另记。
