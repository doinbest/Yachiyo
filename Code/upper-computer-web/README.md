# 八千代·巡航本地控制台

当前唯一控制台入口为 [local-car/README.md](local-car/README.md)。

Windows 双击本目录的 **启动控制台.lnk**，即可启动服务并自动打开网页；服务窗口初始最小化，无需手动打开 CMD。重复双击时复用已运行的默认端口服务，不重复启动或连接串口。需要 Python 3 和 pyserial。

快捷方式指向当前电脑的项目路径；移动项目后需重新设置目标为 `local-car/start.cmd`。也可直接双击该脚本，或运行 `python local-car/serve.py`。网页地址为 `http://127.0.0.1:8765/`。

使用期间保留最小化的服务窗口。退出服务时先在网页停止任务并断开串口，再还原服务窗口输入 `quit`；仅关闭网页不会退出服务。

旧 React/Vinext 原型及其 `sys.ping#`、`motor.*#` 协议已退役，不再使用 `npm run dev`。本地控制台无需 npm 安装或云部署；Node.js 仅用于网页回归测试。

2026-09-21 清理仅涉及本地仓库，未操作远端站点。旧实现可通过 Git 历史追溯。
