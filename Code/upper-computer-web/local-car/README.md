# 八千代·巡航本地控制台

界面默认使用粉色主题（深粉背景、浅粉高亮），可切换黑色背景；原蓝色主题偏好自动采用粉色。物料颜色及地图数据图例保留实际含义。
本地Python串口服务与浏览器操作台，共享F407 USART1无线链路；网页提供任务操作、参数读回、地图和诊断。串口命令与完成语义见[协议索引](../../../docs/上位机协议.md)。

## 启动与连接

系统与标定页新增“电机只读诊断”，默认选择ID5 Base；可读实际相电流、供电电压、位置误差、驱动回零参数及电流上限。也可手动发送 `bus read 5 current|voltage|error|home|driver`，其中竖线表示任选一项。需新固件、重启更新后的本地服务并刷新网页；任务空闲时读取，停车锁定期间允许，读取不修改驱动参数。

1. 安装Python 3和pyserial；缺少时执行 `python -m pip install pyserial`。
2. 双击本目录 `start.cmd` 或上一级 `启动控制台.lnk`，也可在本目录运行 `python serve.py`。
3. 用Chrome/Edge访问 `http://127.0.0.1:8765/`，刷新串口列表，人工选择实际设备并连接，默认115200/8N1。

服务只监听回环地址，无需npm安装或云部署；不要直接双击HTML。启动不自动连串口，页面切换、刷新和重连不发送运动或雷达启动命令。快捷方式移动项目后须调整路径。退出服务前停止任务并确认反馈，再断开串口；服务终端输入 `quit`。

## 操作入口

比赛转向速度的网页输入范围为5～500°/s，默认100；底盘“平移与转向测试”和“持续速度控制”允许输入±500°/s。此为上位机输入上限：当前固件比赛/定时转向仍限制100°/s，持续速度控制仍限制360°/s，超限命令会被设备拒绝。更新后刷新网页即可加载；视觉航向单次试转保留原低速范围。

“机械臂与夹爪 → 夹爪舵机”保留打开2500 μs、夹取1920 μs两个默认按钮，新增500～2500 μs自定义输入，点击“应用脉宽”才改变当前开口。输入、刷新、切页与重连不动作；测试值不覆盖自动任务默认。网页换算后使用现有`grip duty`指令，现有固件可用，无需为此新增指令或重新烧录；刷新网页加载本次界面即可。

车仓取料实测开口2120 μs，自定义输入预填此值；自动流程在ID8/Base到位后输出2120 μs，等待1秒下降，已闭爪续接不重新开爪。源码、设备版本及实物效果分别核对，软件与烧录证据见[10月14日记录](../../../docs/开发记录/2026-10-14-统一DXDY与物料台一次横移.md)。手动自定义输出不改变自动默认。

“机械臂与夹爪”提供PD12 / TD-8125MG雷达盘控制：实测转出扫描2450 μs、收回车内1450 μs两个按钮，保留手动脉宽输入和查询；旧五档快捷值与停止PWM已删除。需新固件、重启本地服务并刷新网页。详见[转出与收回](docs/地图与雷达.md#雷达盘转出与收回)。

`accepted`或串口写出不代表动作完成；停车请求与反馈停稳分别显示。网页断开也不证明车辆停车。表单预填、本机保存和MCU读回不同；网页不会因重连自动写参数或续跑。

ASCII命令最多95字节、10个空白分隔字段。比赛启动末尾可选linear或cosine；省略为linear300 mm/s²，cosine为K200（400 ms）。比赛受理后锁定，暂停与恢复保留；设备采用模式以读回为准。配套更新固件、退出重启本地Python服务并刷新网页，才能使用完整长命令。省略对准方式时默认高位对准。

进入“视觉任务 → 比赛任务”分别选择执行码来源、起点、雷达、工位对准高度和底盘加减速模式后开始。两种来源都真实扫码，屏幕只显示实际码；“暂停比赛”保留进度，需明确继续，“停止比赛”结束本轮并撤销续接，单项入口保留。当前需求见[比赛与取放约定](../../../docs/比赛与取放约定.md)，软件与下载见[10月14日记录](../../../docs/开发记录/2026-10-14-统一DXDY与物料台一次横移.md)及[编号环版本记录](../../../docs/开发记录/2026-10-14-编号环对准高度与抬升选择.md)；自动入仓及完整两批实车验收另记。

准备抓取姿态被拒绝时，在“视觉任务 → 物料取放”点击准备按钮旁的“读取抓取任务状态”，再用“查看抓取任务状态反馈 →”跳到原因与诊断；顶部同名按钮也可查询。详见[视觉任务](docs/视觉任务.md#动态追踪与夹取)。

2026-10-12停车修复涉及网页、本地Python服务和STM32固件。软件更新后退出旧服务再启动，刷新网页并重新选择串口；固件需单独烧录后生效。全局停车覆盖手动机械臂位置运动，单轴停止可抢占ACK等待；服务端拒绝停车前的迟到动作和不匹配当前停车编号的解除请求。操作与恢复见[连接与恢复](docs/连接与恢复.md)。

## 开发与验证

`app.mjs`组织界面，`protocol.mjs`定义命令，`parameter-schema.mjs`及相关模块管理参数；`serve.py`/`serial_bridge.py`管理共享服务及串口队列。雷达主流程在实车监控：采集15有效完整圈，或持续更新最近15圈；下方默认情况2安装，保留车体与工位坐标。稳定XY、安装/仿射/窗口均按设备冻结结果显示和导出，雷达建图页通过F407主机接口提供原始最后圈、preview120及完整诊断对照。停止采集、取消下载与取消路线是独立操作；本机保存不发设备，重连不续采。两页均连接当前正式F407固件、共用F407 C算法；f1_host为历史协议名称，前期F1源码保存在reference中。保留的直连雷达模块只供独立诊断。

抓取参数默认值/范围由[grab_parameters.def](../../template/App/grab_parameters.def)维护，仓库根运行 `python Code/tools/sync_grab_parameters.py`生成网页元数据。不要手写第二套默认值。

仓库根运行相关检查：

```powershell
node --test Code/upper-computer-web/local-car/tests/*.test.mjs
python -m unittest discover -s Code/upper-computer-web/local-car/tests -p 'test*.py'
```

测试使用FakeSerial/内存流，不连接实车发送模拟运动。部署及实车验收按当时记录单独判断。历史变化见[开发记录](../../../docs/开发记录/README.md)和[整理前手册](../../../docs/开发记录/2026-10-09-文档整理前快照/原控制台手册.md)。
