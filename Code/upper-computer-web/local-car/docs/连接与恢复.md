# 连接、停车与故障恢复

## 中文提示与原始报文

终端默认使用“中文摘要”，任务状态、标定原因、追踪及路线反馈也显示中文。Base、X、Z、USB、IMU、ID、DX/DY、RPM及单位保留；电机应答超时、反馈过期、参考缺失、请求拒绝等原因使用中文解释。更新网页后刷新即可，本次显示调整不需要烧录固件。

例如 `ERR grab stack rejected; inspect grab status` 显示“码垛请求被拒绝；请读取抓取任务状态”，并不据此猜测具体拒绝原因；`transfer_off_pose` 显示“Base已转离观察姿态”，不表示参考已经失效。停止未确认表示缺少停稳证明，不能等同于机构仍在运动或停车成功。

“原始报文”、日志导出和本地串口捕获保留英文协议及实际数值。尚未收录的原因保留原始代码供排查；翻译不会改变命令、参数、任务状态、停车或恢复条件。

## 串口与服务

先启动本地服务，再刷新设备列表、人工选择实际端口，默认115200/8N1；只有一个端口也不自动选择。COM编号可能因USB位置变化，工具配置和网页选择分别核对。CMD ports只枚举；connect COM7中的COM7仅示例，启动参数显式指定端口才允许无参数connect。

启动/刷新/重连不启动运动，不重放旧命令或自动写参数。更新网页后刷新；更新服务端代码须退出旧服务再启动、重新选择串口。关闭网页不停止服务也不证明停车；退出服务前先在网页停止任务并确认反馈，再断开连接、CMD输入quit。

HTTP头及响应体默认12秒期限，超时退出忙状态，结果未确认，不自动重发运动命令。离线C规划请求保留50秒预算（编译30秒、运行15秒）；服务不可用先看服务终端，串口占用释放其他程序。

## 停车与恢复

accepted只表示受理，TX只表示实际写出；请求停车、发送完成与stop_confirmed分开显示。网页停止锁定限制新运动，允许grab route/mission status等只读查询；解除锁定或重连不自动续跑。

bus recover沿用逐ID1～8停车、排空与健康检查；四轮同步缓存锁定还核验同步零速批次与反馈，禁止广播触发ID5～8。成功保留参数/参考/预算，不自动续跑。chassis reset-confirmed仅确认驱动已经实际复位，不复位硬件、不强制解锁。状态读bus status、info和对应轴诊断，故障报告区分共享总线与运动隔离。

上电HOME未受理的HAL_BUSY按原100 ms准入轮询重试，已受理HOME不重发；每轴60秒窗口不变。home_pending表示回零未完成，不是用户漏设尺度；home_request_failed/home_bus_fault与驱动回零故障分别解释。0x3A状态不能替代0x3B回零证明。

UART5首次发送尝试前、无活动事务的单独FE可清残片并重启接收；失败或首次发送后仍按实际故障隔离，不用例外掩盖DMA/覆盖错误。info保留首次原因、恢复次数和时刻；owner=8/addr=0/func=0是无历史事务，不是ID8转盘。

TTL多机接线已出现未供电驱动支路引发FE的实测，测试机械臂时保持总线上驱动上电；确需分开供电时在全断电后隔离未供电TX/RX支路并正确共地。详见[锁定诊断](../../../../docs/开发记录/2026-09-27-UART5首次锁定诊断.md)。

## 参数、参考与IMU

普通停止/总线恢复/网页重连保留有效RAM配置、参考与库存。真实原点或模型适用性变化处理对应局部范围；P001手动Base参考失效仍暂缓，见[问题清单](../../../../docs/待解决问题.md)。参数缺项、参考失效和通信错误分别处理，不用填写参数绕过未验证回零。

IMU上电等待新鲜数据，归零并做一次5秒静止验证；失败可显式重新验证。原生标定为手动20秒加30秒验证。已验证资格遇短暂失联暂停，通信恢复并连续两帧新鲜数据恢复，不重置原点或自动续跑；失败/取消仍需验证。不要把角度恢复当作完整定位验收。

## 日志与验证

终端可过滤/导出，默认精简重复抓取状态，关键变化/错误/手动查询仍显示；偏好只影响显示，不发设备命令。原始TX/RX在仓库 `.embeddedskills/logs/serial/`，清日志不清任务/地图。追踪实时与冻结记录见[B2/追踪协议](../../../../docs/协议/视觉B2与动态追踪.md)。

诊断模拟用真实网页处理函数和FakeSerial，不连接实车发送模拟运动。烧录后提醒重开香橙派程序，再测试视觉；本地源码、MCU烧录、远端Pi部署和实车通过分别记录。协议错误字段见[系统协议](../../../../docs/协议/系统与底盘.md)及[机械臂协议](../../../../docs/协议/机械臂与取放.md)。
