# 地图、雷达与路线操作

正式current和F1主机f1_host是两个独立工作剖面。扫描/读图/规划不启动底盘，网页预演只播放F407同C核心的动作；实车执行须明确点击对应运动入口。协议字段见[雷达协议](../../../../docs/协议/雷达.md)和[底盘协议](../../../../docs/协议/系统与底盘.md)。

## 正式实车监控

正式地图左下原点，X向右、Y向上；标准下方(2250,150,180°)，上方(2250,2250,270°)。物理场地0～2400 mm，现行5×5判障内缩为[150,550,1000,1400,1850,2250]，地图g:3，外围150 mm不参与扫描判障。筛选0～360°、100～40000 mm、能量0～255、每格阈值1；人工mask与任务保护分别处理，原始counts/evidence保留。

1. 人工连接实际串口，读回RAM安装/筛选参数；选择地图角落与0°方向并显式应用，不随底盘反馈隐式改安装。
2. 点击扫描3圈并规划（radar scan lower|upper 3），整车静止，三次有效完整圈障碍取并集；坏帧/缺包只重采当前圈，在原10秒窗口继续。
3. 完整同圈地图与路径收齐一起显示；下载/失败时保留历史快照，区分来源与年龄，点云仅按需诊断读取。
4. 本机检查/播放绕障预演不运动。固定路线按钮执行固定路线，不等于预演；实车雷达执行用radar nav start/task start，完整绕障与净空仍需实测。

备用已验证位置复制F1(230,230)时用T(x,y)=(2400-y,x)转换为(2170,230,180°)，读RAM后只写差异，不覆盖标准生产默认、不复制备用任务/网格。此转换只在导入入口使用；已返回current地图不再旋转。g:2旧图保留其全场网格，旧图不套新边界或新安装。

## F1主机雷达页

页面#map/radar共享USART1/DL-20的115200链路；雷达USART2为921600。默认F1坐标(230,230)、固定mask0x00050140、保护mask0x00404405、任务1-5-4-2-3-4-2-3-1，不与正式安装混用。导航/刷新/重连/保存不自动启动扫描。

单次扫描采完整圈，持续扫描每完整圈用全部原始点判障和规划；120分区仅预览。结果请求连续回传冻结地图/路径，end报告页数，仅补缺页，同圈收齐后ACK；每4次不同结果ACK发一圈预览，结果请求可抢占预览。live_id非零且stop/start不复用，迟到旧圈不能混入新结果；真实重复页冲突和CRC仍校验。

改筛选/分区时有完整同圈缓存才重建，不重新启动采集；没有完整缓存的停止圈不能冒充同圈重筛选。MCU配置只在RAM，网页本机配置只有显式保存才写本机。未读回显示待同步/—，不是0点或不可达。

## 实时点云与诊断

正式radar live start upper|lower用独立120分区预览，不改完成地图/规划/完整云；stop停止采集但保留旧图。只用最新完整圈整体刷新，不发送半圈。它与单圈建图/原始诊断互斥，不等于F1持续建图。

radar debug scan按需记录解析前USART2原始字节及冻结参数；raw分页CRC、下载完整性和设备有效完整圈证明分别校验，失败可导出部分证据，不套历史云。radar fetch evidence按需取缺包/逐格来源证据，不加入正常结果下载。radar probe用LUUIDH查询身份，不转雷达、不改参数或地图；必须新鲜PRODUCT SN与MCU发送完成共同证明往返，回显/报警不独立证明。

第一阶段USB-UART直连模块保留独立诊断，当前#map/radar不使用它。雷达供电、USART2交叉连接与共地按实物资料核对，不根据无身份应答直接断言供电故障。

## 路线与遥测

固定15业务目标默认200 mm/s、距离加减速300 mm/s²，转向上限100°/s。右下首腿(2250,150)→(2100,300)→(2100,1200)，中间通行点不触发工位；路线交接按station/visit，不能按绕行后变化的路点序号。

长段先转向再前后走；暂存(425,1200)接驳转向，最后75 mm限速≤min(启动速度,50)。固定路线和后向两批任务朝向分别按对应profile/任务定义，不用一套工位朝向覆盖所有模式。auto到位停稳后直接推进，附加停留0 ms；start完成业务目标后人工next。

网页角速度为°/s，run/遥测为rad/s；底盘平移测试合速度≤300 mm/s。紫色轨迹为反馈估计，橙色为指令推算，不等于实测精确定位；车身外框/动画不能证明真实净空。遥测开启由用户显式操作，重连/重启后不自动开启，旧位置保留过期标记。

历史16段离线时间示意与实车15业务目标路线独立；雷达建图与离线对照共用F407 radar_map/radar_start/radar_plan，不再实现另一套规划算法。SLAM/运行中雷达定位闭环未实现；详细历史与现场证据见[开发记录](../../../../docs/开发记录/README.md)。
