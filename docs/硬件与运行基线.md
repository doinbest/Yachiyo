现行资料更新日期：2026-10-12。本文件集中保存用户已确认条件和协议事实；确认值、源码当前实现与设备RAM读回分别判断，几何精度和整场比赛成功仍须实测。操作流程见[控制台](../Code/upper-computer-web/local-car/README.md)，修改边界见[AGENTS](../AGENTS.md)。

## 主车接线

| 接口 | 引脚 | 用途 |
|---|---|---|
| USART1 | PA9/PA10 | 无线ASCII文本控制台，115200/8N1 |
| USART2 | PA2/PA3 | LDS50C，921600/8N1，DMA1 Stream5/Channel4循环接收 |
| USART3 | PD8/PD9 | 串口屏 |
| UART4 | PC10/PC11 | 二维码 |
| UART5 | PC12/PD2 | 共享步进电机总线 |
| USB CDC | PA11/PA12 | 香橙派B2视觉 |
| I2C1 | PB6/PB7 | OLED |
| I2C2 | PB10/PB11 | HWT101，仅Z角度，SDA=PB11 |
| TIM1_CH1 | PE9 | 夹爪舵机，50 Hz PWM |

电机ID1/2/3/4为左前/左后/右后/右前，5 Base、6 Z、7 X、8车载三仓盘。车载盘与电机1∶1直连；独立F103物料台转盘另见[模块说明](../Code/物料台转盘/README.md)。CAN1/CAN2当前停用；板卡引脚、供电和探针以实际资料为准，不套用其他F407板卡。

## Emm与机械事实

- 2026-10-12用户再次确认夹爪当前脉宽：打开/待机2500 µs（12.5%），夹取1920 µs（`grip duty 9.6`）。舵机曾重新安装，方向与最早结构相反；当前固件、网页及OLED按这组值使用。TIM1保持50 Hz，取放阶段等待时间保持原值。
- 用户已确认使用张大头Emm42固件，只修改电机ID，其余驱动设置默认。位置命令在1.8°、16细分下为3200命令脉冲/电机轴圈；0x36反馈为65536协议单位/电机轴圈，不能互换。手册依据为[ZDT_X42S V1.0.5](硬件资料/执行机构/闭环步进电机/ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527.pdf) Emm章节第57、72页；这些是协议事实，不要求重新进行65536单位选择实验。
- UART5普通事务按匹配Receive应答推进，完整应答后保留2 ms非阻塞交接；四轮同步批次保持原子性。紧急FE/9C按TX完成推进，保留TX后2 ms停车链。实测依据见[连续入仓记录](开发记录/2026-10-07-UART5应答交接间隔与入仓连续循环实测修复.md)，不恢复旧10/80/100 ms固定门槛。
- Base物理回零朝后，任务保存实际多圈锚点；用户确认128°是此前实测用于侧方对正料盘或色环的Base准备转角，动态追踪准备以此为准，并衔接既有路线各工位的车体转向。Base机构转角与地图yaw分开，不能由该值改写底盘路线航向。当前共用准备入口使用回零锚点+128°，Base回零位置就是朝向车仓；作业返回车仓默认偏转−128°。ID8仓1/2/3的0°/−90°/−180°仅属于转盘，与Base机构角度独立。任务转向按2°临时业务容差、新鲜反馈和停稳确认；2～5°残差以≤15 RPM重发原绝对目标，不用实车异常的FD模式2相对补偿；X/Z下降到位条件仍独立。
- X向外为正，Z向上为正。当前Z普通位置运动默认500 RPM、加速度档位120；驱动回零方向/速度由其O_Dir/O_Vel管理。任务阶段速度和驱动加速度档位、MCU加速度分别管理。
- 旧结构历史值：夹爪松开500 µs、完全抓紧700 µs，来自舵机重装前的实测，仅用于后续结构修改时对照，不作为当前控制值。结构再次改变时按实际安装重新核对开合位置。OLED Servo Test页PE2/PE3选择脉宽、PE5开关输出、PE4退出；仅进入页面不驱动舵机。
- 2026-10-11用户确认上电夹爪为空、各机构同时运动无机械干涉；2026-10-12补充Base承载整套机械臂、负载较大，要求其余回零完成后再回零Base。现行顺序为上电/复位等待1秒，Z/X碰撞回零与ID8就近回零先并行；Z/X均通过新鲜回零、稳定位置和使能验证，ID8回零建立参考后，才使能并启动Base就近回零。全部完成后才进行IMU静止5秒验证。回零结束短暂未使能复查600 ms，位置稳定且无驱动故障才补一次使能，1500 ms内复核；人工停止中断已启动但尚未验证完成的回零，取消未启动待办，不再恢复。`grab rehome`先并行Z/X、验证后再回零Base，不重放已经完成的上电ID8动作；单轴命令保留，不改变驱动器存储参数或电机ID。
- ID8机械零点由首次失能对齐、使能、保存建立；上电/复位自动就近回零一次，与Z/X回零并行，反馈成功后建立第一仓RAM参考；ID8与Z/X均完成后才启动Base回零。2026-10-12用户再次确认回零对应仓1；相对仓1的角度为仓1=0°、仓2=−90°、仓3=−180°，不再要求重新实物标定。当前 `turntable.c` 的仓2/3默认仍为 `NAN`（未配置，查询显示unset）；使用这版固件时须将已确认值写入对应RAM参数并读回，复位后仍恢复未配置。停止或显式人工操作取消尚未启动的自动待办，不在总线恢复后重放；手动`turntable home`保留。上电库存待人工核对，回零不自动改空仓。
- 底盘配置中的轮径80 mm、约210/240 mm轮心间距及传动关系以源码与实测记录核对，轮子/IMU位置估计不能当作已消除滑移误差。

## 坐标与参数寿命

- 正式地图左下为原点，X向右、Y向上，yaw从+X逆时针；历史F1参考仅导入时用 `T(x,y)=(2400-y,x)`，不再旋转已验证的底盘、IMU或电机方向。
- 右下车体中心为(2250,150)，车头朝左−180°，朝物料加工区域方向；+180°与之同向，现有网页准备命令仍使用+180°表示。固定路线、雷达路线与右下二维码测试保持该朝向斜移到(2100,300)，再原地顺时针转到90°进入右侧通道；绕障保留规划入口点。
- 2026-10-11用户确认实车雷达只有两种起点安装：右下0°向左180°、右上0°向下270°，方向不再由网页选择。右下默认采用所提供新版F1的(2280,314)与精确标定；2026-10-12用户确认右上采用(2050,2250)，与车辆名义起点(2250,2250)分开，几何精度仍按实测核验。精确XY可分别填写应用；F1原参考情况1(230,230)只供历史参考文件解释，不作实车安装选择。
- 固定路线默认200 mm/s、距离加减速300 mm/s²、转向上限100°/s。网页角速度显示/输入为°/s，底层run与遥测为rad/s；路线阶段、正式/F1判障边界见[地图与雷达](../Code/upper-computer-web/local-car/docs/地图与雷达.md)。
- HWT101只使用Z轴原生角度；上电等新鲜数据后归零并做一次5秒静止验证，失败不自动反复重试。原生标定手动20秒加30秒验证，不使用退役软件漂移补偿/外部Flash方案。已验证状态在短暂失联后恢复通信、连续两帧新鲜数据可恢复资格，不重置原点或自动重启已停止任务。
- `grab set`、轴 `config`及转盘配置主要为MCU RAM，复位恢复固件默认；普通停止保留有效值。网页本机保存与MCU RAM分开，未实现这些参数的Flash持久化。默认值统一见[grab_parameters.def](../Code/template/App/grab_parameters.def)，不在多份手册复制整表。
- 物料视觉默认准心(372,345)，动态追踪和专用码垛对准直接使用B2的DX/DY，后续准心由视觉端管理；旧静态颜色对准ref_u/ref_v仍默认(334,338)，编号环准心(378,333)独立。码垛专用CX+39/CY+1补偿不写回准心，也不是39/1 mm。固件默认值、设备RAM与香橙派实际部署分别核对。手动Base参考失效P001仍[暂缓处理](待解决问题.md)，不把文档整理当作修复授权。
- 香橙派当前实机程序已修改，启动与运行不再完全依赖USB-TypeC连接成功；2026-10-12用户确认STM32烧录后无需重开程序。本地源码、远端部署和实车验证分别记录，仓库版本差异见[香橙派说明](../Code/orange_pi/README.md)。

雷达原始数据、网页预览和正式地图的用途分开；扫描/规划不启动运动，旧完整地图及本地历史图保留来源与年龄。已确认的规则不等于整车验收完成，详细来源保留在[开发记录](开发记录/README.md)。
