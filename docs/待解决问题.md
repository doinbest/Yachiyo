## P001 · 手动 Base 转动清空物料视觉参考点和矩阵

**当前决定：** 2026-10-08 用户要求先记录，暂不修改此逻辑；后续再决定是否处理。

### 现象与影响

手动执行 Base 位置运动后，物料视觉参数 `ref_u,ref_v,j00,j01,j02,j10,j11,j12` 被清空。即使机械臂已回到作业朝向，静止对准仍可能报 `config_missing`，动态追踪诊断可能显示 `model=unset`，增加重复设置参数的操作。

2026-10-08 串口实测回复包含：

```text
reason=config_missing missing=ref_u,ref_v,j00,j01,j02,j10,j11,j12 ref_cause=manual_base_move
```

### 已确认原因

源码 [GrabTask.c](../Code/template/App/GrabTask.c) 的 `GrabTask_MotorEventHandle` 对任务之外已发送的 Base 位置运动调用 `GrabTask_ReferenceInvalidate(MECHANICAL_ARM_AXIS_BASE)`；该函数把物料参考点和六项矩阵参数设为 `NAN`。当前处理直接删除参数值，没有单独管理矩阵对当前姿态的适用性。

Base 姿态改变可能影响底盘运动与图像位移的对应关系；这与是否应删除参数值是两个不同问题，后续需要分别评估。

### 本次临时恢复与验证

在 Base 约 89°的当前作业姿态，恢复物料默认参考点 `(334,338)`，矩阵两行为 `[2,0,0]`、`[0,2,2]`。这只是恢复 RAM 参数，没有修改固件清空逻辑或烧录。

执行 `grab start align 3` 后，蓝色物料误差从约 `(8,-87)` 收敛到 `(0,-4)` px，进入 `hold` 且停车确认完成；随后 `grab stop` 返回空闲、停车确认完成。该结果只证明本轮静止对准通过，不代表动态追踪启动问题已解决。

原始证据保存在本机 `.embeddedskills/tests/static-blue-precheck-20261008.json`、`static-blue-config-20261008.json` 和 `static-blue-align-run-20261008.json`；这些文件是本地诊断产物，不保证随仓库提交。

### 候选处理方向（未实施）

- 核对回到已验证作业姿态后的恢复条件，复用实际角度、静止反馈和既有业务容差。
- 静止对准与动态追踪统一使用姿态及参数适用性判断。
- 普通停止、网页重连不清除有效参数；真实原点或模型适用条件变化时，处理对应范围。

若用户决定实施，验证手动转动后返回作业姿态、停下再启动、网页重连以及不同 Base 姿态的参数适用性；同时覆盖静止对准和动态追踪。编号环独立参考点 `(378,333)` 与物料参考点分别维护。

## P002 · IMU短暂异常导致地图锚点及原点丢失

**当前状态：** IMU原生标定审查发现的既有集成问题；本轮只审查及同步文档，未修改固件、烧录或进行实车测试。

已成功验证、建立地图定位后，一次I2C错误或数据过期使 `HWT101_Cal_ControlAngleGet` 暂时返回false。`chassis_motion.c` 的 `heading_read` 直接调用 `ChassisMotion_AnchorInvalidate`，清除 `map_anchor_valid`；`chassis_localization.c` 随即清除 `origin_valid`。IMU按连续两帧规则恢复资格后，只有 `heading_valid` 恢复，地图锚点、原点与定位反馈仍无效，影响地图路线继续。此行为不符合短暂异常保留有效定位的现行要求；原生标定、显式归零或重新验证真正改变模块原点时，旧定位失效仍应保留。

主机复现使用真实底盘运动与定位源码，注入标定资格暂不可用及恢复，输出为：

```text
before: heading=1 anchor=1 origin=1 feedback=1
outage: heading=0 anchor=0 origin=0 feedback=0
recovered qualification: heading=1 anchor=0 origin=0 feedback=0
```

候选修复方向：区分暂时缺数据与模块原点真正改变，短暂缺数据暂停使用并保留映射及位置；恢复时重新取得有效反馈，不能自动续跑已停止任务。已出发比赛不得以重设名义起点规避。修复需覆盖短暂通信故障、恢复期间新增故障、角度跨±180°、显式标定/归零及暂停续接。

复现源文件和日志在 `.embeddedskills/tests/imu-native-review-20261015/`；完整审查和验证见[IMU原生标定审查](开发记录/2026-10-15-IMU原生标定审查.md)。2026-10-07历史记录保留当时资格层修复事实，本次补充其系统集成边界。
