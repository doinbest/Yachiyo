# 实车后向机械臂任务流程实现计划

> 本轮由 Codex 在当前工作目录连续实施。已有大量暂存及未暂存修改，保留原索引，不切换工作树、不代为提交。用户的功能修改请求及 AGENTS.md 已授权常规实现，不增加逐阶段审批。

**目标：** 右下起点，机械臂物理回零朝后，按底盘与机构实际朝向组织行驶、三件入仓及后续工位交接，取消附加定时停留。

**设计依据：** 用户 2026-10-07 当次需求及补充“实物回零位置改成朝后”；既有取放接口、两批搬运顺序及 `x_car=100 mm`。俯视 Base 正方向为顺时针；回零读取的多圈实际角度作为后向锚点，外侧作业为锚点 +90°，车载方向为锚点 −90°。不把就近回零当作数字零。

**范围与约束：** 独立新任务入口，保留原模拟扫码首件测试与纯底盘路线。新任务二维码点先通过，不启动扫描或 Z 搜码。原料车头 0°、粗加工 180°、暂存 90°，此时 +90°机械臂均面向相应工位。X/Z先退让再转 Base；反馈确认后推进，不用 ACK 或固定秒数代替完成。复用 B2、单件取放、三仓库存及已有到位判据。缺少实物编号关系时先完成独立部分，不猜三仓分度或圆环对应。IOC、EIDE、官方 Emm 与 Flash 驱动不在修改范围；不连接、烧录或发送运动命令。

## 实施步骤

- [x] 路线：增加共享 C 任务姿态路线，首段保留右下斜移接直行；到上方拐角先保持90°左移，工位前采用现有75mm接驳尺度安排作业转向。为新任务提供所有工位的交接/续跑。附加 dwell 取消，真实停车反馈保留。测试正常推进、工位暂停、绕行路点及取消。
- [x] 机构：保存已验证的后向回零实际角度；增加后向/外侧作业姿态动作与结果，保留有效视觉参数。在 X 收回、Z抬起后转向；原料三次取放均回到同一外侧锚点，车载口100mm，角度不累积。测试非数字零、停机、参考失效及三次返回。
- [x] 调度：新入口经过二维码不读码，原料按本次任务码三色依次入仓；按工位/visit交接，不依赖绕行点序号。后续两批流程按既有思路与实物编号关系推进。状态说明当前动作、批次、物料、原因。

## 验证关注

1. 后向物理回零可以对应任意多圈计数；不得发送 ZERO 或反复 HOME。
2. Base转向中暂时离开视觉观察姿态，只暂停适用性，回到同一外侧锚点恢复，不清除有效模型。
3. 三件颜色与仓位有记录，未释放入仓不离站；普通取消保留已完成进度及有效参数。
4. 工位到点确认和机构动作结束共同决定续跑，不靠100ms/2s占位。
5. 雷达绕行保留实际路点，姿态接驳的新增实际线段需核对障碍，不使旧纯底盘接口隐式驱动机械臂。
