# 开局与物料台连续转弯 Implementation Plan

> 执行方式：当前会话内联实施；按项目规则，必要验证、编译及烧录后交付，全面审查另轮执行。

**Goal:** 正式比赛右下开局边移边转到90°，两批物料台进站边移边转到0°，不在这些转弯中途停车。

**Architecture:** 共用C路径给出内侧绕弯位置及随路径变化的朝向。底盘沿同一运动任务跟随路径，末端才确认停车；暂停保存路径进度。离线预演使用同一C路径。

**Tech Stack:** STM32F407、C99、Keil、现有JS控制台与主机测试。

**Spec:** 用户本轮确认整车按300×300 mm、允许向路口内侧偏移50～100 mm；工位终点不变。需求优先于文档中旧的斜移后原地转向。

## 约束与验证关注

- 保持300×300 mm完整车框在通道联合区域及启停区内；不以轮距代替车框。
- 沿用轮径、现有运动学参数与速度配置；转弯速度受角速度限制和反馈跟随约束。
- QR姿态及工位姿态只在车体转弯完成后开始，最终工位交接等待到位。
- 暂停/恢复不重走曲线，人工停止与反馈故障响应保留。
- 非标准绕障接驳、右上开局和独立二维码测试不套用固定曲线。
