# 比赛动作省时与默认速度1000 Implementation Plan

> **For agentic workers:** 使用superpowers:executing-plans在当前工作区逐项实施，保留已有修改。交付后按AGENTS约定独立审查。

**Goal:** 减少已到位机构的重复动作和验证，缩短夹爪等待，默认路线速度1000 mm/s。

**Architecture:** 复用现有GrabTask及比赛调度，只在新鲜静止证据成立时省去无位移的位置命令。保持串口停车、暂停及绝对目标语义；默认值仍由现有定义维护。

**Tech Stack:** STM32F407 HAL / Keil C、原生主机回归、JavaScript控制台。

**Spec:** 用户本轮批准上述省时结论，明确加工区取回顺序不改；随后确认Z仍抬到绝对0才收X。闭爪、松爪、车仓取料准备等待分别改300 ms；默认路线速度1000 mm/s，工位局部50 mm/s上限保留。

## Global Constraints

- 不改变加工三件全部放完再按原顺序取回、颜色与仓位映射。
- 不提前收X、不新增起点移动转向复合轨迹；保留车仓30 mm避让、加工第三件ID8避让及汇合条件。
- 已到位跳过只用于固定转移/姿态；视觉纠偏与下降释放仍发送原目标。
- 暂停、反馈失效、驱动异常或轴运动后不可使用旧证据跳过动作。
- 旧网页保存的显式路线速度保留；新安装及未指定指令默认1000。

## Review Focus

- 同位置但仍在运动/反馈过期必须重新控制和核验。
- 闭爪、释放及取仓等待独立；暂停继续不重复闭爪或释放记账。
- 已经就绪姿态可交接，偏离姿态必须补齐原动作。
- 新参数网页读写与固件元数据一致，不自动写设备。
- 三件取回顺序、局部限速与避让条件不被提速修改。
