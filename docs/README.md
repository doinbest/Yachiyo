## 分类约定

- `硬件资料/执行机构/`：电机、驱动器、舵机和机械执行部件资料。
- `硬件资料/传感器/`：传感器模块的说明书和通信协议。
- `硬件资料/通信与电源/`：CAN、串口、无线、电源及保护电路资料。
- `主控与开发板/`：STM32、开发板、下载调试器和板卡原理图资料。
- `开发规范/`：本项目形成的代码风格、接口约定、调试流程和 AI 协作提示词。
- `开发记录/`：每轮实际代码改动、构建结果、上板步骤、失败原因和后续门禁。
- `赛事资料/`：竞赛命题、评分规则、宣讲资料以及由原文整理出的设计指导。

ST 官方资料保留原始 PDF 内容，仅使用中文文件名补充文档编号和用途；对应的官方来源链接可从 ST 的 [STM32F407/417 文档页](https://www.st.com/en/microcontrollers-microprocessors/stm32f407-417/documentation.html) 获取。

新增资料时优先放入对应分类，并在本文件补充一行用途说明。
