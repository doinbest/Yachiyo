# 准备状态与1米每秒上限

用户截图中实车第一段到点并确认停止，网页却显示起点失效。根因是ready状态持续套用原起点坐标与路线空闲检查，正常出发也触发取消提示。

新增consumed准备终态：收到路线运行/等待受理回复，或同会话有效遥测报告已进入路线段后，显示“已进入实车路线”，停止原起点检查。准备阶段与出发前检查仍保留，串口断开重置准备；consumed不表示路线完成，实际进度由路线反馈显示。

用户要求速度达到1m/s，本次放宽可设定上限至1000mm/s。默认50，最低10，轮速上限从100改为400RPM。当前名义80mm轮径、传动比1，直行1000mm/s约239RPM，等模长斜行最高约338RPM，另有航向修正余量。未更改轮径/传动比、角速度上限、驱动器参数、加速度和距离控制增益。短路线受加减速与到点控制影响，不保证实测达到1m/s。

实车路线扩展为与离线默认路线停点一致的16段，返回(2250,150)。新增chassis route auto [速度]；确认停止后等待1秒自动提交下一段，末段等待后结束。手动start/next保留。自动模式拒绝next；反馈失效、总线故障或取消时不再续跑。不执行扫码、视觉和抓放。最长1750mm段在最低10mm/s下的超时按原公式扩展，上限400秒。
