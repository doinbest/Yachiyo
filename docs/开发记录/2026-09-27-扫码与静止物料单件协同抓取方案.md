## 1. 已确认需求和本轮验收范围

## 2. 路线、扫码和显示

当前路径前四段为 `(2100,300)` → `(2100,1200)` → `(2100,2100)` → `(1200,2100)`，航向90度。结合现有地图，扫码站位于第2段，原料台位于第4段。任务点序号不能直接当作路线段号。

建议增加独立“两站单件抓取测试”入口，复用16段路径中的前四段及已经验证的运动控制。原有纯路线测试仍作为独立入口。测试开始由用户在上位机显式触发。

### 扫码站

1. 第2段结束，沿用原有到点与停车反馈判据。
2. 从停车确认后计时1000 ms，主循环继续运行，不能阻塞串口、电机反馈和显示处理。
3. 计时结束，载入同一份完整任务码并明确来源为“模拟扫码”。任务调度、OLED、串口屏和上位机都读取该任务数据；不伪造UART4收到真实二维码的统计。
4. 串口屏上行显示 `156+123+`，下行显示 `516+231`，抓取/放置数初始为0。等两行发送完成后再推进第3段；发送完成与屏幕实际显示正确分别验收。若传输失败，停留并报告，不带着旧显示继续。
5. 当前屏幕每100 ms最多发送一个字段，显示发送可能让站点总停留略长于1秒；1秒指模拟扫码等待，不是全部站点动作的严格总时长。

### 当前必须处理的接入问题

- `QR_Init()`清空RAM缓存；没有当前任务码的掉电保存。测试码应作为明确的测试配置。
- `main.c`只在路线和距离任务都空闲时调用 `ContestScreen_Process()`；路线waiting也算忙，必须在扫码站允许显示刷新。
- 当前按键测试的 `Camera_ColorTaskDigitGet()`读取第二组；自动抓取应读取第一组，任务解析需统一，不能把放置编号当颜色。
- `ChassisRoute_IsBusy()`包含waiting，机械臂和物料任务会拒绝启动。需增加清晰的站点任务交接状态，释放路径运动控制权，同时禁止自动进入下一段。
- 当前自动路线一般站点等待是100 ms；扫码站的1000 ms应独立定义。

## 3. 控制方式和源码适配

### 采用的思路

借鉴参考项目持续根据视觉修改底盘和伸缩目标的方式。同一次视觉计算同时产生底盘前后、左右和X轴修正，不设置“超过15像素只让底盘动”的交接阈值。

本车建议底盘输出有限幅和加减速限制的平移速度，航向使用已有HWT101保持；X轴输出持续更新的绝对位置目标。底盘反馈用于速度限制、停车确认和工作区域约束。参考项目的OPS场地位置外环不能直接当作本车已经具备的能力。

### 坐标与控制分配

统一定义视觉误差 `e=(DX,DY)`，车身位移 `q=(前进mm,左移mm,X伸出mm)`；实际正方向与现有驱动接口在适配层对应。固定Base和车身航向，分别测量各动作产生的两个像素分量。

测得局部响应矩阵 `J=像素误差变化/机构位移`，大小为2行3列。小范围近似下，误差变化率为 `J*v`。共同控制目标为 `J*v ≈ -lambda*e`，其中lambda单位1/s。视觉尺度用于估计效果，lambda决定修正速度。

若两执行方向的响应近似共线，可以在该方向按贡献比例分配；若交叉影响显著，应按测得的响应求解两个方向的修正，不能把DX、DY机械地一对一分配给机构。可使用带权的最小位移速度解；权重使X在可用范围内多承担修正，接近边界时减少其贡献。近共线导致无法修正二维误差时，需要调整观察姿态并重新测量。

“X承担70%、底盘承担30%”仅适用于两者都能有效修正同一方向的初始分配建议，指像素修正贡献，不是原始增益比例，更不是所有姿态都适用的硬性规定。所有机构的合成修正须满足同一个总体速度要求，避免每个单轴全强度输出造成过冲。

### 时间、目标和总线

- 当前底盘批次启动间隔至少100 ms；视觉采集频率、控制计算频率、总线下发频率分别记录。
- 首轮建议以100 ms作为运动目标更新的起点，并以实际完成时间验证。只发送最新目标，不积压已经过时的位置请求。
- X目标按 `x_target += vx * dt`更新。dt使用实际时间，暂停/丢帧后不把整个停顿时间补积分；内部使用浮点或保留小数余量，在最终下发时换算整数脉冲。
- X目标受绝对机械边界约束，还要限制目标领先实际反馈位置的距离；执行器跟不上时不得继续积累远处目标。
- 必须先验证Emm驱动在运动中接受绝对位置更新的行为；软件收到ACK不等于运动完成。绝对零位置应允许表达，当前接口拒绝Position==0的条件需要区分相对零位移和绝对零目标。
- 四轮批次和同步帧保持完整，X/Z请求安排在批次间，持续保留反馈查询时间。串口传输顺序执行，电机实际运动可重叠。
- 抓取任务统一拥有执行机构，避免路线、手动控制与视觉控制同时改写目标；通过任务权限适配现有busy判断，不能简单删除所有互锁。

## 4. 首轮状态流程

| 阶段 | 动作 | 转移条件 |
|---|---|---|
| 前往扫码站 | 执行第1、2段 | 第2段到点且停车确认 |
| 模拟扫码 | 等1秒，载入并显示固定任务码 | 计时结束、任务码合法、两行发送完成 |
| 前往物料台 | 执行第3、4段 | 第4段到点且停车确认 |
| 观察准备 | Base保持，X/Z到已标定预备位置，500 us打开 | X/Z反馈到位，姿态有效 |
| 目标获取 | 请求颜色1，等待请求后的有效新帧 | 红色目标有效、数据新鲜 |
| 协同对准 | 粗定位阶段共同接近，圆心精定位阶段重新累计稳定条件 | 已确认精定位阶段，误差窗口、稳定时间、新帧数量和低速条件均满足 |
| 停止水平运动 | 底盘和X停止，继续观察 | 停车与X反馈稳定，视觉仍在窗口内 |
| Z下降 | 首轮保持水平位置，Z下降到夹持高度 | Z反馈到位，无故障 |
| 闭合 | 800 us，等待标定闭合时间 | 计时完成；只代表动作完成 |
| 抬升 | 保持夹爪闭合，Z到提起高度 | Z反馈到位 |
| 等待验收 | 保持夹持，不自动进入第5段 | 用户检查物料是否被抓牢 |

水平停止后若视觉超出窗口，回到有限次数的对准重试，不能无限往返。Z下降后的视觉误差只有在验证高度相关映射后才可用于水平修正。首轮不启用下降期间追踪；第二阶段可在已验证的间隙内重叠下降前段和小幅修正。

丢帧、目标无效、行程边界无法消除误差、反馈失效或电机故障：结束本次动作并请求相应机构停止，不继续下降、不自动续跑路线。闭合后故障默认保持夹爪和升降轴承载状态，不能用统一失能造成物料或Z轴下落。报告停止请求与反馈确认的区别。

## 5. 参数确定和测量方法

### 5.1 机械位置尺度

使用已有 `pos x/z <degree>`、`position x/z` 操作小范围运动，记录前后实际位移和反馈。控制台角度是电机轴角度，不能直接当毫米。

对每个轴记录正向和反向各3次。避开端点，在确认有余量后逐步扩大测量行程。

- 若轴角度变化为theta度、实际位移为L mm，则命令脉冲/mm = `(3200*abs(theta)/360)/abs(L)`。
- 若用反馈差n记录实际电机转动，则电机转数为 `n/65536`；命令脉冲的一圈3200与反馈一圈65536分别使用。
- 测得正反行程差异说明可能有回差，记录它，不能只取一次样本当最终换算。
- 设置可复现的零位/参考位置后，记录X/Z机械上下限；现有Z接口没有固定软件脉冲上限，新抓取任务必须按实测行程限制Z目标。

### 5.2 准心与高度

1. 转盘停住，红色物料摆在常规工位；手动把打开的夹爪调整到能下降包住物料的位置。
2. 记录夹持高度 `z_grab`；记录抬起后物料完全离开转盘所需的 `z_lift`。
3. 保持底盘和X不动，把Z抬到能稳定识别且有间隙的 `z_observe`。
4. 记录此时圆心精定位得到的目标中心 `(u_ref,v_ref)`，用作观察姿态准心。轮廓重心只用于接近。现有默认(334,338)只是待核对配置，不能用参考项目(320,230)替换。
5. 若相机随Z移动，记录观察、中间、夹持三个高度的图像变化；首轮不根据下降引起的画面变化追加水平修正。
6. 记录X观察位置 `x_pre` 和Base工作角度；首次预备动作的路径也须有间隙，不能仅检查终点。

### 5.3 三个运动方向的像素响应

保持目标、Z、Base和相机配置固定。逐个测试底盘前进、左移、X伸出，各次只动一个机构。

取运动前后的数帧有效坐标均值，记录实际位移d、DX变化、DY变化，得到每个方向的 `(deltaDX/d,deltaDY/d)`。前后必须采用同一种识别阶段，最终抓取标定用圆心精定位；不能把轮廓重心与圆心的差当成机构运动响应。反向返回再测，重复3次。小步长从有余量的范围开始；若像素变化小于噪声再适当增大，不预设所有机构都能安全移动10 mm。

标定只需覆盖本次预抓取位置附近，超出这个范围需要重新评估尺度。相机朝向、分辨率、裁剪或观察高度改变后应重新核对。

### 5.4 待调参数表

下列建议初值用于制定调试起点；测量不满足前置条件时不得直接启用运动。

| 参数 | 初始方案 | 如何确定最终值 |
|---|---|---|
| 扫码等待 | 1000 ms，已确认 | 不参与抓取调参 |
| 打开/闭合脉宽 | 500/800 us，已确认 | 带物料检查，不增加闭合脉宽挤压端点 |
| 更新周期 | 100 ms建议起点 | 测批次、应答、反馈和视觉端到端延迟 |
| 总体视觉收敛增益lambda | 0.3/s建议起点 | 检查不同方向误差是否平稳下降，再逐步提高 |
| 底盘平移速度上限 | 10 mm/s建议起点 | 先确认低速命令能有效执行，再按误差曲线提高 |
| X直线速度上限 | 5 mm/s建议起点 | 完成mm换算及运动中改目标测试后使用 |
| 加速度/减速度 | 待测 | 记录实际启停时间，驱动acc档位不能直接当mm/s² |
| X/Z位置、行程限幅 | 待测 | 采用本车实际边界，不照搬±80 mm |
| 抓取像素窗口 | 待测 | 从能稳定抓住的物理偏移范围与像素响应推导，并留余量 |
| 稳定判据 | 至少200 ms且至少3个不同的新帧，建议值 | 检查视觉噪声、机构残余运动；不能只计循环次数 |
| 允许下降的速度阈值 | 待测 | 结合反馈分辨率及停稳测量设置，不能只看命令速度为0 |
| 闭合等待 | 待测 | 实测500到800 us带物料闭合时间，留适量裕量 |
| 视觉最大数据年龄 | 待测 | 从新帧间隔和延迟分布定；超龄先停止修正，恢复后重新稳定判断 |
| 目标获取/对准/下降超时 | 待测后设置有限时间 | 根据正常阶段耗时加裕量，不沿用高层超时关闭配置 |

参数示例：某方向响应2 px/mm，误差40 px，lambda=0.3/s，则期望误差修正速度12 px/s，相当于总机构修正速度6 mm/s。若两机构该方向效果近似相同，70%/30%贡献对应X=4.2 mm/s、底盘=1.8 mm/s；实际方向由响应符号决定。这是计算示例，不是本车标定结果。

### 5.5 抓取窗口

从手动可抓住的位置出发，逐步改变水平偏移，测出左右、前后分别能可靠夹住的范围。窗口应考虑夹爪张开宽度、物料夹持部位、视觉抖动、停机后的残余位移和回差；按较小的可用范围留出余量。尺寸容差不足以覆盖视觉抖动时，先改善图像/姿态再调阈值。

不直接采用参考代码约±22像素，也不强制沿用本车当前±1像素。原始图像分辨率相同也不说明两车的物理容差相同。

## 7. 后续实现顺序

1. 统一任务码数据与屏幕刷新，增加前四段站点交接和首件后暂停。
