# 底盘1ms控制与独立曲线周期

## 本轮要求与实现

用户明确选择：控制计算固定1 ms，并新增独立的曲线更新周期供上位机调整。

- `CHASSIS_MOTION_PERIOD_MS`由20改为1，仍为HAL毫秒时基上的主循环调度目标，非硬实时保证。原有20 ms最短动作时长另以`CHASSIS_MOTION_MIN_DURATION_MS`保留，未顺带放宽时长接口。
- 直线平移曲线默认1 ms；本次独立测试可选1～100 ms整数。linear、cosine均适用，曲线周期不改变加速度单位或K×2 ms过渡时长。
- 位置收敛、反馈年龄制动包络及加减速向量限制在曲线更新时计算；间隔中保持地图平移参考，控制循环继续坐标转换、航向纠偏及四轮分配。新鲜IMU才更新航向输出；到点、人工停车和故障处理不等待曲线更新。
- 曲线变化量使用两次实际更新的时间差；调度晚到只计算一次，不回放积压。新动作、位置补偿重启及退出连续曲线时重建曲线时基。余弦段仍逐控制循环保留观测到的最大反馈年龄。
- 参数只覆盖本次独立测试；普通MoveTo、比赛路线恢复曲线默认1 ms。原地转向和连续路径使用自身控制，不套独立测试的平移曲线周期。
- 电机仍使用现有串口同步批次；保留同值去重、最新待发目标替换、位置反馈组屏障及其他客户公平性。控制1 ms不等于总线四轮批次1 ms或IMU新样本1 ms。

## 上位机与协议

“底盘单段运动测试”增加“曲线更新周期 / ms”，默认1，范围1～100。默认1时继续发送既有9字段命令；非默认周期追加在P/D之后，例如：

`chassis test 1000 0 1000 linear 300 0.02 0 5`

该示例仅说明格式，本轮未发送实车运动命令。旧5/6/7/9字段格式保留；10字段格式经测试准备流程原样传递。越界、非整数返回`curve_period_range`。

受理回复与结果增加`curve_period_ms`、`control_period_ms`；后者表示配置目标，实际控制间隔仍看`dt_ms`。网页结果以设备回报显示控制/曲线周期，不从当前草稿猜测；旧回复缺字段时保留兼容。运行中编辑表单只影响下次测试，不在线改变当前任务。
