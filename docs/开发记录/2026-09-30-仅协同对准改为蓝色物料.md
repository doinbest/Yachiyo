# 仅协同对准改为蓝色物料

用户要求将“仅协同对准”目标改为蓝色，以排查橙色夹爪与红色物料可能产生的识别干扰。此前像素跳变的原因尚未通过实物验证。

## 实现

- `grab start align` 使用 B2 蓝色物料，颜色编号 3；识别请求、请求有效性校验、坐标校验、漏检恢复和状态/坐标日志统一按当前任务颜色处理。
- `grab start pick` 及路线交接的视觉抓取继续使用红色，颜色编号 1。固定位置抓取不请求相机。
- 网页任务2说明、页面总述、README 和现行协议同步说明颜色区别。按钮命令不变，初始响应模型与准心不变；无需修改香橙派协议或程序。
- 保留工作区已有改动。本轮未连接硬件、发送设备命令、烧录或复位。
