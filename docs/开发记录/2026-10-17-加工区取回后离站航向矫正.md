# 加工区取回后离站航向矫正

2026-10-17。用户要求加工区夹取完物料后，离开前再做一次视觉航向矫正，随后Base回位、底盘转向。本轮沿用用户手动烧录、烧录后另行下达审查指令的安排，不发送实车命令、不下载、不做修改后代码审查。

## 新流程

两批加工分别执行：第三件取回入仓、释放并完成记账 → 空爪回观察 → 父任务补齐完整work_ready观察姿态和新鲜停稳 → 色环B2/0D航向核验/矫正 → Base恢复行驶姿态 → 按原路线退至Y425 → 到点停稳、完整travel_ready后转底盘离站。

启用本轮视觉航向时，加工末件不再调用StoreFinishTravel，因此不会先回行驶姿态又为了观测转回。观察前仍要抬Z收X、Base到作业方向，不能仅凭PoseClearanceReady就开始观测或提前移动底盘。三件库存和Stored计数只在原stored完成路径记账一次。

离站矫正复用StationHeading的正式色环策略：反号1∶1、IMU闭环、最高min(本轮转向上限,10°/s)、新鲜一致观测和停稳复测；不重置IMU或手填色环映射。观察资格、原5秒取证窗口、无充分观测时沿用原航向及已开始转动后的真实停稳检查保持。关闭本轮视觉航向的兼容调用、原料离站、暂存离站和独立测试不增加该阶段。
