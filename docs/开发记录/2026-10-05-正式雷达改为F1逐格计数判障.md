# 正式雷达改为F1逐格计数判障

## 本轮需求与实现

用户要求实车规划采用备用雷达页已经验证的规则：筛选后的点落在哪格，就累计哪格。正式网格保持全场0～2400 mm，内边界550/1000/1400/1850 mm；默认角度0～360°、距离100～40000 mm、能量0～255、每格最少点数1。

`radar_map.c` 的完整云重建直接复用逐点 `RadarMap_Add`；移除轮廓分割、背景续接和场外连通长轮廓删除。`RadarMap_FinishRaw` 统一按每格独立计数生成扫描证据。同格不连续的点仍可累积，相邻格不能借用点数。场外点只记 `outside_points`，协议兼容字段 `background_points` 保留且为0。截断缓存仍保留全原始点流式计数，不使用120点预览建图。

保留90°参考坐标转换、下方/上方安装约定、当前安装起点格与二维码前/原料前扫描豁免、四固定障碍、工位坐标、任务顺序及全部路线执行逻辑。备用F1实现不改。不同网格范围和正式工位豁免仍可能产生合理差异，不宣称两页障碍掩码完全相同。

网页正式参数默认值、实车标准角落扫描预设和本机C规划服务默认值同步为360°、阈值1及相同距离/能量范围。显式人工筛选参数仍可调整；“当前安装设置”沿用设备当前RAM参数，不擅自挪动实际安装位置。复制备用安装仍转换位置与零角后读回。

## 生效与最小上板检查

烧录本轮HEX后，重启本地控制台服务并刷新网页。已保存的旧设备参数或历史图不会自动变成新图；显式读回安装位置/方向和筛选参数，再静止扫描新圈。若仍在备用页(230,230)测试安装，应先显式复制备用安装设置，正式坐标对应(2170,230,180°)，不能把标准生产默认(2250,150,180°)直接当作该测试安装。

保持雷达及障碍物不动，对比两页扫描障碍：在共同网格内应遵循参考到正式的90°对应关系；外圈及既有工位豁免单独核对。仅扫描和读取结果，不执行底盘/机械臂。全场逐点阈值1会保留此前被背景规则删除的场内回波，这是本轮明确要求，不通过抬高阈值或恢复轮廓过滤掩盖结果。
