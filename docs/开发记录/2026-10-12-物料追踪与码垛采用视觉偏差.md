# 物料追踪与码垛采用视觉偏差

用户将物料视觉准心调整为 `(372,345)`，要求后续优先处理 DX、DY，以便结构变化后只调整视觉目标点；本轮范围包含动态物料追踪及专用码垛对准。

## 实现

- 香橙派 `ColorCircleDetector` 与命令行 `--center-x/--center-y` 默认值同步改为 372、345。编号环检测默认仍为 378、333。物料报文计算 `DX=CX−center_x`、`DY=center_y−CY`，B2 长度、校验和与坐标编码不变。
- STM32 `track_process` 的三种追踪模式直接采用有符号 B2 DX/DY，真实零值不回退到 CX/CY 减静态参考。位置窗口、停稳后新鲜坐标核验、预测/反馈算法、运动分配与行程预算沿用现有逻辑。
- 专用 `grab stack align` 在读取视觉、短漏检宽限与停车重获时共用偏差读取函数，直接使用 DX/DY。先达到绿色准心，再完成原有 CX+39、CY+1 补偿；第二阶段相对绿色准心的目标仍为 DX=39、DY=−1。补偿不是毫米，也不写回视觉准心。
- 旧静态颜色对准及其取放流程仍采用 MCU `ref_u/ref_v`；`grab_parameters.def` 对应默认仍为 334、338。编号环静态参考仍为 378、333。本轮没有将这两组 MCU 参考改为新物料视觉准心，也没有修改设备 RAM。
- `PIX` 每帧记录新增原始有符号 `dx/dy`，CRC 覆盖新字段。临时格式缓冲改为160字节，原FIFO与4096字节积压上限不变；网页接受新字段并兼容旧日志。追踪和码垛界面、视觉 README 及现行协议同步说明偏差来源。

## 部署与操作

本轮更新本地视觉源码及固件并完成软件验证，未SSH部署、未烧录、未发送实车指令。运行中的旧视觉程序仍会按其旧中心产生 DX/DY；本地默认值不代表远端状态，已有启动参数也可能覆盖默认。部署匹配版本后，后续物料准心可由视觉启动参数 `--center-x 372 --center-y 345` 调整，动态追踪与专用码垛无需同步更改 MCU 静态参考。调整视角或机械尺度时，现有 J 标定仍须与实际机构相符。
