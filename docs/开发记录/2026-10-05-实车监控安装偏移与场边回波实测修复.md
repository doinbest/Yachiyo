# 实车监控：安装偏移与场边回波实测修复

日期：2026-10-05。范围：正式实车监控的静止建图、显示及同圈规划；备用F1页、固定路线、机构方向、IOC/EIDE不改。原生执行，无子代理/模拟审查。

## 根因与修改

1. 备用已验证安装为(230,230)，经整场逆时针90°转换应为正式(2170,230,180°)，不能套用标准启停中心(2250,150,180°)。原始圈在这两个位置重放会有80 mm的X/Y偏移，目标及场边落格随之变化。监控新增“备用已验证位置 · 转90°”，扫描前读RAM、仅写差异；标准角落预设与固件默认仍保留，进入/切页/选择不发指令。
2. 正式网格包含全场0～2400 mm，备用内圈150～2250 mm不计入的场边回波会进入正式网格。实测同圈左边X=0±20 mm、上边Y=2400±20 mm回波沿边延伸到场外，造成多余外圈红格。不是把全场网格缩回内圈，也不提高每格1点阈值。
3. 正式`RadarMap_Add`记录四条已知场边的同圈证据。仅当回波贴边<=20 mm、至少8点、沿边跨度>=400 mm、存在法向越界点时，在`Finish`从有效扫描障碍计数中区分这些边界命中。原始counts/evidence/完整云不删；独立外圈点及同格离边30 mm的独立物体仍判障。流式及完整云走同一规则，手工mask和备用host不受影响。没有新增通用轮廓删除、时间投票或半圈预览判障。

网格仍为`[0,550,1000,1400,1850,2400]`，筛选仍0～360°、100～40000 mm、0～255能量、每格1点。四固定格与既有扫描保护保留。参考R4C3→正式R3C2，参考R5C5→正式R5C1；正式结果不再二次旋转。
