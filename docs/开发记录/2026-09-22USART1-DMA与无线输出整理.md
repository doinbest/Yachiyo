## 决策记录

- 在用户正在使用的项目目录内建立 codex 分支实施，保留已生成文件及现有本地服务入口，避免另建工作树导致用户继续编辑不同副本。

- 工程清单逐项比对确认自研模块未丢失；不回滚 CubeMX 的格式变化。EIDE 中仍有 CAN 文件项，需同步删除。
- 32 字节 / 30 ms 仍是待实测限速参数，不以 DMA 改造为由提高空中链路负载。

## 实现与参数

- RX：DMA2 Stream2 Channel4 / Circular / High；128 字节 DMA + 512 字节软件环形缓冲。回调读取实时 NDTR，避免 IDLE 先于延迟 HT/TC 时重复消费。错误恢复只终止 RX，不中止健康 TX；损坏命令丢弃到换行，Ctrl+C 独立锁存。
- TX：DMA2 Stream7 Channel4 / Normal / Low。停车回复独立 1024 字节 FIFO，普通回复 8192 字节，IMU/视觉各 320 字节最新值槽、每路至少 500 ms 发送开始间隔。32 字节 / 完成后 30 ms 限速保留。完整文本行及已开始的 JSON 不插入其他回复。
- NVIC：UART5/DMA1 Stream0/7=1；USART1/DMA2 Stream2/7=2；UART4=3；USB OTG FS=4；USART3/DMA1 Stream3=5；SysTick=15。子优先级均 0。UART5 DMA 仲裁 RX High、TX Medium，串口屏 TX Low。
- CAN 保持停用；EIDE 删除失效 CAN 清单；栈恢复 0x1000，同时写回 CubeMX 配置。
- 地图：v1 config + v2 紧凑状态，2000 ms 最短周期。仅压缩重复字段名，保留四轮原始值、时间戳、有效性、控制目标及路线/停车语义，网页兼容旧 v1。完整 v1 状态由 `chassis snapshot` 按需获取。
- `console status` 提供接收/发送诊断，两个新增查询通过网页和本地服务的只读分类，停车锁定时允许使用。

## 独立审查
