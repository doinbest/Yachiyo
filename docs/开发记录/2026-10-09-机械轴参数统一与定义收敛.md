# 机械轴参数统一与定义收敛

用户要求先解决“机械轴参数存在多个来源，配置不能一致地作用于任务”和重复定义冲突，修改前保存 Git。

修改前提交为 `21e412e`（`chore: checkpoint before mechanical motion parameter fixes`）。工作期间发现另一组 ArmVision 退役改动，其修改前提交为 `406b416`；本次保留这组改动，不把旧控制器清理算作本次参数修正。

## 实现

- GrabTask 的 X/Z 静态位置请求及动态追踪 X 在发送时读取 `MechanicalArm_ConfigGet` 的加速度档位；MaterialVision 的 X 也读取该配置。Base 原来已读取，逻辑保持。
- 轴配置默认值保持 Base20/X20/Z120。任务实际加速度从原固定8切换为当前轴配置，因此默认 X/Z 下发分别为20/120。阶段速度保留：静态视觉与固定转运使用各自的 X 速度，物料夹取下降对应1000 RPM、观察/普通提起/放置对应500 RPM（默认 Z 尺度480脉冲/mm）。
- `grab_parameters.def` 是49项 grab RAM参数的唯一人工数值定义，含名称、默认值、范围、整数要求及启动/X回零/Z回零/视觉参考恢复时机。固件枚举、键表、验证、默认值载入由同一份定义展开；网页元数据由 `Code/tools/sync_grab_parameters.py` 生成，固件主机回归使用 `--check` 检查同步。
- 修复 `z_pick_speed=111.111111 mm/s` 默认值无法通过 `grab set` 写回的冲突。Z速度范围统一为 `(0,333.333] mm/s`，保留当前尺度换算后的1～3000 RPM检查，追踪夹取显式速度同样验证。网页Z下限由旧−80改为现行−150，Base偏转由旧±10000改为固件现行±360°。
- 删除重复的车载X默认宏，100 mm数值及说明集中在定义文件。网页调试预设按选定键读取生成默认值，不再重写一份数值。

动态追踪的控制剖面仍独立；本次没有合并旧控制器、改 MCU 速度曲线或提高轴配置默认档位。`grab accel`/`grab track accel` 是 mm/s²；`config ... acc ...` 是驱动档位。未知粗加工/暂存高度仍不代填，参考载入与普通停止保留参数的行为不变。
