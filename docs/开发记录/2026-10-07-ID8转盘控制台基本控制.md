# ID 8 车载转盘控制台基本控制

用户要求在“机械臂与夹爪”控制台增加 ID 8 基本控制。页面新增独立车载转盘区域，提供相对角度点动、仓位分度、读取状态、单独停止和建立参考零位，并链接仓位角度与转速参数。

沿用现有 turntable 命令，转盘命令与回复归入机械臂控制台状态/日志。ID 8 不依赖 Base/Z/X 的轴选择；参考零位仍需人工对齐第一仓后读取当前位置建立，不执行机械回零或计数清零。第二、第三仓角度继续由实物标定。

验证：app.mjs 语法检查通过，网页回归 433 项通过。未修改固件、烧录或发送硬件命令；实际运动待实车验证。

## 后续：驱动器机械零点与就近回零

用户明确需要失能手动对齐后保存机械零点，以后每次就近回零，不反复人工建立软件参考。新增 turntable enable/disable/save_zero/home 命令与控制台按钮。机械零点沿用官方 Emm 0x93 88 01 存储，回零沿用 0x9A 模式 0；不改驱动器配置或位置计数。回零 ACK 后继续读 0x3B、实际位置、速度和驱动状态，确认回零退出且位置稳定后自动将第一仓软件参考同步到当前位置；不要求反馈计数为零或位置运动到位位。

回零期间停止先发 0x9C 退出回零，再发 FE 停止并读反馈。保存零点、使能/失能和回零保留仓位角度与库存；首次设置后驱动器保存机械零点，仓位参数仍是 STM32 RAM。界面说明改为“失能 → 手动对齐第一仓 → 使能 → 保存机械零点；以后就近回零”。
