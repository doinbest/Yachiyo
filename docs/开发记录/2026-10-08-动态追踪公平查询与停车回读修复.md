# 动态追踪公平查询与停车回读修复

## 修改依据与实现

承接[反馈饥饿与停车锁定分析](2026-10-08-转动物料追踪反馈饥饿与停车锁定分析.md)。用户授权修改、烧录并串口验证。

`GrabTask.c:track_io` 将 X 最新运动、X 位置读取、低频轴反馈分成三个轮转机会；无待办的机会直接跳过，成功排队后推进游标。低频反馈仍沿用原有查询顺序与 100 ms 调度条件，X 位置读取仍按 50 ms 到期；不会重复排队旧控制目标，也不放宽反馈超时、机械边界或四轮批次原子性。

追踪首次遇到过期/缺失反馈时保存电机 ID、反馈类型、年龄、阈值及有效位，通过 `grab track status` 的 `feedback_fault` 行读回。停车后的新数据不覆盖触发证据，下一次显式观察或启动清除该快照。原 `feedback_age` 仍只表示 X 位置年龄。

`motor_bus.c` 允许在途位置运动/普通机械轴停车取消后，通过匹配功能码读取停车证据；放行范围包含四轮、机械臂、转盘与恢复检查的既有只读位置/速度/状态/回零状态查询。取消的旧运动 ACK 不能完成不同功能码的只读事务。运动隔离保留；真正的应答超时/UART 故障不会因随后取消而被自动解锁。

`bus status` 增加独立的 `OK bus motion locked=... error=... feedback_allowed=...`，分别显示底盘锁定与共享总线是否允许只读查询，避免把共享总线 `locked=0` 当成底盘已可启动。

本轮未处理 P001（手动 Base 转动使物料参考和矩阵失效），未改变应答驱动模式、视觉参考、速度、加速度、观察姿态、库存、IOC 或 EIDE。

## 软件验证

持续每 20 ms 更新控制序号、X 目标与速度，模拟 5 秒事务排队竞争。旧实现 20/25/80 ms 完成周期均无慢项回复，年龄到 5000 ms；新实现结果：

| 模拟完成周期 | X 最大位置年龄 | 慢项最大年龄 | 慢项回复数 |
| --- | --- | --- | --- |
| 20 ms | 99 ms | 499 ms | 50 |
| 25 ms | 100 ms | 499 ms | 50 |
| 80 ms | 239 ms | 1200 ms | 20 |

这些数值为主机模拟，不代替实车测量。触发证据保留回归通过；ARM 位置/停车及四轮取消后的回读、迟到 ACK 不串包、真正超时不放行回归通过。相关追踪、取放、姿态、视觉宽限、总线恢复、机械臂紧急停车链、底盘追踪批次与停车回归通过。Keil Target `template` 构建 0 错误、0 警告，Flash 234808 字节。
