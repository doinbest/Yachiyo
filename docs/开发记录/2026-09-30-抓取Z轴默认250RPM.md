# 抓取任务Z轴默认250 RPM

用户要求将程序中的Z自动升降默认速度改为250 RPM，并在重新上电后保留。此次修改默认值并编译；未烧录、复位或发送串口命令。

## 单位与实现

本地《ZDT_X42S第二代闭环步进电机用户手册V1.0.5》第20～21页说明O_Vel为回零转速、单位RPM；第65页Emm回零参数同样为RPM。第57页Emm位置指令的速度单位为RPM，默认1.8°/16细分为3200命令脉冲/圈。

当前Z尺度为480命令脉冲/mm：250×3200÷60÷480=27.777777… mm/s。GrabTask启动默认z_speed由5改为该换算值，位置指令实际提交250 RPM；网页预填27.777778，读回约27.7778。接口继续使用mm/s，修改z_ppm后相同z_speed对应的RPM会变化。

适用fixed/pick下降、提起、放置，以及align/pick前往观察高度。X/底盘速度、Z行程与目标高度、驱动器回零参数、普通pos z速度不变；加减速档仍为8，到位仍依赖反馈，不能将发送成功视为下降完成。250 RPM为设定上限，短行程和加减速会影响实际峰值及耗时。

| 设置 | 原默认 | 新默认 |
|---|---:|---:|
| grab z_speed | 5 mm/s | 约27.777778 mm/s |
| 当前尺度对应电机速度 | 45 RPM | 250 RPM |

## 使用与回退

固件：`template/MDK-ARM/template/template.hex`。SHA256：`67bd059094d33d7c78317af5027b048830a1b8f4ca0b375e4f1f362b75e8328d`。

烧录本版后，上电默认即为250 RPM对应的z_speed。需要临时调速时仍可在任务空闲后执行 `grab set z_speed 27.777778`，随后 `grab get z_speed` 核对；临时设置不要求重烧。改回旧速度用 `grab set z_speed 5`，重启后回到所烧录版本的默认值。
