# 实车监控与路线计划对照

用户要求实车监控像离线对照一样列出停车状态、计划速度及最后停止坐标，并融合两部分。网页共用现有 C 路线计划卡片，监控计算采用完整同圈障碍副本；离线副本仍保留独立编辑。计划终点、预演结束/中止坐标和实车反馈停止坐标分别标注。播放监控计划转到离线视图，不替换实车位置、不发送运动命令。

使用现行 `route_meta` 的启动速度和阶段限速，避免用浏览器下次启动设置覆盖正在执行的速度。新增页面内停车历史，仅在同帧 `stop_confirmed` 与 Telemetry 已验证的新鲜反馈位置同时有效时采纳。重复确认去重，运动恢复后再次确认可记录纠偏结果。原点版本分别标注，断流、停止订阅和重连保留已记录结果；刷新页面清空。

限制：当前遥测约2秒一帧，短暂停靠可能漏过；软件停车事件独立显示，不用事件和旧坐标拼成虚假的同帧停止位置。反馈坐标仍是编码器＋IMU估计，未做视觉精定位。未改固件、协议、Keil/EIDE或硬件配置，未连接串口发送命令。

验证：新增停车记录测试覆盖无有效坐标不记录、确认去重、纠偏再次停车、断流/重连和原点版本；界面测试覆盖监控本机计划、速度快照保留与离线播放不发TX。运行 `node --test Code/upper-computer-web/local-car/tests/*.test.mjs`，506项通过。浏览器打开本地8765监控页，验证固定 C 路线计算、阶段与限速、计划终点及预演中止坐标展示；当时未连接实车，实车位置区域明确显示待遥测。实车停靠仍待开启遥测后的现场验收。
