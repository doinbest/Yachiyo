# 联调暂关抓取底盘行程限制（2026-09-30）

蓝色仅协同对准在 DX/DY 仍向准心收敛时，因四轮之一相对本任务起点的换算行程超过 `travel_mm=100` mm，报告 `travel_limit` 并确认停车。该值对当前测试范围过小。按用户要求，本版把 `travel_mm` 默认值改为 0，并明确 0 表示关闭这项检查；正数仍执行原有四轮逐轮行程检查，范围至 10000 mm。网页参数预填值与标签同步更新，操作员可用 `grab set travel_mm <毫米>` 重新启用、`grab get travel_mm` 读回。

仅关闭 `travel_limit` 条件；四轮反馈新鲜度、使能/堵转、停车确认、X/Z 轴边界、视觉过期和总线故障判断不变。主机固件回归覆盖 0 关闭及正数超限，网页 Node 测试 119 项通过；Keil 构建 0 错误、0 警告。尚未烧录或实车验证新一轮对准。
