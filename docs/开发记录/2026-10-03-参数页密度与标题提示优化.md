# 参数页密度与标题提示优化

用户要求按空间排为两、三或四列，减少参数页滚动；RAM 和未读取提示利用“参数调试”标题旁空白。修改前工作区干净，基线为 `c1d4739`。

## 界面调整

- 通用参数组按可用宽度自动排为最多四列，中宽三/两列，手机一列。输入保留 30 px 高、14 px 字号，标签、数值与单位、设备值与状态紧凑对齐。
- 物料六个场景为三列两行；中宽两列，手机一列，每个场景内部保留下降/抬升两格。X/Z 速度与车载 X/Base 位置两组并排。
- RAM/读取说明移到标题旁，完整说明保留在提示中；场景与参数组的说明利用组标题旁空位。视觉调试预设改为紧凑横排，转盘操作按宽度排列，不单独堆大块说明。
- 修正 761～1150 px 下参数页只占半个工作区的问题，继续覆盖已隐藏终端留下的空间。
- 缩减组间距、卡片边距和底部空白，手机长组说明单行显示并保留完整提示。

保留 74 个显示字段（73 个设备值、1 个浏览器设置）、输入/行 ID、读取/应用核对、草稿和页内导航、蓝/黑主题。没有修改固件、协议、停止按钮或硬件配置。

## 验证

网页全套 **165/165** 通过。实际浏览器检查全部五标签，视口为 1680×1050、1366×768、1024×768、390×844、320×700；无横向溢出、页面错误或 POST/TX，输入在所属参数行内，切页及蓝/黑切换保持草稿。

与基线提交的实际页面对照，1366×768 的物料页从 **4/13** 项完整参数行同屏增加为 **13/13**；参数内容高度从 1026 px 降至 368 px，与可视区高度相同，不需下滑。1680 px 下视觉等通用参数组为四列，1024 px 下为三列；手机保留适合输入的单列。

基线浏览器对照使用 Git `c1d4739` 的原版 app/page/styles 响应，不修改当前源码。检查脚本、`baseline.json`、`final.json`、浏览器日志、网页测试日志与截图保存在 `.embeddedskills/parameter-density-review/`，不提交运行产物。未运行固件构建或操作硬件。
