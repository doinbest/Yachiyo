## 实现

- GrabTask 增加 vision_pause 和独立恢复额度；正常停车复用底盘与 X 停止发送、四轮与三轴反馈确认。停止期间继续收 B2，但不累计恢复坐标。
- 停稳时才开启窗口，以当时本地接收序号作起点。新鲜有效坐标一次任务更新最多计一次；相同坐标的新报文可计、同快照不可计。InvalidCount 捕捉粘包失效，清零后最新有效包最多作第 1 次，不重置窗口。
- 500 ms 边界可恢复，501 ms 超窗；反馈必须仍停稳。恢复重新建立 X 起点、速度历史和控制时钟，重走对准与停稳，不直接下降。额度独立于原偏移重试。
- 坐标过期、USB/请求失效、机械反馈和总线故障保留硬停止；人工停止取消恢复资格。未确认停稳不开始窗口、不自动运动，没有新增整任务超时。
- grab status 保留 B2/rx 序号和停止字段，新增 recovery_used/recovery_count/recovery_left_ms。具名常量在 GrabTask.c，不新增设置菜单。
- 网页展示设备恢复进度、次数和原因，暂停明确“不下降夹取”；旧固件字段显示未报告。日志过滤保留状态和成功次数变化，忽略纯计数倒计时刷新；不发送额外识别或恢复命令。
