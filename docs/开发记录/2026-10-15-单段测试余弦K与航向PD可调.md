# 单段测试余弦K与航向PD可调

## 范围与默认值

用户要求在底盘单段运动测试中填写余弦K及航向P、D，并明确要求P、D允许0。当前源码已由此前PD试验恢复为P0.02/D0，本次沿用该默认；不把历史P0.10/D0.01重新写成全局默认。

线性加速度默认300 mm/s²、范围10～5000；cosine下显示K输入，默认200、整数10～2000，半余弦过渡时间K×2 ms。P、D各0～1，允许单项或同时为0，单位分别(rad/s)/°、(rad/s)/(°/s)。P=D=0关闭该航向控制器输出；地图位置反馈、IMU验证和到点航向判定仍保留，因此有偏航时仍可能等待到点确认，不能把零增益解释为跳过完成条件。

## 实现及现行文档

- `chassis test f l speed linear accel P D`或`chassis test f l speed cosine K P D`，最多9字段；旧5/6字段和线性7字段兼容，cosine增加7字段K调用；只追加一个增益拒绝。
- 参数在受理时复制到动作快照；K用于提速、短段峰速、制动参考及矢量变化限制；P/D用于直线平移的航向纠偏，D取新鲜IMU测量变化率并保留40 ms滤波及±0.50 rad/s限幅。位置收敛重启保留本动作参数，后续普通任务恢复源码默认，原地转向和连续弯道控制不变。
