## 最小改动

`chassis run vx vy omega hold_ms`：当omega为0时，选择新增HOLD_CURRENT模式，在MCU接受任务时只捕获一次经过验证、新鲜的HWT101航向，后续复用原航向PID纠偏。前进、后退、横移共用同一控制器，不重复造PID。没有有效IMU则拒绝；运行中IMU失效、采样或调度超限时沿用停车流程，不降级到开环。

当omega非0时，保留主动给定角速度模式；两种旋转控制不会叠加。原显式`chassis heading`和地图距离任务保持原语义与锚点约束。新增起步保向不要求地图锚点，不设置原点、不改单位，也不接入视觉任务或旧持续速度入口。

仍使用20ms计算、100ms同步发送、半余弦起停、统一轮速缩放、整数RPM。PID参数继续使用Kp=0.02、Ki=Kd=0、输出限幅0.15rad/s、HWT角度符号+1。这些参数和纠偏方向仍需上板验证；整数RPM会影响小偏差时的纠偏分辨率。

`chassis task` 新增mode、target_deg、yaw_deg、yaw_valid、omega：mode=0给定角速度，mode=1显式目标航向，mode=2锁定起步航向。yaw_deg为带符号模块展开角度，target_deg为等价包角目标，不是地图角度；有效性必须看yaw_valid。完成后的omega可能是最后一次规划值，停车状态与轮速另看现有字段。

网页改为“自动保向 / 转向”，表单说明角速度0的IMU前置条件，更新资源版本。没有增加额外必点按钮。
