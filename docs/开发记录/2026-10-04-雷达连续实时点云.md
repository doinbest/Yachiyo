# 雷达连续实时点云（2026-10-04）

## 目的与基线

用户希望边扫描边观察回波，用于排查黑色圆柱和白色围墙的位置偏差。本轮实现持续显示，不修改障碍判定算法或实车路线。

修改前检查点：`15d9621`（`chore: checkpoint before live radar point cloud`）。原有单圈扫描、同圈原始诊断、完整点云下载和5×5地图独立保留。

## 实现

- 新增 `radar live start upper|lower`、`radar live stop`、`radar live status`；`radar stop`也结束实时采集。启动只配置一次雷达，之后连续采圈。
- 与静态扫描共用CE/CF角度插值及距离单位换算。实时预览覆盖360°，使用冻结的距离、能量条件；120个3°区间各保留最近有效回波及其实际角度，不把角度直接量化为区间中心，不按场地边界删点。
- 工作圈、最近完整圈和发送冻结圈各480字节。发送当前圈后跳到最新圈，中间圈不排队；每圈5片，每片24点。普通查询优先，沿用32字节/30ms无线节奏。
- 页面提供场地叠加、雷达中心两种视图，1/2/4/8米半径、世界坐标轴和雷达0°箭头。首圈可以显示接收进度；已有完整圈时保持显示，下一圈完整后整体替换，避免分片清屏闪动。
- 单圈诊断完整cloud不再被网页二次抽样到360点；设备完整云中存在的点全部绘制。
- 停止、断线明确显示历史及更新时间。页面导航、视图切换、重连不发送启动指令。实时120点不作为完整障碍识别或原始协议分析的替代品。
- 新停止指令沿用本地桥接优先队列与停止锁定例外；带`arm>`提示符的数据页同样走点云通道，保留底层二进制日志。

本次验证的是持续采集、传输和显示；没有把点云刷新成功描述为障碍位置精度、供电报警或安装参考已标定通过。页面使用的 `(2170,230,180°)` 仍为下起点的名义安装位姿。
