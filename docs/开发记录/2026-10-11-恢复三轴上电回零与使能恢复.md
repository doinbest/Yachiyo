# 恢复三轴上电回零与使能恢复

用户完成单轴 `home x/z collision` 和 Base 就近回零测试后，要求恢复上电流程并处理自动流程的未使能误判，沿此前授权直接烧录；随后授权使用 `system reset` 验证软件重启。

## 依据与改动

历史日志在 HOME 状态从运行变为完成后，报告 `home_flags=0x03 motor_flags=0x02`。原自动流程把单次未使能直接判为 `home_axis_fault`；用户稍后手动查询 X/Z 均为 `0x03`。这些证据能确认检测时序差异，尚不能确定驱动器失能的物理原因，也不能仅凭 ACK 判断回零完成。串口原始证据保留在 `.embeddedskills/homing-fault-20261011/`。

恢复 `main.c` 的 `GrabTask_BootHomeStart()`：Z 碰撞 → X 碰撞 → Base 就近，各轴验证成功后才恢复该轴参数/参考，三轴成功后启动 IMU 静止 5 秒验证。ID8 沿现有流程等待 `home_complete`，然后就近回零建立第一仓参考。不修改电机 ID、驱动器保存的碰撞电流/方向/模式、官方 Emm 驱动或 EIDE。

每轴读取回零状态，检查过温、过流与编码器/校准就绪，再发 ENABLE；读取实际使能状态，1500 ms 内未确认则停止，不发 HOME。HOME 后读回零状态、位置、电机状态，要求连续两轮正常使能、位置稳定。X/Z 保持原 ±182 反馈单位零点窗口；Base 保留实际多圈位置，不清计数器。

HOME 已完成且只有使能位为 0 时，先复查 600 ms。若仍未使能，且新鲜反馈确认位置稳定、无驱动保护，仅补一次 ENABLE，不重复 HOME；重新核验位置、使能和回零状态，1500 ms 内无法完成则 `home_enable_failed`。恢复期间位置偏移超过 182 单位则 `home_position_changed`，不建立参考。人工停止后不再提交恢复动作；真实保护、总线错误和停止处理仍保留。详细触发与恢复入口见[机械臂协议](../协议/机械臂与取放.md)。

首次上板验证发现 Base 在本次 HOME 尚未发送时返回 `home_flags=0x0B`，新增前置检查误把上一次回零失败 bit3 当成本次故障。已修正：发送新 HOME 前允许历史 bit3；本次 HOME 受理后 bit3 仍按当前回零失败停止。过温、过流和校准检查不放宽。该场景增加先失败后通过的回归，不发送清故障或改驱动配置命令。

网页同步自动启动提示、使能等待/恢复/失败说明和缓存版本，保留暂停版本横幅兼容。暂停时期的记录仍保留历史事实。
