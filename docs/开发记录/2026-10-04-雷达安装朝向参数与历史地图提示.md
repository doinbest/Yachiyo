# 雷达安装朝向参数与历史地图提示

## 范围与基线

用户要求在上位机指定实物雷达0°朝向，并解释自动识别起点未确定的截图。本次修改前工作区干净，基线已保存为`47b9419`；只修改本地控制台及当前文档，未改变固件、协议、安装预设、外设、Emm、Flash或EIDE，未发送硬件指令。

## 安装朝向操作

参数调试→雷达与路线新增“雷达0°安装朝向（俯视）”，车头为0°、车左为正、车右为负，支持四个方向和自定义偏角。

| 实物雷达0°方向 | 相对车头角 | 下方名义起点的zero_deg |
| --- | --- | --- |
| 车头 | 0° | 90° |
| 车右 | −90° | 0° |
| 车尾 | 180° | 270° |
| 车左 | +90° | 180° |

换算`zero_deg=normalize(90°+相对角)`，使用已有`radar set zero_deg`。上方参考继续由固件加180°，不额外旋转地图或更改底盘、IMU方向。当前默认180°隐含雷达0°朝车左，只是参考假设；默认雷达位置也仍未实测。

未读取时朝向为空；读取后显示“设备参数折算”，不宣称已核实实物安装。选择方向只填零角草稿；直接编辑零角也反算朝向。草稿跨切页、停止、取消和参数读回保留；自定义小数归一化避免显示无意义的浮点尾数。点击“应用本页修改”仍按受理、主动读回、数值比较确认，失败原因保留。参数只存STM32 RAM，重启恢复原固件默认值；应用后重新扫描使用新参数。

雷达页右上“雷达安装与参数”直达此项，现有来源返回和导航无TX语义保留。本轮无需重新编译或烧录STM32；刷新网页即可使用新控件。

## 截图状态与显示修正

`ready`表示完整圈采集完成，不保证本圈起点已选定或地图已发布。`start_ambiguous`表示两个起点候选的必空区域都未达到障碍阈值，不能排除其中任何一个；这也不能证明安装角正确。用户截图scan=4、map=2、plan=2时，第4圈未确定起点，旧地图和规划保留。显示的格内275/113是历史图的点数，并非毫米距离。

网页改为明确显示“本圈采集完成”及“显示历史地图2/规划2（不适用本圈）”；没有历史图时显示“尚未发布本圈地图和规划”。左上“不可用”来自车辆位姿显示，与雷达查询通信和完整圈采集独立。
