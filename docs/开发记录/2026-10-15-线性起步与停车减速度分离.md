# 线性起步与停车减速度分离

日期：2026-10-15。

## 需求与实现

用户要求尝试起步坡度较大、停止坡度较缓的线性速度规划。网页单段测试新增独立的起步加速度和停车减速度，初始填写500和300 mm/s²；前进、后退共用该处理。普通路线与固件默认仍为300/300 mm/s²，旧单加速度接口和指令仍使用对称加减速。航向默认保持单P=0.02，控制周期与曲线更新周期沿用当前实现。

制动包络按独立减速度计算，并保留反馈年龄与驱动响应预算。平移速度矢量增加时使用起步加速度，沿已有运动方向消减时使用减速度。进入到点窗口后，普通linear平移先把参考速度按减速度降到零，再请求停车并核验实际停稳；该末端处理也适用于普通linear路线。人工停车、取消和故障仍立即执行停车，余弦、原地转向及连续路径保持各自控制。

网页在线性模式展示两项输入，切换余弦时隐藏并保留草稿。设备受理和结果回报新增实际`decel_mm_s2`；余弦报告0表示不适用。历史设备缺少该字段时不猜测实际减速度。

新线性指令在原10字段之后追加减速度，最多11个空白分隔字段、95字节，示例：

```text
chassis test 2000 0 1000 linear 500 0.02 0 1 300
```

依次为位移、速度、模式、起步加速度、航向P/D、曲线更新周期和停车减速度。旧格式保留；新11字段仅用于linear，减速度范围10～5000 mm/s²。网页与固件需要配套，刷新网页后使用新输入。
