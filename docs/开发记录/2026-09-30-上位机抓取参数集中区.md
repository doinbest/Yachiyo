# 上位机抓取参数集中区（2026-09-30）

用户希望在上位机集中修改联调参数。新增 `upper-computer-web/local-car/grab-params.mjs`：`GRAB_FORM_DEFAULTS` 只作为表单预填，`GRAB_TEST_PRESET` 是操作者点击“逐项发送调试预设”时要发给 STM32 RAM 的项目。页面打开和串口连接不自动发送。每条命令仍通过现有 `grab set` 验证和串口队列；写出失败或停止后不发送余下项目。页面只报告已写出数量，不把写出当作固件接受或到位；实际值用 `grab get` 读回。固件的上电默认值独立，修改此文件无需重新烧录，但重新上电后若需应用预设必须再次点击发送。
