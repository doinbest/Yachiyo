# 地图界面改版计划

按用户已确认方案实施，仅改本地网页，不改固件及雷达硬件条件。

1. route-annotations.mjs 从 C phases/设备路点建立编号、重复目标和方向标注；新增纯计算测试，验证中间点不影响 C 编号、重复坐标及反向线段。
2. radar-view.mjs 分开实车参考计划与离线方案设置；app.mjs 取消预演速度与实车速度绑定。测试离线速度、选择、障碍副本和播放不发送运动指令。
3. index.html/styles.css 按现场状态与离线输入顺序整理，合并计算按钮，提供地图来源说明、折叠诊断及运动实验入口。
4. map-view.mjs/radar-view.mjs 接入编号、方向、点击选择、高亮和播放控制；实车按遥测当前目标高亮，离线按用户选择高亮。
5. 更新现行手册及开发记录；运行网页测试、差异检查及浏览器验证。独立检查无反馈、重复到访、重叠往返及切页恢复。现场验收另报告。
