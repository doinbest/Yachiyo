# 静态对准统一与手动码垛滚轮调高

用户要求先识别下层物料的颜色中心并移动对准，再人工装入上层物料、主动夹紧。高度调整与松爪分别执行，鼠标滚轮停止一秒后才发送最终高度，便于试出码垛高度。本轮只实现单件手动码垛测试，不从车载仓取料、不更改库存。

## 入口与操作

控制台入口：视觉任务 → 码垛。默认蓝色、高度 −100 mm。

| 操作 | 指令 | 结果 |
| --- | --- | --- |
| 蓝色物料中心静态对准 | `grab align color 3 0` | Z在最高处识别，底盘和X对准后停稳，保持等待装料 |
| 编号环静态对准 | `grab align ring 1 -100` | 横向接近后逐步下降，对准完成后停止纠偏并抬至最高 |
| 编号环低位观察 | `grab align ring 1 -100 stay` | 对准完成后保持指定高度 |
| 人工装料后夹紧 | `grip catch` | 只闭合夹爪 |
| 调整到绝对高度 | `grab stack lower -100` | 只移动Z，夹爪保持原状态 |
| 独立松爪 | `grab stack release` | Z到位后松爪并停留 |
| 独立抬升 | `grab stack lift` | 提至Z最高，夹爪状态保持 |
| 停止并退出 | `grab stop` | 停止任务、取消网页待发高度 |

颜色编号沿用B2：1红、2黄、3蓝、4绿、5黑、6浅蓝。编号环使用0A～0C，颜色准心(334,338)与编号环准心(378,333)独立，未把环的新准心写回物料配置。旧 `grab ring align` / `grab start align` 仍可调用。

## 共用静态控制

颜色与编号环通过 `GrabTask_AlignStart` 进入同一准备、接近、停车及保持流程，沿用编号环已验证的横向接近和渐进下降方式。颜色码垛默认Z目标为0，完成后等待装料。

静态颜色、编号环与静态pick对准共用grab RAM参数：底盘160 mm/s、X60 mm/s、加速度300 mm/s²、lambda2.5、lead12 mm、DX/DY各1 px。可通过原参数页面调整。动态 `grab track` 保留独立TrackConfig，不因静态参数修改而改变。静态运动应答仍按总线Receive推进，取消多余的50 ms SENT等待。

联动仿真发现：半个脉冲附近的浮点残差可能让X反复发送相同的整数脉冲目标，重置停稳证据。现在比较实际整数脉冲，保留小数积累，同时不重发没有变化的执行目标；手动Z到位也容忍合法的脉冲量化误差。

## 滚轮与高度状态

滚轮每格1 mm，向下滚使Z目标更负，向上滚提高目标；滚动期间只更新网页预览。每次滚动重新计时，连续停滚1000 ms后只发送最后一个目标。数字输入只修改本地值，点击“下降到目标高度”才执行。

高度为绝对坐标，可向上调整。已有Z运动未完成时，新高度覆盖待执行目标，不强行取消正在消费的应答或回读。运动完成进入保持状态；松爪独立指令要求高度到位。高度阶段关闭视觉纠偏，底盘、Base与X保持对准结果。

停止、故障、断线、切换标签、设备重启及页面销毁取消尚未发送的高度，不自动重放。网页区分预览、已请求、设备运动中及已到位；一秒计时不是机械到位证明。网页范围−150～0 mm，固件按当前RAM中的Z机械范围校验。

## 验证范围

新增真实固件状态机回归覆盖颜色/编号环参考独立、共享调速、人工夹紧、独立下降和松爪、未完成高度覆盖、脉冲量化及停止后的拒绝。真实网页面板事件与FakeSerial覆盖滚轮一秒防抖、断线/故障/切页取消、独立松爪与提起；不连接实车模拟运动。

本记录的软件回归和编译不代表实车码垛验收。待实车观察颜色中心精度，并用滚轮试出放置高度。
