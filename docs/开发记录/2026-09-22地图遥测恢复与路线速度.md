# 地图遥测恢复与路线速度

日期：2026-09-22。用户反馈无线遥测格式错误、运行一段时间后地图不再显示，实车四段路线速度偏慢，希望在地图页准备和运行。

## 实现

- 遥测JSON坏帧和字段错误计数并丢弃，清除实时状态，不把损坏数据或过期位置用于准备通过。保留最后有效位置供淡色显示并明确“已过期”。连续6秒无有效帧时保留会话，恢复同会话且时间戳递增的有效帧后继续显示，轨迹断开。断开串口、主控重启、关闭或新建订阅仍清除旧状态。初始配置帧丢失且尚未成功取得配置时仍需重新开启订阅。
- `chassis route start [speed_mm_s]`，省略速度兼容原50 mm/s；指定范围10～100。一次四段路线沿用启动速度，运行及等待下一段时不能重设。位置闭环靠近目标减速，航向闭环与反馈门槛保留。
- 每段超时按2倍理论行驶时间加10秒、至少60秒、最多190秒计算，给10 mm/s下整数RPM量化与到点减速留余量。独立位移测试仍默认60秒。没有放宽实时反馈/航向失效停止条件。
- 准备跑图、速度、开始/下一段/取消/查询移到地图页操作区，底盘页保留基础平移/转向与诊断。网页已知路线忙时禁用速度输入和重新启动；固件始终检查任务互斥。

## 验证

固件主机回归通过；网页70项、桥接20项通过；Keil template构建0错误0警告。新增覆盖坏帧后过期显示与同会话恢复、轨迹断开、错误会话隔离；速度上下限、运行中拒绝改速、下一段继承速度、低速超时预算。

独立8767预览服务未连接串口，浏览器验证地图操作区迁移与速度100生成对应指令。未烧录或实车运行。本次需要烧录新固件以支持带速度参数的start，并刷新控制台。

本次修复显示恢复机制，不代表DL-20链路丢字节根因已消除。现场仍需对比原始串口日志、模块参数与有线链路；实际速度、路线到位及低速完成时间需实车验收。
