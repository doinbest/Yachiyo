# 2026-09-14 同步取消后保留只读反馈

## 问题

运动中停车中断部分同步批次，运动锁sync_cache_uncertain有必要保留，但原实现同时停止四轮查询，无法取得停车后的新反馈。

## 修改

- motor_bus.c/.h：仅取消底盘0xF6/0xFD运动应答造成的隔离可开启只读诊断权限。只允许反馈所属模块向地址1..4发送严格格式的0x35/0x36/0x3A读取，不允许其他命令借此发送。原运动隔离保持。
- mecanum_chassis.c：CANCELLED运动锁下，停车发送结束后允许已开启的反馈轮询继续。正常取消反馈事件不把已停止状态改成发送故障。
- 迟到运动ACK功能码不同，不能完成当前反馈请求。实际UART错误、超时、发送失败会撤销隔离下的诊断权限，避免旧查询回复污染新的查询。
- 保留前一轮只读取消的旧回复接收/丢弃机制。机械臂、其他事务、部分同步缓存保护不自动解除。
- 停止确认仍需要已确认位置单位与新鲜完整反馈。此次未放宽阈值、未代填65536、未修改CubeMX或网页协议。
