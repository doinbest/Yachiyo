# 电机总线恢复与手动操作检查

用户问题：运动期间误发指令后，所有步进电机拒绝后续命令，原先只能重新上电。目标是拒绝冲突操作，并提供可检查结果的免断电通信恢复入口。

## 原因与边界

UART5 为底盘 ID1～4、Base ID5、Z ID6、X ID7 共用总线。旧代码对串口错误、超时和被取消的机械臂应答统一保留 quarantine，后续普通命令被拒绝。物理电机运动与一次通信事务忙是不同状态；未取得本次实车故障行，不能把所有故障都归因于误操作。

本次将机械臂及手动检查的只读 0x35/0x36/0x3A/0x3B 取消改为等待并消费原应答，等待期间仅允许优先停止；超时仍锁定。运动命令的应答被打断仍锁定，不重发相对运动命令。

## 使用方式

- 网页“系统与标定”和“视觉任务 → 单件抓取”顶部增加“一键恢复电机总线”“查看恢复结果”。分别发送 `bus recover`、`bus status`。
- 点击恢复后等待终端最终结果；它会停止当前任务和机械臂，保持夹爪 PWM 与 Z 使能状态，不复位 MCU、不自动归零、不自动续跑。
- `OK bus recover complete arm_ready=1 chassis_ready=1 ... tasks_resumed=0` 表示本次总线检查通过，可以重新下达命令。若原本回零被中断，须重新完成该轴回零并按原规则配置抓取参数。
- `chassis_ready=0 reason=chassis_cache_or_state_requires_reset` 表示共享通信已恢复，但底盘存在同步缓存或状态限制；机械臂可单独操作，底盘仍不可启动。实际复位驱动器后才可用原 `chassis reset-confirmed`，不能仅凭电机停住清除此限制。
- `ERR bus recover reason=... addr=... locked=1` 表示未恢复。根据地址检查供电、连接及驱动状态；修正后手动重试，不自动循环尝试。
- 需全部七台总线驱动器在线；未上电的总线分支可能持续产生 UART 错误。网页停止锁不会因恢复成功自动解除，恢复按钮本身可在该锁定下使用。

## 实现与协议依据

复用 `motor_bus.c` 状态机及事务队列，新增独立恢复 owner 和手动检查 owner，未新增工程源文件。

恢复顺序：取消自动任务并请求停止 → 等待其退出和在途事务结束（最多 10 秒）→ 关闭四轮轮询 → 等待 RX 静默至少 500 ms → 检查 UART DMA 重启结果 → 逐台发送非同步立即停止 `FE 98 00` → 逐台发送退出回零 `9C 48` → 再等待至少 500 ms 静默 → 三轮读取全部七台速度、状态、回零状态 → 符合条件才解除共享总线锁。恢复本体最多 8 秒，任何新串口错误、缺失应答或发送失败均终止并保持锁定。

检查条件：速度绝对值不超过 1 RPM，电机状态无堵转/保护，编码器及校准表就绪、不在回零、无过流/过热。回零失败标志允许保留，通信恢复不等于原点有效。三轮按逐台顺序执行，不能将其当作同时采样或实物夹取验收。

依据本地《ZDT_X42S 第二代闭环步进电机用户手册 V1.0.5》Emm 章节：第 60 页立即停止与同步触发，第 62～63 页退出回零、回零状态。停止命令不作为清除未触发同步缓存的证据；本次绝不发送 0xFF 同步触发来“清缓存”。底盘跟踪同步缓存是否可能存在，只有完整批次完成或实际驱动复位才清除该不确定性。

手动 `pos/home/zero/origin/disable` 在发送前读取对应轴速度、回零及故障标志，速度非零、回零中或保护状态时输出 `ERR manual axis_busy_or_fault ... command_not_sent`。只保留当前一次检查请求，后续冲突指令直接拒绝，不排队；停止取消待发动作。自动任务继续使用各自的反馈条件。查询不作为运动命令；正常忙拒绝不锁总线。

## 验证

主机模拟覆盖：错误后恢复、七台停止/退出回零、不重放运动、设备离线、仍在运动、驱动保护、回零未退出、RX 重启失败、新 UART 错误、取消恢复、停止打断只读事务后的迟到应答、底盘同步缓存保留、手动冲突拒绝、连续点击与停止取消待发命令、网页/桥接停止锁下的恢复入口。

固件主机完整回归通过，桥接回归 21 项通过，Keil Target `template` 构建 0 错误、0 警告（Flash 136280 B、RAM 42416 B）。日志分别为 `.embeddedskills/tests/bus-recovery-host.log`、`bus-recovery-web.log`、`bus-recovery-bridge.log` 和 `.embeddedskills/build/template-template-build.log`。

尚未烧录或进行实车恢复验收；超过 500 ms 的迟到回复不由无序列号协议证明排除，恢复静默窗口依托已确认的 Receive 应答配置，持续线路故障仍须排查实物。
