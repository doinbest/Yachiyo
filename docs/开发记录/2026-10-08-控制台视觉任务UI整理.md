# 2026-10-08 控制台视觉任务 UI 整理

用户要求整理控制台冗余内容、改善外观，并删除下方历史视觉诊断。

## 调整结果

- 视觉任务从一个长页面拆为编号环、物料取放、动态追踪、路线任务、仅识别五个标签，默认编号环。各模式只挂载一次，切换保留输入与展开状态，不发送设备命令。
- 编号环按视觉对准、人工装料、下降放置三步展示；对准和放置高度仍独立可调，默认−100/−150mm。
- 顶部统一读取任务状态与停止并退出入口，滚动后保持可见。状态区默认展示关键坐标、结果和原因，完整诊断按需展开；缺项和错误回复仍直接展示。更新反馈时保留诊断展开状态。
- 回零/总线恢复、取回/车载取出、库存核对和姿态辅助操作按需展开。指令预览、复制保留在“查看指令”中，执行按钮使用具体动作名称。
- 删除历史视觉诊断的页面构建和导航分支。旧history/legacy/calibration链接回到编号环；相关协议命令及固件模块保留。
- 机械臂页将车载转盘ID8与机械臂车载放料分开，避免把grab place car理解成转盘分度。
- 同步模块README、根目录入口和协议文档。未修改固件、视觉程序、串口通信或动作参数。
