# 关闭物料任务底座自动回零（2026-09-27）

用户计划抓取时保持机械臂底座 Base 不动。原 `material auto` 在启动后会发送 Base 就近回零命令，并等待回零到位；这会改变底座姿态，也增加抓取准备时间。

现已移除该任务内的 Base 回零、等待和超时状态。`material auto` 在确认视觉参考及执行器空闲后，直接请求物料识别并启动底盘搜索；Base 保持当前姿态。单独的 `home {axis} {mode}` 是操作者显式发出的机械臂回零命令，仍保留。上电流程未发现机械臂自动回零；HWT101 的 Z 轴角度归零是 IMU 操作，不是机械臂运动。

主机测试增加了 `material auto` 启动时 Base 回零调用次数为零、旧 Base 回零事件不被任务消费，以及相机和底盘启动失败的检查。固件主机回归与网页回归通过；Keil 构建通过。尚未烧录或进行实车验证。上板时应先确认 Base 当前姿态、相机参考点和夹爪周围空间，再启动 `material auto`。
