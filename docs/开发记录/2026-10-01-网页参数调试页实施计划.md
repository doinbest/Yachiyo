# 网页参数调试页实施计划（2026-10-01）

目标：把视觉抓取参数和三轴运动配置集中到独立网页页面，明确显示待输入值、设备读回值和本次写入结果；复用现有指令，不改 STM32 的底层底盘宏。

1. 增加纯协议测试与参数交换模块：解析 `grab get`、`config <axis>` 的回复；写入后串行读回，断开或超时不显示“已生效”。
2. 增加网页导航与参数页面：抓取参数按已有分组展示，每行读取/应用；Base、X、Z 运动配置按轴读取/应用；路线速度说明并指向现有启动控件。
3. 保留原停止优先级、连接时不自动读写、运行中由固件拒绝参数改动。页面在停止、断开和主控重启时清除等待中的核对。
4. 更新控制台说明；运行 Node 和桥接回归，检查无串口实际写入或自动运动。

实现：新增 `parameter-console.mjs` 负责串行读回、数值匹配与取消，`parameter-page.mjs` 负责独立参数界面；新页面复用固件现有命令，不改 STM32。写入和读回被分开显示，`OK grab set` 本身不视为应用成功。路线速度只同步网页下次启动输入框。

验证：网页 Node 测试 128 项、桥接 Python 测试 26 项通过；`app.mjs`、参数页面与参数交换模块语法检查通过，`git diff --check` 通过。页面挂载测试确认打开页面不发送串口命令，路线速度保存只更新网页输入。未连接实车串口，本次没有执行实机参数读写。
