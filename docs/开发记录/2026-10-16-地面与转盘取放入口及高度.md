# 地面与转盘取放入口及高度

2026-10-16，用户要求地面放置/夹取改为120 mm下降、入仓下降20 mm，整理物料取放UI、移除上方持料继续入仓按钮，并区分地面和物料台转盘入口。保留其他对话的现有工作区修改。

## 实现

- grab_parameters.def将共享z_proc_place默认从−140改为−120 mm，覆盖加工放置/取回及第一层暂存；第二层z_stack_place保持−110 mm。z_place现有−20 mm及track_store_drop_mm现有20 mm沿用，网页两个入口均按用户填写值显式写入并读回。车仓取出car_pick_drop_mm仍40 mm。
- 新增grab store ground <slot 0..3> <color 1..6>，复用比赛加工取回的高位静态视觉对准、固定下降、Z到位闭爪、提起收X、ID8/Base及入仓记账；抽出共享入口以免为独立地面物料伪造编号环号。自动选仓按库存，明确仓位保持原规则，第三盘避让沿用比赛处理。原grab store proc固定夹取语义保留。
- 地面入口采用z_proc_place，转盘追踪仍采用z_grab（默认−50 mm）；地面参数写入不覆盖转盘夹取高度。地面转移高度z_car_lift默认0，入仓绝对放料Z默认−20；转盘默认从−50抬升50 mm到0，再下降20 mm。
- 夹取下降速度使用与正式比赛相同的z_pick_speed，当前默认250 mm/s；Z运动继续读取当前驱动配置的加速度档位（默认255），不增加MCU余弦周期调速。没有把驱动档位当成mm/s²。
- 主卡片改为“物料夹取与入仓”，提供“转盘夹取并入仓”和“地面夹取并入仓”；保留准备、状态和停止，移除上方“将已夹取物料入仓 / 继续入仓”。单独追踪、条件读写、记录和导出放入折叠区。原持料恢复命令保留作诊断接口。
- 同步元数据、控制台帮助、现行规则、比赛约定、主车入口、视觉操作及机械臂协议。历史开发记录保留当时高度。
