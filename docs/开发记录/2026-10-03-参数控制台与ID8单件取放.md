## 实现

- 参数调试页五标签全部展开，蓝色深色背景、保留浅色偏好、最多三列卡片、固定两行结果栏。设备框初始未读取，73 项设备值包括 46 个 grab、8 个 turntable、9 个普通轴配置、10 个雷达参数；路线待用速度是浏览器本地设置。
- 顺序读取覆盖所有设备组，雷达整组分页一次；应用只写当前标签改动，等待受理后主动读回比较。设备拒绝、取消、部分成功与草稿分别显示，断线/重启标历史。
- 视觉、地图、雷达与参数页通过上下文链接往返，保留来源子页/滚动、地图视角/来源、视觉选项和草稿。导航无 TX；离线模拟返回后仍暂停。
- `App/turntable.c/.h` 为 ID 8 独立业务和 MotorBus owner。三仓、1∶1 直连，首仓参考 0°，其余角度未设置；人工对齐后软件采参考，不 home/zero。支持分度、点动、停止、参数、状态及库存校正，库存保留原 B2 色号 1～6。
- 分度使用实际位置求最短方向，指令 3200 脉冲/圈、反馈 65536 单位/圈。预约只覆盖短事务，每轮反馈之间释放总线，不阻断机械臂与轮反馈。到位要求新鲜位置/速度/状态、使能/到达标志及稳定条件。
- 新增加工夹取/抬升、车载取出抬升、粗加工/暂存两层释放目标、`x_car` 和 `base_car_offset`。界面以正数下降及相对抬升显示，协议保持绝对负 Z。未标定场景不阻断其它场景。
- 入仓与取出先抬 Z、收 X，再分度和转向；取放完成返回保存的实际 Base/X/Z 外侧观察姿态，释放任务占用。`align` 仍 HOLD；`pick` 共用其视觉宽限与停稳恢复路径。组合路线只等待首件入仓完成，不扩展两批赛事调度。
- 停止覆盖 ID 8、保持夹爪输出和 Z 使能；涉及仓位中断后待核对，普通停止保留标定、完成结果和库存。局部 `grab return` 依据保存参考及新反馈返回，不强制回零。

具体命令、九种距离及 RAM 默认值见[当前协议](../上位机协议.md)，操作界面见[控制台手册](../../Code/upper-computer-web/local-car/README.md)。
