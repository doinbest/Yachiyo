# 串口屏任务码显示适配（2026-09-23）

当前 `HMI/display.HMI` 的 `main` 页使用 `tTaskTop`、`tTaskBottom` 两个文本控件显示任务码，初值分别为 `---+---+` 和 `---+---`。固件收到 UART4 二维码模块输出的 `DDD+DDD+DDD+DDD` 加回车后，仍由 `QR.c` 校验，再由主循环调用 `ContestScreen_TaskCodeSet()`。屏幕模块将任务码前 8 个字符发送到 `main.tTaskTop`，后 7 个字符发送到 `main.tTaskBottom`。

页面上的 `tGrab`、`tPlace` 文本包含“正确抓取数：”“正确放置数：”标签；刷新计数时保留标签。当前 HMI 没有 `tState`，固件不再向它发送命令。USART3 沿用 115200 波特率，发送命令末尾由驱动追加 `FF FF FF`。主循环仍按现有调度条件刷新串口屏。

验证：`tests/contest_screen_test.c` 检查初始显示、任务码分行、计数标签和重复扫码不重发；`python tests/run_firmware_tests.py` 通过；Keil `template` Target 构建为 0 错误、0 警告。尚未烧录或在实物串口屏上验收。
