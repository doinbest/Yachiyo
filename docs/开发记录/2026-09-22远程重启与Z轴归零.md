# 远程重启 STM32 与 HWT101 Z 轴归零（2026-09-22）

## 需求与实现

用户要求类似主板 RESET 的远程主控重启，并增加独立 HWT101 Z 轴角度清零。修改前 Git 检查点为 `fc96e72`，保留用户现有 Keil 工程及未跟踪资料。

- `system reset`：控制台空闲检查 → 紧急受理回复 → 等待 USART1 DMA/TC 完成 → 200 ms 无线留时 → CMSIS `NVIC_SystemReset()`。发送失败或 5 秒超时取消；等待期间主循环继续服务控制台，暂停业务生产者；Ctrl+C 或合法的底盘/机械臂/视觉停止取消尚未执行的重启。不会向外部电机驱动器发送复位，不改变硬件配置。
- `imu zero`：复用 HWT101 标定模块已有解锁及 CALIYAW 非阻塞步骤，独立执行归零并等待新样本；不写零偏、模式或 SAVE。结果 `ZERO_SAMPLE` 表示写入后收到新角度，不表示漂移验证通过；终端输出 before_deg/after_deg。
- 单独归零撤销旧 IMU 控制资格；现有航向采集与定位流程随后撤销地图锚点。跑图前重新静止验证、设定地图起点。
- 系统页增加清零按钮和折叠的主控重启区；重启发送前显示用途确认，手动终端及常用入口也经过相同确认。串口未连接或本地服务停车锁定时不可发送。
- 收到 STM32 启动信息后，网页清除旧模块状态、反馈与准备状态。二维码及遥测订阅须手动重新开启。

归零依据沿用已核对的本地 HWT101 IIC 协议截图及官方上位机命令：详见[验证前归零记录](2026-09-14IMU验证前Z轴归零.md)。本次未引入外部源码或依赖。

## 实物待验

忙判定只覆盖软件任务与通信事务；机械臂位置/回零请求的 ACK 不代表实体运动结束，不能以软件忙标志替代人工确认静止。审查后补齐合法机械臂/视觉停止取消待执行重启的回归。

本轮未烧录、未发送实物命令。需烧录后在整车静止、任务空闲时验证：重启后启动信息与 USB CDC 重连；HWT101 清零后的实际角度；重新验证及地图准备。STM32 重启会重新初始化 GPIO/PWM 等片上外设，但不对 HWT101、驱动器、香橙派断电；无线 ACK 留时不保证远端接收。主循环卡死或链路失联时此命令不可替代实体 RESET。
