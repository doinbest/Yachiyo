# 底盘双模式对照测试与 X/Z 固定档位恢复

## 实现

- 修改前版本已保存为 Git `bc13310`。本轮在当前路线基础上增加模式选择，不回退路线几何和现行任务流程。
- 直线默认 linear，300 mm/s²；可选 cosine，K200、名义400 ms。保留1000 mm/s默认路线速度、局部限速、连续曲线与原地转向控制，以及新鲜反馈停车判定。
- 比赛和底盘单段测试各自提供选择；比赛受理后保存模式，暂停、继续及通信恢复保留，独立测试不能覆盖待续接比赛。
- 独立测试按本页受理动作编号显示模式、实际耗时、轮反馈峰值合速度、终点误差和末次停车确认耗时。重连保留历史显示并清除绑定；新动作重新绑定。
- 固定X/Z恢复场景速度和驱动配置档位，默认X20/Z255；移除固定动作余弦更新器。连续视觉控制及抓取/入仓/加工流程保持。
- 完整固定码加模式需要超过旧63字节限制，固件、网页与Python服务同步为最多95字节、10字段。
