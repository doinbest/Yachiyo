## 判定依据与实现

| 项目 | 右上（赛题启停区1） | 右下（赛题启停区2） |
| --- | --- | --- |
| 名义车辆中心 / mm | (2250,2250) | (2250,150) |
| 名义航向 / °，从+X逆时针 | 270 | 90 |
| 默认雷达参考 / mm、° | (2330,2170,0) | (2170,230,180) |
| 返程接驳点 / mm | (2100,2100) | (2100,300) |

起点几何来自项目赛题资料，用户确认车头朝二维码台方向。雷达安装沿用既有参考预设，尚未实测。上方参考按同一安装关系由下方参考推导：`x=4500-lower_x`、`y=2400-lower_y`、`zero=lower_zero+180°`并归一化；10项既有RAM参数含义保留。

`radar_start.c`使用两个流式计数图，每个完整原始样本同时投影，不受4096点显示缓存限制。二维码前方格为bit14：X∈[1850,2250)、Y∈[1000,1400)；原料台前方格为bit22：X∈[1000,1400)、Y∈[1850,2250)。保留既有同格阈值（默认3）和距离、角度、能量筛选。

1. 完整圈结束，先按原始计数生成两个候选障碍，记录两格冲突及点数。
2. 只有一个候选无冲突才选该候选；都无冲突为`ambiguous`，都冲突为`both_conflict`，不强行选右下。
3. 选定后仅豁免上述两格的扫描障碍，保留原始计数、固定四障碍；其他实测障碍照常参与规划。离线人工编辑的障碍mask仍为权威输入。
4. 同一任务工位顺序`1→5→4→2→3→4→2→3→1`，首末点及返程接驳点采用所选起点，station/visit语义保持。

这套判定依赖赛场必空条件及名义摆放。二维码板侧面、遮挡或实际扫描平面可能缺少区分证据；工作室杂物环境不满足赛事假设，可使用原人工参考扫描检查点云。

## 命令与网页

| 命令 | 用途 |
| --- | --- |
| `radar scan auto` | 静止采一圈、比较两起点；网页主按钮“自动识别起点并建图” |
| `radar start status` | 只读最近完成圈证据，可在网页停止锁定期间查询 |
| `radar start upper` / `radar start lower` | 人工选择完整自动圈候选，复用同圈数据重新发布地图和规划 |
| `radar scan` | 原人工下方参考扫描，保留既有反馈位姿投影 |
| `radar status` | 状态、三页诊断及最近完成圈起点证据 |

新增`k:start`两页，`selected=0/1/2`表示待定/右上/右下；`qr/raw/conflicts`均按[右上,右下]排列。先完整拼齐再显示；详细原始计数保留在诊断和原始日志。路径各页新增numeric `start`。扫描受理后立即报告实际采集状态，首次无基线也能可靠跟踪本圈；所选结果完成后立即报告起点证据和状态，网页自动连续读取地图与路径；点云另按需下载。

无法区分的完整圈只增加scan编号，保留旧map/plan和真实地图年龄，applicable=false；本圈完整原始点云保留在固件，但未选定前不附加到旧世界地图。手动选择增加map/plan、不增加scan，地图年龄来自采集完成时刻。新扫描开始后旧候选不可再选择；坏帧、单位变化及DMA覆盖的重采会同时清空当前两个候选计数。普通停止、重连和失败保留完整历史地图。

实车执行仍检查右下准备流程。右上`nav/task start`回复`upper_start_plan_only`；未确定回复`start_unresolved`，网页显示具体原因。离线HTTP服务和CLI使用同一`radar_start.c`/`radar_map.c`，支持`start_mode=manual/auto/upper/lower`；右上只提供几何路径，实际行驶阶段预览仍保留原固定右下模型。导出、导入和复制离线地图保留地图所属起点；上方世界位姿与下方安装参考分别处理，避免重复旋转点云。未编辑的离线初始值不覆盖设备地图。

## 用户上板顺序

1. 用户烧录新`Code/template/MDK-ARM/template/template.hex`，重新启动本地控制台服务并刷新网页；本轮未烧录或发送实车指令。
2. 分别在两个名义起点静止采集，点击“自动识别起点并建图”。检查所选起点与实际一致，以及路径首末点和障碍格；按“读取起点结果”或`radar start status`保存原始证据。
3. 未确定时在实际已知起点点击人工选择，确认scan不变、地图/规划更新且自动显示；不必重扫。检查夹杂障碍和遮挡时的判断。
4. 两起点分类、安装偏移和实际通行空间先实测验收。当前右下路线可沿既有低速验收顺序显式运行；右上只检查地图与路径，不执行实车路线。

软件测试、合成回波和编译通过与实物识别正确率、无线耗时、碰撞空间及比赛完成率分别验收。
