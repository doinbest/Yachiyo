# 比赛与取放现行约定

上位机新比赛统一采用高位Z=0对准并开启视觉航向矫正，不提供高度或矫正开关选择；比赛页和通用上位机比赛启动入口均显式提交vhigh。转向速度默认100°/s，允许5～360°/s，固件显式转向及路径参数同范围；旧终端显式对照入口保留，暂停/继续保留设备已受理的本轮设置。

视觉漏检/正常对准停车与ID8提前分度并行时，停车仍有优先权。若ID8纯位置/速度/状态/HOME状态读取被取消且总线未隔离、无UART错误，保留原目标、阶段、参考、库存和计时，仅重采完整反馈；不因查询取消退出比赛，不重发运动、HOME、使能或保存。旧回复排空期限和新鲜稳定判据保持，反复抢占不能延长原运动/HOME时限。真实故障及显式停止/暂停/终止沿各自原规则处理。详见[实施记录](开发记录/2026-10-17-ID8反馈查询被停车抢占修复.md)。

静态视觉提速采用连续静止证据衔接与提前识别：仅ALIGN已完成稳定窗口后的本流程正常停车，可保留三轴/四轮连续静止的累计时间；仍须停车发送完成后的新鲜三轴位置/状态、四轮速度/位置/状态及真实接收在停车后的新在窗B2，不能用旧反馈或解析时间代替。运动、新运动序号、失鲜、漏检、越窗、暂停及人工停止撤销衔接，恢复完整稳定核验。正式加工放置/取回、暂存第一层/第二层在换环及机构准备期间提前请求本件目标，准备完成后保留同请求数据流，只接纳观察姿态就绪后的新接收坐标；不重复请求、清空编号环追踪或使用准备期坐标完成。暂停、取消、故障及参考变化取消预备；航向观测完成后才准备位置识别。λ、速度、制动、像素容差及200 ms稳定参数保持。

静态视觉恢复重发前，Camera_RestartIfMissing在USB中断边界再次检查本请求目标、暂停/请求边界和真实接收年龄；已恢复的有效坐标保留，尚未解析的USB输入先交回主循环解析，不发送新请求、不清缓存。只有持续无有效坐标才沿原流程重新请求，仍共用本轮vision_wait_ms期限；正常显式开始/换目标继续刷新。无效后有效的同批新坐标应直接参与纠偏，不依赖有限目标的定位基线，但重置稳定计时；任意合格新有效帧结束旧漏检计时。有限目标基线只决定漏检时能否按实测剩余位移续调，最终完成仍须新鲜在窗观测、稳定与真实停稳。

静态漏检恢复保留“有限目标实测续调；无基线时沿原趋势减速、默认250 ms宽限”的现行控制。因近窗口、方向变化或宽限耗尽停车后，如果原目标新鲜有效坐标已恢复，取消待重识别、保留原流，不再无必要重发B2/0A；仍须停稳和恢复起点后3次新观测才能续调。旧缓存不算新帧，持续失联仍受原vision_wait_ms恢复窗口限制（默认12秒）。该修复不修改底盘None、机构应答、J、速度、稳定参数或视觉端部署。

Z任务速度统一默认250 mm/s：扫码升降、夹取下降、抬升、放置和入仓共用z_speed；保留z_pick_speed、qr_z_speed兼容键，显式设置任一项同步三项。普通手动Z默认2250 RPM（按480脉冲/mm折算250 mm/s），驱动加速度档位默认0（直接按目标速度运行，不使用驱动曲线）；显式手动调速保留，HOME仍使用驱动回零参数。网页开始夹取前统一写入并核对三项，读取时分别显示设备实际值；刷新/重连不自动写入。

当前比赛与后续调试采用linear，用户当前不使用余弦加速度模式。本文余弦路线及参数描述保留为兼容参考，不作为当前整改或验收目标；P010（余弦+雷达标准开局丢失连续曲线）不再安排修复，状态不是已修复。若将来重新启用该组合，需重新核对标准开局。linear雷达路线的加工离站净空等问题仍保留原处理要求。

动态X绝对前瞻按需切Receive，仅RAM修改并读回；固定Base/Z/X/ID8同样使用Receive及默认200 ms实际反馈到位，不再来回切换。恢复过程已取消的底盘位置动作不因暂缺定位重新失败，实际停车和续接定位分别取证；人工暂停在stop_wait等阶段也撤销自动续跑，不丢本轮进度。[现场故障修复](开发记录/2026-10-16-动态追踪通信中断与恢复停车修复.md)。

加工/暂存及其它静态颜色、编号环协同对准按香橙派新有效B2帧更新，取消正常水平纠偏及显式低位Z目标的100 ms门槛；总线忙时仅保留最新未处理帧，空闲后续接，旧快照不重复积分。保留视野、机构边界、漏检恢复及原视觉稳定/真实停车完成条件。共享静态λ默认2.5 s⁻¹，可在上位机“仅协同对准”处显式读取、应用并核对；不覆盖原料追踪独立λ。详见[B2静态调度协议](协议/视觉B2与动态追踪.md#静态协同对准的新帧调度与λ)。

正式比赛linear采用分段参数，独立测试仍按网页本次填写值。正常linear直线收尾先在到点窗口内将平移参考降到零，再请求同步零速和新鲜停稳确认；人工停车、取消及故障响应保留。

正式比赛正常路线到点以停车发送完成后的两组新鲜四轮速度/位置反馈确认，先补读驱动状态，再优先轮转速度/位置；普通独立MoveTo与独立停车监控仍三组。保留各轮≤±1 RPM、相邻位置变化≤2 mm、发送完成与到点/航向检查，不使用额外500 ms稳定等待。人工停止、取消、故障及恢复保持独立处理。视觉夹取和机械臂的稳定时间不随本次停车提速改变。

X/Z固定目标动作使用当前轴配置的驱动加速度档位，默认X0、Z0（直接按目标速度运行）；场景速度和有限绝对终点保持，MCU不再周期重发余弦调速。视觉连续纠偏、渐进下降、回零、Base和ID8沿用各自控制。到位、停稳、机械限位和驱动故障检查保留；Z先抬到0再收X，取仓避让X30 mm并行规则不变。

底盘直线平移提供linear与cosine两种模式：linear为默认，普通MoveTo加减速度300 mm/s²，正式比赛按路段起步500/800/1000、停车300 mm/s²；cosine为K=200、名义400 ms半余弦速度过渡，短段降低峰值；余弦保留半余弦起步与距离制动参考，位置P收敛按反馈和驱动响应时间降低有效增益；同一平移段保留已观测的最大反馈年龄作为制动预算，避免新反馈突然放宽限速。反馈引起的速度矢量变化受该段曲线峰值加速度约束，末端接近速度按到点窗口和延迟进一步限速，避免目标前提前归零后反复补走。两者都计入反馈年龄和驱动响应的制动余量，共用1000 mm/s路线默认速度、工位局部限速、位置/航向及新鲜停稳判定。除线性模式恢复分段开局外，其他连续转弯和原地转向保持现行独立控制。比赛启动选择模式并冻结，暂停、继续与通信恢复保留；省略选项为linear。连续转弯保留原向量变化率300 mm/s²及角速度/跟随限速，退出弯道后从当前速度接入直线规划。保留工位局部50 mm/s限速与到角减速；浏览器已有显式保存速度不被覆盖。夹爪闭合、释放及车仓开口后等待分为close_ms、release_ms、car_pick_wait_ms，默认均100 ms，可分别调整。Z仍升到绝对0后才收X，加工区三件取回顺序不变。固定转移目标已由新鲜正常静止反馈确认时可省去重复位置命令；已完成任务与姿态准备可移交仍新鲜的静止证据。反馈过期、运动或暂停后重新核验；视觉修正与下降取放不省略目标指令。

Base参考建立统一使用单圈就近回零（mode=0）：上电及`grab rehome`保留Z/X验证、开爪和ID8就绪后再启动Base的原有顺序，直接使用驱动已保存的机械零点，不做自动方向参数改写。首次使用或驱动重置后先在正确车仓姿态设零，后续仍以新鲜HOME/位置/使能及停稳反馈验证参考。手动`home base dir`仅保留显式测试入口。

## 正式linear比赛分段速度

分段速度为本轮路线速度与下表上限的较小者；因此比赛填200时不会被分段表提高到700/800/1000。参数在路线阶段生成时确定，暂停、继续及通信恢复沿用该阶段参数。按工位/visit及生成阶段几何识别，不使用可被雷达绕障改变的固定路点序号。

|---|---:|---:|---:|
| 短斜移（≤300 mm，含右下出发和最终返回） | 500 | 300 | 300 |
| 右下起点转向后的扫码直线：(2100,300)至本轮扫码Y | 800 | 300 | 800 |

第二批中心到原料台仍走独立连续曲线，向量变化率300 mm/s²，现有60 mm/s参考限速及跟随限制保留；不把它称为已按800/1000提速。cosine模式保留K200及原路线/曲线参数。直线航向默认P0.1/D0，原地转向独立P0.1/D0，角速度默认100°/s、显式请求上限360°/s，500 ms起步过渡及到角/停稳检查保留；±0.1°直线纠偏死区及±0.50 rad/s限幅保留。上述分配同样用于正式固定/雷达路线生成阶段；非标准绕障的小段按实际阶段几何分类，实际扫掠及高速通过仍须实车核验。

## 起点定位、扫码与雷达

正式linear右下标准扫码离站的实际航向已在90°现有容差内时，直接平移，微小角误差交给航向保持，不建立独立转向等待机械臂。标准扫码点→(2100,2100)→首批原料台(1200,2100)在进入右上角10 mm窗口后连续衔接左移，车头保持90°；运动层保留速度参考、反馈、action_id及整体期限，路线层仅采纳过点事件更新阶段，不假报停车。左移持续修正Y=2100并保留800/300及700 mm/s上限（受本轮速度约束），中间点不发送停车或累计停稳组；到物料台仍停车后转0°并准备作业。过点前后暂停保存各自目标，继续不重走已过中间点。仅实际标准三点及linear条件启用，绕障、其他工位与独立测试保持原衔接。

加工区到暂存区等后续“直行＋横移”路段先记录为候选，不在本次连续化；后续须分别核对车头朝向、真正转向/作业停车边界、完整车体投影及暂停恢复。见[待办P013](待解决问题.md#p013--后续直行与横移路段连续衔接候选)。

- 右下车体中心(2250,150)、yaw=180°（与−180°同向），右上(2250,2250)、yaw=−90°。STM32自动选择四轮反馈，取得本轮新鲜静止反馈及已验证IMU；符合所选起点的有效定位直接复用，否则建立本轮定位。缺反馈短时等待、恢复后自动推进，不复位IMU、不让网页拼接准备指令。
- 普通暂停继续保留有效原点。尚未出发时IMU中断使原点失效，恢复验证后可局部重建；已出发阶段不借此重设起点。

## 暂停终止与通信恢复

- 恢复停车的独立停稳采集与正常到点采集期间暂停后台应答配置，后台不能插入新的读写准备；紧急停车仍优先。纯参数读取被取消先按原期限排空，写后验证取消则保存预期快照、后续只补验证，运动及参数写入取消保护不放宽。进入恢复前记录当前触发故障的ID/指令/接收证据，区分初始丢应答与后续停车取消。

- 普通四轮3A单次漏答先在原事务内有限补读一次，原阶段不立即因这一次漏答结束；补读状态按首次TX保守计龄。完整停车应答、迟到及异步通知后也满足原2 ms普通交接；DMA半帧静默2 ms后放行，期限检查避免TX IRQ时间下溢；紧急停车不等该交接。二次失败仍走原恢复，不重放动作、放宽机械故障或以旧反馈冒充停稳。

## 视觉航向校正测试分支

普通行驶新增的±0.1°航向纠偏死区不作用于本视觉分支。自动视觉航向校正和按视觉角单次试转仍使用独立精确转向接口，不因普通行驶死区放弃小角度修正；保留各自现行精度、有效观测及新鲜停稳判定，不把完成容差改成0或无期限追转。

航向采样使用独立5秒窗口，从机构停稳、开始请求时计时；漏检、USB重试及采样组重置不延长截止时间。允许间断有效帧累计，至少3个不同序号且接收时刻递增的新鲜样本；最后一帧必须新鲜。正式比赛色环使用已确认反号1∶1策略，以0.3°图像差取三帧平均；其它独立已标定核验使用head_spread比较换算后的角度，未标定/独立观测仅取图像角，不套用未验证参照。无效/缺失帧不清空已有有效样本，不一致则重建采样组；机构运动后旧样本作废。5秒内证据不足报告heading_no_observation并沿用原航向继续。尚未成功提交的校准也受该截止时间约束；已采用校准或开始转向后仍完成运动和停稳验证，不以采样超时跳过。人工暂停后重新给予观测窗口，普通物料视觉等待参数不变。

比赛视觉航向开启时，每次进入加工区或暂存区启动一次航向观测：加工区两批及暂存区第一批使用色环B2/0D，暂存区第二批码垛使用色环前方黑线B2/0E；区内换环、逐件放置和逐件加工取回不重复。新增加工离站复核：两批加工各在第三件取回入仓、释放和库存记账完成后，空爪返回完整作业观察姿态（抬Z、收X、Base作业角）并补齐新鲜停稳证据，再用色环B2/0D按既有反号1∶1/IMU闭环矫正一次。完成或按原规则结束观测后，才请求Base行驶姿态，沿原Y425退出路线到点停稳并确认完整travel_ready后再转底盘。不能仅凭X/Z避让就绪跳过Base观察姿态，也不在最后一件stored前或持料遮挡时观测。第二批再次进站仍重新观测；每件位置对准、暂存离站、独立测试及关闭本轮视觉航向时的流程保持。暂停、继续与总线恢复保留离站阶段、已完成记账和后续行驶姿态目标。

准备阶段Z已高于`z_car_lift`时保持实际高度，不为满足等值检查而下降；实际坐标与配置目标分别保存，后续绝对下降、明确参考的相对深度及暂停续接不得漏算高度差或重复累加。航向观测允许更高的静止姿态，自动校正仅使用与实际观察高度匹配的标定；高度不匹配只观测并回显实际Z，保留原映射和标定。暂停时间不消耗恢复后的观测窗口。见[修正记录](开发记录/2026-10-14-航向观察高度与暂停窗口修正.md)。

摄像头会随Base/X/Z运动，不能按固定车体相机建模。已有比赛流程负责机构朝向色环，视觉航向观测在对应姿态到位静止后采集；IMU测角已确认准确，校正解决摆车角与地图名义角不一致，更新IMU到地图映射，不重置IMU。

上位机比赛任务固定开启视觉航向矫正，不再提供关闭选择，与两批原取放顺序对齐；固件旧终端省略选项保持原兼容行为。上位机统一提交高位vhigh，本轮锁定并在暂停/继续时保留；固件终端显式对照选项仍兼容。新版0D四个数据槽为EX/EY/EA_X100/STOP，不能按普通CX/CY/DX/DY处理；STOP仅表示图像角进入±5°，仍持续输出实际角误差，不是精确零角、物理停车或地图校准证据。

色环B2/0D与黑线B2/0E按独立目标请求和匹配，保持14字节回复，保留STOP字节和报文校验，STM32可不使用该标志；仅作可选诊断，不以STOP决定运动、稳定、完成或失败。控制以对应参照的已确认零偏角为目标（正式色环为0°，黑线按独立标定），独立核验有效观测、实际精度与停车；人工暂停/停止和真实驱动故障处理保留。

正式比赛开启视觉航向时，色环B2/0D采用用户已实测确认的反号1∶1关系（视觉+α→底盘相对−α），不再要求手填head_proc/head_temp映射参数；零点0、比例1仅为本次色环策略，不写入RAM标定参数。仍需原观察高度匹配、可靠Base参考、完整作业姿态及新鲜静止反馈。取3帧新鲜一致角度、最大差0.3°，视觉残差≤±0.2°时通过；需要转动时同步地图航向，再用IMU独立P0.1/D0闭环转正，单次转角到位±0.1°、500 ms起步，角速度上限min(本轮转向上限,10°/s)，停稳后重新取帧复核。黑线B2/0E不套色环实测关系，仍使用独立标定；独立普通核验/观测及单次试转保持各自语义。 原“未标定只观测”在正式色环分支被覆盖，历史实施记录保留当时事实。实现、回归与下载结果见[实施记录](开发记录/2026-10-14-比赛视觉航向分支实现与验证.md)。方案、实施、部署与实车分别报告，详见[方案](superpowers/specs/2026-10-14-色环参照校正地图航向方案.md)、[修改计划](superpowers/plans/2026-10-14-比赛视觉矫正分支修改计划.md)及[视觉接入分析](开发记录/2026-10-14-新版视觉代码收录与工位校准接入分析.md)。实车标定、视觉端部署及完整比赛验收分别完成。

独立测试入口为“视觉任务 → 航向矫正”：上电后可直接在色环前摆偏，复用空爪准备姿态，再显式启动工位航向测试。无定位时建立本地测试基准，已有有效定位保留；不启动比赛、不更改库存。普通核验未标定只观测；另设用户显式启动的“按视觉角单次试转”，按当次新观测角乘方向+1/−1转一次，停稳后复测，不连续追转、不写入标定或重设地图角。默认反号（−1），依据加工区单次试转结果；独立入口不写入完整映射，正式色环已按用户确认复用此关系。停止后结束本次独立测试。见[实现及操作](开发记录/2026-10-14-独立视觉航向测试.md)。

黑线与色环共享图像水平0°和右端向下为正的约定。黑线实际车体角映射使用独立的`head_line_zero/head_line_gain`，不借用暂存色环参数，默认均未标定；观察高度与停稳证据沿用原流程，未标定仅观测。黑线只用于暂存区，独立测试可显式选择，比赛第二批码垛自动选用。场地前后位置不等于透视零点已标定；实车对照验收另记。
