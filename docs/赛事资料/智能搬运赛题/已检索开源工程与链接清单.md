# 已检索的工创赛智能搬运工程与链接清单

整理日期：2026-10-16。

串口总线张大头步进电机的专项对照见[串口张大头步进多机控制对照](串口张大头步进多机控制对照.md)，仅采用已确认UART调用链的6项参考，不混入CAN、脉冲底盘或直流电机。

从项目历史研究报告、后续专项记录和本对话可确认，共有 **28个仓库或项目来源入口：GitHub 26个、Gitee 2个**。其中包括完整控制工程、视觉程序、邻近AGV参考和资料索引，并不等于28套独立、完整且已验证的比赛程序。`enginer-train`旧作者地址与新地址合并计为一项；同源项目仍分别列出仓库，但注明关系。
