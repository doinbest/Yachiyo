# STM32F103C8T6 物料台转盘

## 当前入口：上电串口直发（2026-09-25 再次切换）

按用户最新要求，`main.c` 调用 `Turntable_BootInit/Process`。上电等待 1 秒发送使能，再隔 100 ms 发送 8 RPM 顺时针连续旋转指令，各发送一次，不等待回包、不读取按键、不执行分度和停留。

停止测试需切断电机电源，单独复位 MCU 不保证停车。Keil Watch 的 `Turntable_BootStatus` 记录发送尝试和 HAL 返回结果，不代表驱动器应答或实际转动。原双按键模块保留但不调用；以下分度控制说明适用于该保留模块，当前入口不启用。

## 已确认的硬件与默认参数

| 项目 | 配置 |
|---|---|
| 主控 | STM32F103C8T6 蓝色最小系统板 |
| 时钟 | HSE 8 MHz，PLL ×9，HCLK 72 MHz，APB1 36 MHz，APB2 72 MHz |
| USART1 | PA9 TX → 驱动器 RX，PA10 RX ← 驱动器 TX，共地，115200/8N1 |
| PA15 | 按下接 GND，上拉输入，启动/停止 |
| PB3 | 按下接 GND，上拉输入，停止状态单步换位 |
| PB4 | CubeMX 已配置上拉输入，但未焊接、不读取、不分配功能 |
| 下载调试 | 保留 PA13/PA14 SWD；已关闭 JTAG |
| 电机 | Emm 固件，其余默认；单机默认地址 1，默认 Receive 应答 |
| 机械传动 | 电机与转盘 1:1 直连，三个料盘均匀相隔 120° |
| 速度 | 8 RPM，匀速段折算 7.5 秒/圈，不含启停和停留时间 |
| 停留 | 每次确认到位后 2000 ms |
| 方向/加速度 | CW（协议方向 0），Emm 加速度档位 10 |

## 使用方法

1. 在断电、可自由调整时，把一个料盘摆在远离小车的一端，另两个对称靠近小车，呈人字形。随后上电，等待至少 1 秒。
2. 上电不发送运动指令。首次有效按键操作时，读取电机当前坐标，作为本次人工摆放起点；不发送清零或回零指令。
3. PA15 按一次启动自动运行：首次 60°，到位停 2 秒；以后每次 120°，到位停 2 秒，循环运行。
4. PA15 再按一次请求停止。旋转中停止会保留未完成的目标；再次 PA15 启动，或 PB3 单步，先完成原来的目标。停留中停止，下一次启动直接前往下一工位。
5. PB3 只在空闲停止状态有效：首次单步 60°，后续单步 120°，到位后不会自动再动。运动或自动停留期间的 PB3 不排队。
6. 两键均为按下触发、20 ms 消抖；按住只触发一次，没有长按回零或连发。上电已按住的键须松开后重新按。
7. 重新摆放起点时，先停机、断电调整，再重新上电。运行期间不要挪动料盘或转盘后直接续行，否则原坐标不再代表摆放位置。

## 反馈与停止

Emm 默认 Receive ACK（`02`）只说明命令受理，不表示运动完成。每轮顺序读取 `3A` 状态、`36` 实时位置、`35` 实时速度，连续两轮满足以下条件才开始停留：

- 已使能、无堵转/堵转保护标志。
- 到位标志有效，实际位置距目标不超过约 0.5°。
- 实时转速反馈为零。

命令位置按 3200 脉冲/圈，反馈按 65536 单位/圈换算。采用从起点累计计算的绝对目标脉冲，避免每段 120° 固定取整引入累积误差。默认起点零附近的目标序列为 533、1600、2667、3733……；60°/120°受脉冲分辨率限制为近似值。

PA15 发送 `FE 98` 停止命令，收到 ACK 并连续两次读取零速后，才标记停止反馈已确认。默认保持使能。它是软件停止，不是硬件急停；通信断开时不能保证电机收到停止命令。

250 ms 无有效应答、驱动拒绝、堵转、失能、10 秒未完成换位或 2 秒未确认停止，会尝试发送停止并进入锁定故障，不继续换位。此时不宣称已经停车，排除原因并重新上电、重新确认摆放位置。

没有新增显示或调试串口。可在 Keil Watch 查看 `Turntable_Status`：`state`、`error`、`target_pulses`、`position_units`、`completed_moves`、`automatic`、`stop_confirmed`。串口仅用于电机二进制协议，不输出 printf。

## 目录与构建

- `App/turntable.c`：按键事件与运动状态机。
- `Hardware/turntable_key.c`：PA15/PB3 按键消抖。
- `Hardware/turntable_motor.c`：Emm 协议、UART 中断接收和超时。
- `Core/Src/main.c`：仅在 USER CODE 区域加入初始化与主循环调用。
- `MDK-ARM/turntable.uvprojx`：Keil Target `turntable`，已登记源文件和包含目录。
- 当前独立工程没有 EIDE 工程清单。

根目录执行 `python 物料台转盘/turntable/tests/run_tests.py` 可运行独立主机回归，需要 GCC、Python。测试模拟 UART 与电机，不操作硬件。日志写到 `.embeddedskills/turntable/`。

Keil 编译产物：`MDK-ARM/turntable/turntable.hex`、`turntable.axf`。重新用 CubeMX 生成时保留 USER CODE，并检查 Keil 仍包含 App/Hardware 组与头文件目录。

## 上板验收

软件编译和主机模拟测试不代表实物已验收。本次未烧录。

1. 空载确认电机 ID、串口交叉连接与共地，上电静止。
2. PB3 单步确认首次约 60°，第二次约 120°；按住不连续运动。
3. PA15 自动运行，核对每个料盘轮流到达近端并停约 2 秒。
4. 分别在旋转中、停留中停止；旋转中再次启动应补完原目标。
5. 带物料检查速度、到位抖动、滑动和夹取位置；依据实测调整加速度/位置窗口。
